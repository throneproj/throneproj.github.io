开始使用

介绍 Throne 是什么、支持哪些系统，以及从哪里开始。

本节介绍 Throne 是什么、支持哪些系统，以及应该先阅读哪些页面。如果你是第一次使用 Throne，请从这里开始。

Throne 是什么

Throne（前身为 Nekoray）是一款适用于 Windows、Linux 和 macOS 的免费开源（GPL-3.0）代理客户端。它拥有基于 Qt 的图形界面，并使用 ThroneCore 作为核心：ThroneCore 基于 sing-box，也会为需要 Xray 的配置档运行 Xray。你可以添加服务商提供的服务器或你自己的服务器，选择哪些流量经过这些服务器，然后以系统代理模式或 TUN 模式连接。

Throne for Android（前身为 NekoBox for Android）是 Throne 的 Android 应用。从 2.0.0 版本起，它与桌面版使用相同的核心、相同的设置模型和相同的备份格式，因此你可以在电脑和手机之间迁移你的整套设置。参见 Throne for Android。

如果你以前使用过 Nekoray 或 NekoBox，请阅读从 Nekoray / NekoBox 迁移。

平台

系统 要求 安装包类型
Windows Windows 10 1809 或更高版本（x64、ARM64）。使用 legacy 版本时支持 Windows 7 SP1 或更高版本（x64、32 位 x86）。 安装程序、便携版 ZIP
Linux x64 或 ARM64，glibc 2.34 或更高版本（自带 Qt 的 ARM64 版本需要 2.38） 便携版 ZIP、.deb、.rpm、安装脚本
macOS macOS 13 或更高版本（Apple Silicon 和 Intel）。使用 legacy 版本时支持 macOS 10.15 或更高版本（Intel）。 ZIP
Android Android 7.0 或更高版本 APK

安装文件请从下载页面获取。

功能亮点

  • 支持多种协议，包括带 REALITY 和 XHTTP 的 VLESS、Shadowsocks、Trojan、Hysteria、TUIC、WireGuard 和 AmneziaWG、NaïveProxy、OpenVPN 以及 OpenConnect：协议与导入格式。
  • 订阅可按计划自动更新，每个分组都可以单独设置 User-Agent 和 HWID：订阅与分组。
  • 通过系统代理或 TUN 模式为所有应用提供代理，并可与网络中的其他设备共享代理：系统代理、TUN 与局域网共享。
  • 带规则和规则集的路由配置档，以及适用于中国、伊朗和俄罗斯的现成配置档：路由。
  • 延迟测试、IP 测试和速度测试，以及让你始终使用可用服务器的自动选择器：测试与自动选择器。
  • 代理链，以及你自己的 sing-box 或 Xray 配置：代理链与自定义配置。
  • TLS 分片、uTLS 和 ECH 等反审查选项：反审查预设。
  • 内置 Cloudflare WARP：Cloudflare WARP。
  • 桌面版和 Android 应用通用的备份：备份、更新与迁移。

从哪里开始

  1. 安装 Throne：安装。
  2. 添加服务器并连接：快速入门。
  3. 阅读使用指南，了解你需要的功能，例如订阅、路由和 TUN 模式。

在 Android 上，请从 Throne for Android 开始。如果遇到问题，请参阅故障排除和常见问题。

致谢

Throne 基于以下项目构建：

  • SagerNet/sing-box：核心的代理引擎
  • XTLS/Xray-core：Xray 引擎
  • Qv2ray：部分界面代码和系统代理代码
  • Qt：界面工具包
  • simple-protobuf：界面与核心之间的消息通信
  • fkYAML：Clash YAML 导入
  • quirc：二维码识别
  • QHotkey：全局热键
  • srombauts/sqlitecpp：配置档和设置数据库
