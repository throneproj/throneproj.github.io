Подписки и группы

Как добавлять и обновлять подписки, настраивать параметры групп и решать проблемы с обновлением.

Подписка — это ссылка от вашего провайдера, по которой можно получить список серверов. Throne хранит каждую подписку в отдельной группе — вкладке над списком профилей — и умеет обновлять её за вас. Группа типа Стандартный (Basic) содержит профили, которые вы добавляете сами; у группы типа Подписка (Subscription) есть ещё URL. Изменить тип позже нельзя.

Примечание

Обновление приводит группу подписки в соответствие со списком провайдера: оно удаляет профили, которых нет в списке, и отменяет изменения, которые вы внесли в остальные. Храните собственные профили в группе типа Стандартный (Basic).

Фронт-прокси (Front Proxy), Выходной прокси (Landing Proxy), Доп. настройки (Advanced) группы и большинство параметров вкладки Подписка (Subscription) видны только в расширенном режиме, см. Простой и расширенный режим.

Добавление подписки

  1. Скопируйте адрес подписки. Он начинается с https:// или http://.
  2. В Throne нажмите Ctrl+V (Программа (Program) → Добавить профиль из буфера обмена (Add profile from clipboard)).
  3. Выберите Создать новую группу подписки (Create new subscription group) и нажмите OK.

Throne называет группу по имени хоста из адреса и загружает её. Вариант Добавить профили в эту группу (Add profiles to this group) вместо этого добавляет профили один раз и не сохраняет адрес, поэтому они никогда не обновляются.

Чтобы сначала задать название и параметры группы, выберите Группы (Groups) → Добавить новую группу (Add new Group), в поле Тип (Type) выберите Подписка, вставьте адрес в поле URL и нажмите OK. Создание группы не загружает её: щёлкните её вкладку правой кнопкой мыши и выберите Обновить подписку (Update subscription).

Ссылка throne://addsub/… от провайдера заполняет название и адрес; нажмите OK, чтобы добавить группу. См. Глубокие ссылки.

Обновление подписки

Выберите вкладку группы и нажмите Ctrl+U или щёлкните вкладку правой кнопкой мыши и выберите Обновить подписку. Группы → Обновить все подписки (Update all subscriptions) обновляет все группы подписок, включая группы с флажком Не обновлять автоматически (Skip automatic update).

Обновление добавляет новые профили, обновляет изменённые и удаляет те, которых больше нет в списке. Профили, которые не изменились, сохраняют результаты тестов. Группа принимает порядок провайдера, а отсортированная группа сортируется снова. Если в ответе нет ни одного профиля, группа остаётся без изменений.

  • Настройки (Settings) → Основные настройки (Basic Settings) → Подписка → Очищать список серверов перед обновлением подписки (Clear servers before updating subscription) удаляет профили группы перед каждым обновлением, поэтому их результаты тестов теряются.
  • Настройки → Основные настройки → Ядро (Core) → Предпочтение Xray для VLESS (Xray VLESS Preference) применяется при импорте профилей, поэтому после его изменения обновите подписки ещё раз. См. sing-box или Xray.

Какие форматы может возвращать подписка, см. на странице Протоколы и форматы импорта.

Отчёт об изменениях

Каждое обновление записывает отчёт на вкладку Логи (Logs): добавленные [+], обновлённые [~], удалённые [-] и сохранённые [=] профили, а также записи, которые не удалось импортировать или удалось импортировать только с предупреждениями, с причиной. После ручного обновления одной группы отчёт также открывается в отдельном окне; чтобы это отключить, снимите флажок Отображать окно с изменениями после обновления подписки вручную (Show the changes window after a manual subscription update) на вкладке Подписка.

Профиль, который вы используете

Обновление никогда не удаляет профиль, к которому вы подключены, даже если провайдер его удалил. Чтобы Throne останавливал и удалял его, включите Разрешить остановку активного профиля (Allow stopping the active profile) на вкладке Подписка. Тогда Throne подключается к профилю группы с тем же названием и типом, если такой профиль ровно один.

Если провайдер изменил запущенный профиль, подключение работает со старыми параметрами, пока вы не запустите профиль заново. Запущенный автовыбор перезапускается сам, когда обновление заменяет его профили.

Автоматическое обновление

По умолчанию автоматическое обновление выключено. Чтобы включить его:

  1. Откройте Настройки → Основные настройки → Подписка.
  2. Рядом с Автообновление подписки (Subscription auto update) установите флажок Включить (Enable).
  3. Задайте интервал в минутах, не меньше 30 (по умолчанию).
  4. Нажмите OK.

Группа обновляется, когда с её последнего обновления прошёл интервал, а если срок наступил, пока Throne был закрыт, — вскоре после его запуска. Группы с флажком Не обновлять автоматически пропускаются.

  • Использовать интервал обновления, установленный сервером подписки (Use the update interval sent by the server) следует интервалу, который предлагает провайдер, если он его передаёт.
  • Для одной группы можно задать собственные Интервал обновления (Update Interval) и Интервал сервера (Server Interval) в её параметрах → Доп. настройки (Advanced) → Обновление (Update). По умолчанию (Keep Default) следует вкладке Подписка, а Автообновление подписки всё равно должно быть включено.

Сведения от провайдера

Многие провайдеры передают вместе с подпиской сведения о вашем тарифе. Тогда их для текущей группы показывает карточка над списком профилей:

  • Трафик: израсходованный и общий трафик. Полоса становится красной при 90 % и после окончания срока действия.
  • Срок действия: оставшееся время, например Осталось 12 д. (12d left); становится красным, когда остаётся 3 дня или меньше. Наведите на него указатель мыши, чтобы увидеть дату.
  • Интервал обновления, пока включено автоматическое обновление.
  • Портал (Portal) и Поддержка (Support): ссылки провайдера.
  • Объявление: сообщение провайдера. Щёлкните его, чтобы прочитать весь текст.

Те же сведения показываются при наведении указателя на вкладку группы.

Throne читает их из заголовков ответа Subscription-UserInfo, Profile-Title, Profile-Web-Page-Url, Support-Url, Announce и profile-update-interval или из строк-комментариев # с теми же названиями в начале подписки.

Параметры группы

Щёлкните вкладку группы правой кнопкой мыши и выберите Редактировать выбранную группу (Edit selected Group).

Параметр Назначение
Фронт-прокси (Front Proxy), Выходной прокси (Landing Proxy) Дополнительные звенья для каждого профиля группы. См. Фронт- и выходной прокси.
Профиль маршрутизации (Routing Profile) Профиль маршрутизации, с которым подключаются профили группы. По умолчанию (…) (Default (…)) следует меню Маршрутизация (Routing). См. Профиль маршрутизации для группы.
Автоочистка недоступных профилей (Auto Clear Unavailable Profiles) Удаляет профили, не прошедшие тест задержки группы, не спрашивая подтверждения.
Не обновлять автоматически (Skip automatic update) Исключает группу из автоматических обновлений.
Использовать профиль маршрутизации из подписки (Use the subscription's routing profile) Использует профиль маршрутизации, который провайдер передаёт вместе с подпиской. См. Из подписки.
Доп. настройки (Advanced) Интервал обновления, очистка после каждого обновления, User-Agent и HWID, версия TLS и HTTP и адрес сервера.

Копировать ссылки профилей (Copy profile share links) копирует ссылки всех профилей группы.

После каждого обновления

Группа подписки может сама наводить порядок после каждого обновления. Откройте её параметры → Доп. настройки (Advanced) → Обновление (Update). По умолчанию все параметры выключены.

Параметр Назначение
Сохранять рабочие профили (Keep working profiles) Сохраняет профили, последний тест которых прошёл успешно, даже если подписка их больше не содержит.
Удалять дубликаты профилей (Remove duplicate profiles), Удалять небезопасные профили (Remove insecure profiles), Удалять недействительные профили (Remove invalid profiles) То же, что команды очистки.
Запускать тест задержки (Run URL test) Тестирует профили группы после завершения обновления.
Удалять недоступные профили (Remove unavailable profiles) Требует Запускать тест задержки. Удаляет профили, не прошедшие тест.
Сортировать по задержке (Sort by latency) Требует Запускать тест задержки. Ставит самые быстрые профили первыми.

Удалённые профили перечислены в отчёте об изменениях. Профиль, к которому вы подключены, удаляется, только если включено Разрешить остановку активного профиля.

User-Agent и HWID

Некоторые провайдеры отдают разным приложениям разные списки или отказывают незнакомым приложениям. Укажите User Agent, который ожидает ваш провайдер:

  • Для всех групп: Настройки → Основные настройки → Подписка → User Agent. Если поле пустое, отправляется Throne/ и номер версии.
  • Для одной группы: параметры группы → Доп. настройки (Advanced) → Запрос (Request) → User Agent. Если поле пустое, группа использует глобальное значение.

Некоторые провайдеры также требуют идентификатор устройства (HWID). Throne отправляет его, только если вы это включите:

  • Для всех групп: на вкладке Подписка установите флажок Включить отправку HWID, модели устройства и версии ОС при обновлении подписки (Enable sending HWID, device model, and OS version when updating subscription).
  • Для одной группы: в разделе Запрос установите для Отправлять HWID (Send HWID) значение Вкл. (On). Поля HWID, ОС (OS), Версия ОС (OS Version) и Модель устройства (Device Model) заменяют значения для этой группы.

Чтобы заменить значения для всех групп, заполните поле Указать параметры системы вручную (опционально) (Custom System Parameters (optional)) на вкладке Подписка, опустив значения, которые не нужно менять:

hwid=value,os=value,osVersion=value,model=value

Что именно отправляет Throne, см. на странице Конфиденциальность и сетевые запросы.

Фронт- и выходной прокси

Группа может направлять трафик всех своих профилей через два дополнительных профиля:

Ваше устройство → Фронт-прокси → профиль этой группы → Выходной прокси → WARP (если включён) → интернет

Используйте Фронт-прокси (Front Proxy), когда ваше устройство не может напрямую подключиться к серверам группы, и Выходной прокси (Landing Proxy), когда сайты должны видеть его адрес, а не адрес серверов группы. Можно выбрать любой сохранённый профиль, кроме автовыбора; для поиска начните вводить текст в поле. О цепочках и совмещении ядер см. Цепочки прокси и пользовательские конфигурации.

Адрес сервера

Группа может направить все свои профили на другой адрес — например, на адрес CDN, который, по данным IP-сканера, работает в вашей сети. Откройте параметры группы → Доп. настройки (Advanced) → Адрес сервера (Server Address) и выберите:

  • Собственные адреса профилей (Profiles' own addresses): без изменений (по умолчанию).
  • Фиксированный адрес (Fixed address): имя хоста или IP-адрес, без порта.
  • Список IP (IP list): первый адрес IP-списка.

Профили сохраняют свои порты и по-прежнему отправляют исходный домен как имя сервера TLS (SNI) и Host. В столбце Адрес (Address) показан адрес, который каждый профиль использует на самом деле. Профиль может переопределить настройку группы в своём редакторе: Доп. настройки (Advanced Settings) → Адрес сервера.

Проблемы

Сначала откройте вкладку Логи (Logs): каждое обновление записывает туда свою ошибку. См. также Устранение неполадок.

Провайдер отказывает Throne или не присылает профили

Некоторые провайдеры отвечают только знакомым им приложениям. Тогда в логе появляется ошибка, например код состояния 403, или сообщение «В подписке не найдено профилей» (No profiles found in the subscription). Укажите в поле User Agent группы значение, которое ожидает ваш провайдер; пользователям, например, требовались ClashMeta, sing-box и Happ/1.0. Если провайдер требует идентификатор устройства, установите для Отправлять HWID (Send HWID) значение Вкл. (On). См. User-Agent и HWID.

Сервер возвращает веб-страницу или капчу

Тогда Throne сообщает «Сервер вернул веб-страницу вместо подписки.» (The server returned a web page instead of a subscription). Измените способ подключения к серверу: Версия TLS (TLS Version) и Версия HTTP (HTTP Version) на вкладке Подписка для всех групп или в разделе Запрос (Request) дополнительных параметров группы. TLS 1.2 часто помогает, когда на обычное рукопожатие сервер отвечает капчей; стоит попробовать и HTTP/1.1 или другой User Agent.

Если первая загрузка новой группы не удалась, группа сохраняется. Исправьте её параметры и обновите её снова.

«Запрос через прокси, но профиль не запущен.» (Request with proxy but no profile started.)

Пока включён параметр Настройки → Основные настройки → Прочее (Miscellaneous) → Использовать прокси (Use proxy) или Системный прокси (System Proxy), Throne отправляет собственные запросы, например обновления подписок, через запущенный профиль. Если ни один профиль не запущен, они завершаются ошибкой. Сначала запустите профиль или выключите Использовать прокси и Системный прокси.

Адрес подписки заблокирован в вашей стране

  1. Запустите рабочий профиль.
  2. Включите Настройки → Основные настройки → Прочее → Использовать прокси (в простом режиме: Общие (Common) → Настройки сети (Network Settings)).
  3. Обновите подписку.

При включённом Отключить mixed inbound (Disable Mixed Inbound) для этого нужен Режим TUN (Tun Mode); иначе обновление завершается ошибкой «Request with proxy but the mixed inbound is disabled and Tun Mode is off.» (запрос через прокси, но mixed inbound отключён, а режим TUN выключен).

Ссылки «crypt» из Happ и v2RayTun

Ссылки, начинающиеся с happ://crypt или v2raytun://crypt, зашифрованы для этих приложений, и Throne не может их прочитать. Веб-страницы вида …/dl/happ-link/… тоже не являются подписками. Попросите у провайдера обычный адрес подписки, начинающийся с https://.

Профили отображаются как Custom Xray Config

Подписка, которая возвращает полные конфигурации Xray, даёт по одному профилю Custom Xray Config на каждую конфигурацию; он запускается как есть, без раздела inbounds. Так задумано: такие конфигурации могут содержать балансировщики нагрузки и цепочки, которые работают только целиком.

На Android

В Throne для Android те же группы, параметры и обновления. Откройте Группы (Groups) в боковом меню. Отличия:

  • Фильтры по имени. Параметры Фильтр (Filter) в редакторе группы оставляют только профили, имя которых совпадает с Только совпадающие имена (Only names matching), например HK|SG|Japan, и удаляют профили, совпадающие с Удалять совпадающие имена (Remove names matching), например expire|traffic|website. Оба поля — регулярные выражения, регистр не учитывается, фильтры применяются при каждом обновлении. Если после фильтров не осталось бы ни одного профиля, группа остаётся без изменений.
  • Карточка сведений. Чтобы скрыть сведения от провайдера для группы, выключите в её редакторе Карточка сведений о подписке (Subscription info card).
  • Адрес сервера. На Android недоступен.
  • Файлы. Поле URL принимает и адрес content://, поэтому подписка может поступать из файла, который предоставляет другое приложение.
  • Параметры для всех групп находятся в Настройки (Settings) → Подписки (Subscriptions). Если поле UserAgent (User agent) пустое, приложение отправляет Throne/Android/ и номер версии.
  • Режим Только прокси (Proxy only) отправляет обновления через запущенный профиль, а пока ни один профиль не запущен — напрямую.
  • Неподдерживаемые записи пропускаются, см. Отличия на Android.
