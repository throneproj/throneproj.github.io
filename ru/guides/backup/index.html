Резервное копирование, обновление и перенос

Резервное копирование и восстановление Throne, перенос данных между компьютером и Android и обновление приложения для компьютера.

Делайте резервную копию перед каждым обновлением.

Резервное копирование и восстановление

Откройте Настройки (Settings) → Основные настройки (Basic Settings) → Резервное копирование и восстановление (Backup and Restore). Чтобы создать резервную копию, отметьте нужные части в разделе Создать резервную копию (Create Backup) (по умолчанию отмечены все), нажмите Создать резервную копию (Create Backup...) и выберите, куда сохранить файл .thrbackup.

Часть Что содержит
Профили (группы и прокси) (Profiles (groups and proxies)) Группы, подписки и профили.
Профили маршрутизации (Routing profiles) Профили маршрутизации и их правила.
Настройки (Settings) Все настройки, включая DNS, TUN, WARP и входящие подключения.
OTP-профили (OTP profiles) Записи менеджера OTP.
Списки IP и сканирования (IP lists and scans) Списки и результаты IP-сканера.
Пользовательские иконки (Custom icons) Собственные иконки для трея.

Резервная копия не содержит историю трафика, логи, кэш ядра и то, был ли включён Режим TUN (Tun Mode) или Системный прокси (System Proxy).

Предупреждение

Резервная копия содержит пароли ваших серверов, ссылки на подписки и другие секретные данные. Никому не передавайте этот файл и никогда не прикладывайте его к отчёту об ошибке.

Чтобы восстановить резервную копию:

  1. Нажмите Восстановить из копии (Restore from Backup...) и выберите файл .thrbackup. Throne покажет, когда и на каком устройстве он создан.
  2. Отметьте части для восстановления и нажмите Восстановить (Restore). Каждая часть заменяет ваши текущие данные, и это нельзя отменить.
  3. Throne перезапустится.
  • Резервные копии из более старых версий восстанавливаются как обычно. Копию из более новой версии Throne может отклонить с сообщением «Неподдерживаемый формат резервной копии» (Unsupported backup format version): сначала обновите Throne.
  • Правила маршрутизации с условиями, которые ваша версия не поддерживает, пропускаются, и Throne сообщает, сколько их.
  • Если восстановить только одну из частей Профили (группы и прокси) и Профили маршрутизации, группы с собственным профилем маршрутизации возвращаются к профилю по умолчанию.

Для Throne без интерфейса (headless) см. thronectl.

Резервные копии на WebDAV

Throne для компьютера и Throne для Android могут хранить резервные копии на сервере WebDAV, например в Nextcloud, на NAS или в Яндекс Диске, и каждое приложение восстанавливает то, что загрузило другое. На компьютере задайте сервер через WebDAV Settings... в Резервное копирование и восстановление, затем нажмите Upload to WebDAV, чтобы загрузить части, отмеченные в разделе Создать резервную копию. Throne не загружает копии по расписанию и сам не удаляет старые.

Предупреждение

Резервные копии не шифруются. Любой, кто может читать папку WebDAV, может прочитать пароли ваших серверов и ссылки на подписки. Используйте сервер, которому вы доверяете, и подключайтесь к нему по https://.

Настройки WebDAV

Поле Что делает
Server URL Адрес WebDAV, начинающийся с http:// или https://, например https://cloud.example.com/remote.php/dav/files/me/ для Nextcloud.
Username, Password Данные для входа. Они передаются через базовую аутентификацию HTTP (basic authentication), поэтому по http:// идут без шифрования.
Folder Папка внутри адреса сервера (по умолчанию Throne, вложенные папки через /). Недостающие папки Throne создаёт сам.
Device name Имя этого компьютера в списке резервных копий (по умолчанию — имя компьютера).
Connect through the proxy Отправляет запросы через локальный прокси Throne. Должен быть запущен профиль.

Test проверяет значения ещё до того, как вы сохраните их кнопкой Save. Эти настройки относятся только к этому компьютеру: резервные копии их не содержат.

Без Connect through the proxy запросы WebDAV идут напрямую, если не включены Использовать прокси (Use proxy) или Системный прокси (см. Сетевые запросы). Throne проверяет TLS-сертификат сервера, если не включён Игнорировать ошибки TLS (Ignore TLS errors).

Восстановление или удаление резервной копии

  1. Нажмите Restore from WebDAV.... Throne покажет резервные копии, новые сверху, с устройством, платформой, версией и частями.
  2. Выберите копию и нажмите Восстановить (Restore) (или дважды щёлкните по ней).
  3. Продолжайте с шага 2 раздела Резервное копирование и восстановление.

Throne сверяет каждую скачанную копию со списком резервных копий. Файлы, которых нет в списке, например скопированные туда вручную, отображаются как «Unknown device» (неизвестное устройство), и проверить их нельзя. Чтобы удалить копию, выберите её и нажмите Delete.

Сообщение Что делать
«Wrong username or password.» Проверьте Username и Password. Сервисам с двухэтапным входом часто нужен пароль приложения.
«Permission denied.» У учётной записи нет права записи в эту папку Folder. Укажите другую или проверьте права на сервере.
«The server redirected to …; check the server URL.» Укажите адрес из сообщения в поле Server URL.
«The server's folder listing could not be read.» Server URL не является адресом WebDAV, например это веб-страница вашего хранилища.
«The server did not answer in time.» Проверьте подключение или попробуйте Connect through the proxy.
«Запрос через прокси, но профиль не запущен.» (Request with proxy but no profile started.) Запустите профиль или выключите Connect through the proxy, Использовать прокси и Системный прокси.

WebDAV на Android

В Throne для Android откройте Настройки (Settings) → Резервное копирование и восстановление (Backup & restore) (или Инструменты (Tools) в боковом меню). На карточке Резервная копия WebDAV (WebDAV backup) есть Резервное копирование в WebDAV (Back up to WebDAV), Восстановление из WebDAV (Restore from WebDAV) и Настройки WebDAV (WebDAV settings). Чтобы делиться копиями с компьютером, укажите тот же сервер и ту же папку: Folder на компьютере соответствует Путь резервной копии (Backup path) здесь. Резервное копирование в WebDAV загружает части, отмеченные на карточке Локальная резервная копия (Local backup).

У Android нет параметра прокси для WebDAV: в режиме VPN запросы проходят через VPN, как трафик других приложений. Ошибки TLS-сертификата он никогда не игнорирует.

Перенос между компьютером и Android

Приложение для компьютера и Throne для Android используют один формат резервных копий, поэтому данные можно переносить в обе стороны — файлом или через WebDAV.

С компьютера на телефон:

  1. Создайте резервную копию на компьютере и скопируйте файл .thrbackup на телефон.
  2. На телефоне откройте Настройки (Settings) → Резервное копирование и восстановление (Backup & restore), нажмите Восстановить (Restore) и выберите файл (или откройте его из файлового менеджера).
  3. Отметьте части для восстановления и подтвердите.

С телефона на компьютер: на телефоне откройте Настройки → Резервное копирование и восстановление, отметьте части и нажмите Создать резервную копию (Create backup) (Поделиться (Share) отправляет файл в другое приложение). Скопируйте файл на компьютер и восстановите его.

При восстановлении резервной копии с компьютера на Android кое-что меняется:

Элемент На Android
OTP-профили, Списки IP и сканирования, Пользовательские иконки и Адрес сервера (Server Address) групп Не восстанавливаются.
Настройки, которые есть в обоих приложениях Получают значения из резервной копии. Например, MTU для TUN становится 1500 (по умолчанию на Android — 9000).
Разрешить подключения из локальной сети (Allow connections from the LAN) Выключается с предупреждением, если резервная копия разрешает подключаться другим устройствам, а на телефоне это было выключено.
Правила маршрутизации с условиями, которые Android не поддерживает Пропускаются с предупреждением.
Raw-профили маршрутизации Сохраняются, но только для чтения и не используются. Если один из них был активен, активным становится первый пригодный профиль маршрутизации.
Конечные точки OpenVPN и OpenConnect в профиле маршрутизации Сохраняются, но не работают.
Профили Tailscale и дополнительного ядра (Extra Core) Восстанавливаются, но запустить их нельзя.

В обратном направлении правила для приложений Android и настройки прокси для отдельных приложений на компьютере ни на что не влияют.

Обновление приложения для компьютера

Обновление сохраняет профили и настройки (они хранятся в папке данных), но сначала всё же создайте резервную копию.

  1. Откройте Программа (Program) → Проверить наличие обновлений (Check For Update) (до 1.4.0: Утилиты (Tools) → Проверить наличие обновлений).
  2. Если есть более новая версия, окно Обновление (Update) покажет изменения. Нажмите Обновить (Update).
  3. Когда Throne предложит перезапуститься, нажмите Да (Yes). Программа обновления установит новую версию.

Обновление одной кнопкой Обновить работает только для копий из ZIP-архива и для установки через установщик Windows по умолчанию (для текущего пользователя), и не работает, пока из той же установки запущен фоновый Throne. Остальные установки обновляются так:

Способ установки Как обновить
ZIP-файл Обновить или замените файлы программы новым ZIP. Папку config сохраните.
Установщик Windows, текущий пользователь (по умолчанию) Обновить или запустите новый установщик.
Установщик Windows, все пользователи Запустите новый установщик.
Пакет .deb или .rpm Установите новый пакет.
Скрипт установки для Linux Запустите скрипт ещё раз.
macOS Замените Throne.app новой версией. См. Установка.
WinGet, Scoop, AUR, Nix, Homebrew или репозиторий APT или RPM Используйте менеджер пакетов. См. Менеджеры пакетов.

Если вы переустанавливаете Throne установщиком Windows, ответьте Нет (No), когда программа удаления спросит, удалить ли также профили, настройки и логи.

Некоторые антивирусы помечают программу обновления как подозрительную, потому что она заменяет файлы программы. Если обновление не удалось, убедитесь, что Throne не находится в папке «Загрузки» (#1109), и попробуйте ещё раз или скачайте новую версию со страницы загрузок.

Бета-версии

Бета-версии (предварительные выпуски) первыми получают функции и исправления, но в них может быть больше ошибок. Перед установкой бета-версии сделайте резервную копию.

  • Компьютер: отметьте Настройки (Settings) → Основные настройки (Basic Settings) → Прочее (Miscellaneous) → Разрешить обновление до бета-версий (Allow updating to beta versions) (в простом режиме — в разделе Настройки сети (Network Settings) на вкладке Общие (Common)).
  • Android: включите Настройки (Settings) → Основные (General) → Разрешить обновления до beta-версий (Allow updating to beta versions). См. встроенное средство обновления.

Чтобы вернуться, выключите этот параметр. Программа обновления предлагает только более новые версии, поэтому вы останетесь на бета-версии, пока не выйдет более новый стабильный релиз.

Старые версии

  • Throne для компьютера до версии 1.1.0: версия 1.1.0 перенесла все данные в throne.db и не конвертирует старые конфигурации. Добавьте подписки и профили заново или попробуйте скрипты сообщества из #1202. Резервные копии из версии 1.1.3 и новее восстанавливаются в более новых версиях.
  • Nekoray или NekoBox: см. Переход с Nekoray / NekoBox.
  • Throne для Android до версии 2.0.0: версия 2.0.0 подписана новым ключом, поэтому сначала удалите старое приложение. Версия 2.0.0 запускается без данных и не восстанавливает старые резервные копии (throne_backup_*.json или файлы .zip из WebDAV) — только файлы .thrbackup. Перед удалением запишите ссылки на свои подписки или перенесите всё с помощью резервной копии с компьютера. См. Установка и обновление.
