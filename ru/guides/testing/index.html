Тестирование и автовыбор

Тестирование профилей и сервисов, доступных через них, сортировка, закрепление и очистка списка и автовыбор лучшего профиля.

Тесты не останавливают запущенный профиль. Профили автовыбора тесты пропускают — вместо этого тестируйте группы, которые использует автовыбор.

Тест задержки

Тест задержки проверяет, что профиль работает, и измеряет его задержку. Throne дважды запрашивает URL теста задержки (Latency Test URL) через профиль и показывает, сколько миллисекунд занял второй запрос.

  • Выбранные профили: щелкните их правой кнопкой мыши и выберите Тест (Test) → Тест задержки (URL test, Ctrl+Shift+S).
  • Вся группа: выберите Группы (Groups) → Тест → Тест задержки (URL test, Ctrl+Shift+G).
  • Запущенный профиль: щёлкните его имя в левой части строки состояния. Результат появится в строке состояния.

Тест → Остановить тестирование (Stop testing, Ctrl+.) останавливает идущий тест.

В столбце Результат теста (Test Result) отображается задержка (зелёным до 100 мс, жёлтым до 300 мс, красным при большем значении), Недоступен (Unavailable), если тест не пройден (в логе есть строка с ошибка теста (test error) и причиной), или Подключение успешно (Connect OK), если профиль OpenVPN или OpenConnect подключился, но тестовый URL через него не ответил. Неизвестно (Unknown) означает, что во время теста не работала ваша собственная сеть, поэтому результат ничего не говорит о профиле: такой профиль сортируется вместе с непротестированными, Удалить недоступные (Remove unavailable) и автоматическая очистка его не трогают, а следующий тест заменяет результат.

Параметры находятся в Настройки (Settings) → Основные настройки (Basic Settings) → Проверка (Testing) → Задержка (Latency).

Параметр По умолчанию Назначение
URL теста задержки (Latency Test URL) http://cp.cloudflare.com/ Адрес, который Throne запрашивает через каждый профиль.
Таймаут (Timeout; рядом с Кол-во потоков) 3000 мс Ограничение времени для каждого запроса. При слишком маленьком значении профили с мультиплексированием, которым нужно больше времени на первый запрос, помечаются как нерабочие.
Кол-во потоков (Concurrency) 10 Сколько профилей тестируется одновременно.
URL проверки Direct (Direct Test URL) пусто Адрес, который открывается в вашей сети без прокси. Автовыбор запрашивает его напрямую, чтобы отличить пропавшее подключение к интернету от нерабочих серверов. Пустое значение означает, что Throne использует состояние сети, которое сообщает операционная система.

Тест выходного IP

Этот тест показывает выходной IP-адрес каждого профиля и его страну: именно этот адрес видят сайты. Щелкните профили правой кнопкой мыши и выберите Тест → Выходной IP (Exit IP) или выберите Группы → Тест → Выходной IP. После этого в столбце Результат теста отображается флаг страны, а также выходной IP, если включено отображение Выходной IP (Exit IP) — см. Сортировка и фильтрация. Эту страну используют фильтр по странам и параметр автовыбора Только страны (Only countries).

После запуска профиля Throne также показывает страну и город его выхода в левом нижнем углу окна и в заголовке окна. В разделе Проверка → Страна выхода (Exit Country) параметр Определять страну выхода (Look up exit country) отключает это, а Сервис определения IP (Lookup service) выбирает сервис; Автоматически (Automatic) начинает с IP2Location.io, который использует и тест выходного IP. О сервисах, к которым обращается Throne, см. Конфиденциальность и сетевые запросы.

Тест скорости

Тест скорости измеряет скорость скачивания и отдачи через профиль.

  • Выбранные профили: щелкните их правой кнопкой мыши и выберите Тест → Тест скорости (Speed test, Ctrl+Shift+P).
  • Вся группа: выберите Группы → Тест → Тест скорости (Speed test, Ctrl+Alt+P).
  • Текущее подключение: пока профиль запущен, выберите Утилиты (Tools) → Тест скорости текущего подключения (Speed test current connection, F6).

Throne тестирует профили по одному. В столбце Результат теста отображается скорость скачивания после ↓ и скорость отдачи после ↑, если включено отображение Скорость (Speed).

Настройки → Основные настройки → Проверка → Тест скорости (Speed Test) → Режим теста скорости (Speed test mode) определяет, что делает тест: Скачивание (↓) + отдача (↑) (Download + upload; по умолчанию), Только скачивание (↓) (Only download), Только отдача (↑) (Only upload) или Простое скачивание (Simple download) — загрузка URL для простого теста скачивания (Simple Download URL) без поиска сервера. Таймаут (Timeout) в том же разделе (по умолчанию 5000 мс) ограничивает каждую часть теста.

Предупреждение

Тест скорости передаёт столько данных, сколько успеет до истечения таймаута, — и так для каждого профиля. Тестирование большой группы может израсходовать много трафика.

Проверка сервисов

Проверка сервисов показывает, какие сервисы работают через профиль, например ИИ-ассистенты, стриминговые сервисы и социальные сети, и к какому типу относится выходной IP профиля. Щелкните профили правой кнопкой мыши и выберите Тест → Проверка сервисов (Service check) или выберите Группы → Тест → Проверка сервисов.

После этого в столбце Результат теста отображается логотип каждого сервиса с зеленым, желтым или красным значком. Наведите указатель мыши на логотип, чтобы увидеть статус сервиса (Доступно (Available), Частично (Partial), Ограничено (Restricted), Заблокировано (Blocked), Неизвестно (Unknown) или Сбой (Failed)), а на ячейку — чтобы увидеть дату и тип IP: IP дата-центра, мобильный, корпоративный или домашний. Чтобы найти профили, на которых работает сервис, введите его название в фильтр столбца Результат теста (см. Сортировка и фильтрация).

Настройки → Основные настройки → Проверка → Проверка сервисов (Service Check) определяет, какие сервисы проверяются; остальные не проверяются и не отображаются. Кнопка Проверить (Check) на вкладке Статистика (Runtime Stats) главного окна проверяет запущенный профиль.

  • За один запуск проверяется не больше 100 профилей. Если их больше 20, Throne сначала спрашивает подтверждение, потому что каждый профиль отправляет около 20 запросов к проверяемым сервисам.
  • Список проверок скачивается не чаще одного раза в день; см. Конфиденциальность и сетевые запросы.

Сортировка и фильтрация

Щелкните заголовок столбца, чтобы отсортировать по нему, и еще раз, чтобы изменить порядок на обратный. При сортировке по задержке вверху оказываются самые быстрые профили, за ними — не прошедшие тест, а в конце — непротестированные. Группа остается отсортированной, в том числе после тестов, обновления подписки и импорта, пока вы не щелкнете заголовок столбца правой кнопкой мыши и не выберете Отключить сортировку (Stop sorting) или не перетащите строку на другое место.

Щелкните заголовок Результат теста правой кнопкой мыши, чтобы выбрать, что показывает столбец (Выходной IP, Скорость), и по чему он сортируется (Пингу (Latency), Скорости скачивания (↓) (Download speed), Скорости отдачи (↑) (Upload speed), Выходной IP (Exit IP)).

Чтобы отфильтровать список, нажмите Ctrl+F и введите текст в поле под заголовком Тип (Type), Адрес (Address) или Название (Name) либо в поле Фильтр по стране или сервису... (Filter by country or service...) под заголовком Результат теста. В поле Адрес запрос port=443 показывает профили на порту 443, а port=1000:2000 — профили на портах от 1000 до 2000. Нажмите Ctrl+F еще раз, чтобы скрыть и очистить поля.

Поле Результат теста принимает коды стран из теста выходного IP, например DE, а также названия или категории сервисов из проверки сервисов: gemini показывает профили, на которых работает Gemini, а !netflix — профили, на которых Netflix отказывает в доступе. Совпасть должны все слова, поэтому DE gemini показывает немецкие профили, на которых работает Gemini.

Закрепление профилей

Щелкните профили правой кнопкой мыши и выберите Закрепить вверху (Pin to top), чтобы они оставались над остальными профилями своей группы в том порядке, в котором вы их закрепили. Сортировка перемещает только незакрепленные профили, а закрепленные отделены от них линией. Если все выбранные профили уже закреплены, пункт меню называется Открепить (Unpin). Строка, перетащенная к закрепленным профилям, тоже закрепляется. Закрепление сохраняется при обновлении подписки, пока профиль остается в подписке.

Очистка

Группы → Очистка (Clean up) (это подменю есть и в контекстном меню вкладки группы) удаляет профили из текущей группы:

Команда Что удаляет
Удалить дубликаты (Remove duplicates) Точные копии более раннего профиля, включая название.
Удалить недоступные (Remove unavailable) Профили, последний тест которых не пройден. Запущенный профиль никогда не удаляется.
Удалить недействительные (Remove invalid) Профили, которые ядро отклоняет как недействительные.
Удалить небезопасные профили (Remove insecure profiles) Профили без шифрования, с TLS без проверки сертификатов или со старыми шифрами Shadowsocks.

Остальные команды останавливают запущенный профиль, если удаляют его. Группы → Тест → Очистить результаты (Clear results, Ctrl+Shift+C) очищает только результаты тестов.

Чтобы увидеть, какие профили считаются небезопасными, включите Настройки → Основные настройки → Внешний вид (Appearance) → Список профилей (Profile List) → Отображать безопасность профилей (Show profile security): тогда небезопасные профили помечаются предупреждающим значком в столбце Тип.

Для автоматической очистки используйте параметр группы Автоочистка недоступных профилей (Auto clear unavailable profiles), который удаляет не прошедшие тест профили после каждого теста задержки группы, или параметры группы подписки из раздела После каждого обновления, которые также могут тестировать и сортировать ее.

Автовыбор

Автовыбор — это профиль, который выбирает лучший рабочий профиль из одной или нескольких групп, продолжает проверять остальные и переключается, когда текущий профиль начинает работать хуже или отказывает. Новые профили из обновления подписки сами добавляются в него.

  1. Выберите вкладку группы, которую он должен использовать.
  2. Выберите Программа (Program) → Новый профиль (New profile, Ctrl+N). Откроется редактор, в котором в поле Тип (Type) уже выбран Автовыбор (Auto Selector).
  3. Введите Название (Name).
  4. В поле Профили из (Profiles from) отметьте группы, из которых автовыбор выбирает профили. Текущая группа уже отмечена.
  5. Нажмите OK, затем запустите новый профиль, как любой другой.
Параметр Назначение
Профили из (Profiles from) Группы, профили которых использует автовыбор. Профили всех отмеченных групп ранжируются вместе.
Фильтр по названию (Only names matching) Необязательное регулярное выражение; используются только профили, название которых ему соответствует. Совпадение может быть в любом месте названия, регистр не учитывается: germany|nl использует все названия, в которых есть germany или nl, а ^(?!.*(germany|🇩🇪)).*$ — все названия, в которых нет ни germany, ни 🇩🇪.
Выбор (Choose) Самый быстрый (Fastest; по умолчанию) использует лучший по результатам измерений профиль. По приоритету (In priority order) использует Уровни приоритета.
Уровни приоритета (Priority tiers) Показываются при значении По приоритету. Каждая строка — это Группа (Group) (или Любая группа (Any group)) с необязательным выражением Фильтр по названию (Names matching). Профиль относится к первой строке, которой он соответствует, а профили, не соответствующие ни одной строке, идут последними. Автовыбор использует самую верхнюю строку, в которой есть рабочий профиль, и в ней — лучший по результатам измерений.
Распределить трафик между лучшими профилями (Share traffic between the best profiles) Выкл. (по умолчанию): весь трафик идет через один профиль, а остальные готовые профили находятся в резерве. Вкл.: трафик распределяется между готовыми профилями. При Переключать каждые 30 сек (Rotate every 30 s; по умолчанию) новые подключения каждые 30 секунд переходят на следующий профиль; при На каждое подключение (Per connection) каждое новое подключение может использовать другой профиль, поэтому ваш выходной IP может меняться во время сеанса.
Предпочтительный профиль (Preferred profile) Появляется, после того как вы выбрали профиль кнопкой Использовать этот профиль (Use this profile) в окне статистики. Использовать автовыбор (Use automatic) возвращает выбор автовыбору.

Каждый профиль работает так, как если бы вы запустили его отдельно: через Фронт-прокси (Front Proxy) и Выходной прокси (Landing Proxy) своей группы. Эти прокси группы, в которой находится сам автовыбор, не применяются.

Дополнительно ▾ (Advanced ▾) показывает дополнительные параметры; у каждого есть рабочее значение по умолчанию и всплывающая подсказка. Чаще всего меняют эти:

Параметр По умолчанию Назначение
Только страны (Only countries) пусто Коды стран, например DE,NL,FR. ! исключает страну: !RU,!IR использует все страны, кроме этих двух. Используется страна, которую нашел тест выходного IP, поэтому, пока параметр задан, профили без страны пропускаются.
Запускать лучших (Run the best) 300 профилей Сколько профилей загружается в работающую конфигурацию. Автовыбор переключается между ними без переподключения.
Порог переключения (Switch tolerance) 300 мс Насколько быстрее должен быть другой профиль, чтобы автовыбор переключился на него.
Максимальная задержка (Maximum latency) без ограничений Профили медленнее этого значения используются, только если не работает ни один более быстрый.
Разрывать подключения при сбое профиля (Drop connections when a profile fails) вкл. Когда текущий профиль отказывает, открытые соединения сразу переходят на новый. Если параметр выключен, они завершаются через отказавший профиль.
Учиться на реальных подключениях (Learn from real connections) выкл. Оценивает профили также по реальным подключениям ваших приложений и откладывает те, что постоянно отказывают.

Если пригодных профилей больше, чем задано в Запускать лучших, автовыбор сначала выполняет тест задержки для профилей без свежего результата (успешный результат действует 24 часа, неудачный — один час) и загружает лучшие. Он запускается, как только несколько из них работают, заканчивает тесты в фоне и один раз перезапускается, если рейтинг изменился. Если все запущенные профили не работают, он пересобирается из следующих лучших. Пока у компьютера нет подключения к сети, он приостанавливается. Его строки в логе начинаются с [Автовыбор] ([Auto selector]).

Пока автовыбор запущен, Утилиты → Статистика автовыбора (Auto Selector Stats) показывает статус и задержку каждого профиля. Использовать этот профиль (Use this profile) оставляет выбранный профиль в работе, Вернуть автовыбор (Back to automatic) снова доверяет выбор рейтингу, а Проверить все сейчас (Check all now) немедленно измеряет все запущенные профили.

Ограничения:

  • Цепочка может содержать один автовыбор в качестве звена, но не вместе с профилем дополнительного ядра (Extra Core) или пользовательской конфигурацией; см. ограничения цепочек и Проверка цепочки. Автовыбор не может быть Фронт-прокси (Front Proxy) или Выходной прокси (Landing Proxy).
  • Он пропускает цепочки, другие профили автовыбора, OpenVPN, OpenConnect, Tailscale, дополнительное ядро (Extra Core), полные конфигурации sing-box, пользовательские конфигурации, которые не удаётся прочитать, и полные конфигурации Xray, которые нельзя совместить с фронт- или выходным прокси своей группы.

На Android

В Throne для Android те же тесты и тот же автовыбор. Отличия:

  • Меню. На экране Конфигурация (Profiles) в меню ⋮ есть Тест (Test) (URL-тест (URL test), Тест IP и страны (IP & country test), Тест скорости (Speed test), Остановить тест (Stop testing)), Удалить (Remove) и Сортировка (Sort). Для выбранных профилей используйте Тест в меню выделения, для одного профиля — его кнопку ⋮.
  • Панель тестирования. Панель показывает ход и результаты теста, а также действия, например Сортировать по задержке (Sort by latency), Удалить недоступные (Remove unavailable) и Подключиться к самому быстрому (Connect to fastest).
  • Текущее подключение. Пока подключение активно, нажмите на панель статистики, чтобы проверить подключение. Долгое нажатие на неё открывает Графики в реальном времени (Live graphs) и Тест скорости текущего соединения (Speed test current connection). Панель также показывает страну выхода; в Настройки (Settings) → Тестирование (Testing) есть Look up exit country и Lookup service.
  • Автовыбор. Создайте его через Добавить профиль (Add profile) → Ручные настройки (Manual settings) → Автовыбор (Auto selector). Нажмите на его строку состояния на экране Конфигурация, чтобы открыть Статистика автовыбор (Auto selector stats).
