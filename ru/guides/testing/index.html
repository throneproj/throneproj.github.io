Тестирование и автовыбор

Как проверять профили на задержку, выходной IP и скорость, сортировать и фильтровать список, удалять нерабочие профили, поручить автовыбору поиск лучшего сервера и искать рабочие IP-адреса.

Throne умеет тестировать ваши профили и помогает оставить только хорошие. На этой странице описаны тест задержки, тест IP и страны и тест скорости, сортировка и фильтрация, очистка списка, автовыбор, который сам подбирает для вас лучший сервер, а также IP-сканер, который находит адреса серверов, работающие в вашей сети.

Тесты не останавливают запущенный профиль. Профили автовыбора тесты пропускают — вместо этого тестируйте группы, которые использует автовыбор.

Тест задержки

Тест задержки проверяет, что профиль работает, и измеряет его задержку. Throne дважды запрашивает URL теста задержки (Latency Test URL) через профиль и показывает, сколько миллисекунд занял второй запрос.

Чтобы запустить тест задержки:

  • Выбранные профили: щёлкните их правой кнопкой мыши и выберите Тест задержки (Url Test Selected, Ctrl+Shift+S).
  • Вся группа: выберите Группы (Groups) → Тест задержки всей группы (Url Test Group, Ctrl+Shift+G) или щёлкните вкладку группы правой кнопкой мыши и выберите Тест задержки выбранной группы (Url Test selected Group).
  • Запущенный профиль: щёлкните имя профиля в левой части строки состояния. Throne один раз проверит текущее подключение и покажет в строке состояния Результат теста: (Test Result:) со временем или Недоступен (Unavailable).

Пока идёт тест, в контекстном меню и в меню Группы появляется пункт Остановить тестирование (Stop Testing, Ctrl+.).

В столбце Результат теста (Test Result) отображается одно из следующих значений:

Результат Значение
Время, например 85 ms Профиль работает. Время отображается зелёным до 100 мс, жёлтым до 300 мс и красным при большем значении.
Недоступен (Unavailable) Тест не пройден. В логе есть строка с ошибка теста (test error) и причиной.
Подключение успешно (Connect OK) Профиль OpenVPN или OpenConnect подключился, но тестовый URL через него не ответил.

Параметры тестов находятся в Настройки (Settings) → Основные настройки (Basic Settings) → Общие (Common), в группе Проверка (Testing):

Параметр По умолчанию Назначение
URL теста задержки (Latency Test URL) http://cp.cloudflare.com/ Адрес, который Throne запрашивает через каждый профиль.
Таймаут (Timeout; рядом с Кол-во потоков) 3000 мс Ограничение времени для каждого запроса. Не делайте его слишком маленьким: профилям с мультиплексированием нужно больше времени на первый запрос, и при коротком таймауте они помечаются как нерабочие.
Кол-во потоков (Concurrency) 10 Сколько профилей тестируется одновременно.
URL проверки Direct (Direct Test URL) пусто Запрашивается без прокси, чтобы автовыбор мог отличить пропавшее подключение к интернету от нерабочих серверов. Укажите адрес, который открывается в вашей сети без прокси. Пустое значение означает, что Throne использует состояние сети, которое сообщает операционная система.

В простом режиме в группе Проверка (Testing) видны только URL теста задержки и Определять страну выхода (Look up exit country). Остальные параметры тестов с этой страницы, например Режим проверки скорости (Speedtest mode) и Сервис определения IP (Lookup service), доступны только в расширенном режиме (см. Простой и расширенный режим).

Чтобы скопировать результаты выбранных профилей, щёлкните их правой кнопкой мыши и выберите Поделиться (Share) → Копировать результат теста (Copy Test Result).

Тест IP и страны

Этот тест показывает выходной IP-адрес каждого профиля и его страну. Именно этот адрес видят сайты.

  • Выбранные профили: щёлкните их правой кнопкой мыши и выберите Определить выходной IP выбранных (Resolve Selected Out IP).
  • Вся группа: выберите Группы → Определить выходной IP группы (Resolve out IP for group).

Оба пункта доступны только в расширенном режиме (см. Простой и расширенный режим).

Throne запрашивает https://api.ip2location.io/ через каждый профиль. После этого в столбце Результат теста отображается флаг страны, а также выходной IP, если включено отображение Выходной IP (Out IP) — см. Сортировка и фильтрация. Тест использует Таймаут и Кол-во потоков теста задержки.

Страна используется фильтром по странам и параметром автовыбора Только страны (Only countries). О сервисах, к которым обращается Throne, см. Конфиденциальность и сетевые запросы.

У запущенного профиля есть собственное определение выхода. После запуска профиля Throne через локальный порт прокси спрашивает у сервиса определения IP, с какого IP-адреса и из какой страны выходит подключение. Страну и город он показывает в левом нижнем углу окна, в заголовке окна и на вкладке Статистика (Runtime Stats; только в расширенном режиме). Это определение не меняет столбец Результат теста. Начиная с 1.4.0 сервис можно выбрать или отключить определение в Настройки → Основные настройки → Общие, в группе Проверка:

Параметр По умолчанию Назначение
Определять страну выхода (Look up exit country) вкл. Выкл.: Throne никогда сам не обращается к сервису определения и не показывает страну выхода.
Сервис определения IP (Lookup service) Автоматически (Automatic) Сервис, к которому обращается Throne: ip-api.com, ipwho.is, ipinfo.io, ipapi.co, IP2Location.io, FreeIPAPI или Cloudflare. Автоматически опрашивает IP2Location.io, ip-api.com, ipwho.is, ipinfo.io и Cloudflare в этом порядке, пока один из них не назовёт страну, и прекращает попытки через 20 секунд. Он начинает с IP2Location.io, потому что тест IP и страны тоже использует этот сервис, и оба называют одну и ту же страну.

Тест скорости

Тест скорости измеряет скорость скачивания и отдачи через профиль.

  • Выбранные профили: щёлкните их правой кнопкой мыши и выберите Тест скорости (Speedtest Selected, Ctrl+Shift+P).
  • Вся группа: выберите Группы → Тест скорости всей группы (Speedtest Group, Ctrl+Alt+P) или щёлкните вкладку группы правой кнопкой мыши и выберите Тест скорости выбранной группы (Speed Test selected Group).
  • Текущее подключение: пока профиль запущен, выберите Утилиты (Tools) → Тест скорости текущего профиля (Speedtest Current, F6).

Throne тестирует профили по одному. Затем в столбце Результат теста отображается скорость скачивания после ↓ и скорость отдачи после ↑, если включено отображение Скорость (Speed).

Что именно делает тест, выбирается в Настройки → Основные настройки → Общие → Режим проверки скорости (Speedtest mode):

Режим Что делает
Скачивание (↓) + отдача (↑) (Download + Upload; по умолчанию) Находит ближайший сервер Speedtest, затем измеряет скорость скачивания и отдачи.
Только скачивание (↓) (Only Download) Измеряет только скорость скачивания.
Только отдача (↑) (Only Upload) Измеряет только скорость отдачи.
Простое скачивание (Simple Download) Скачивает файл по адресу из URL для простого теста скачивания (Simple Download URL), по умолчанию http://cachefly.cachefly.net/1mb.test. Поиск сервера не выполняется.
Только проверка страны (Only Country) Только находит ближайший сервер Speedtest и показывает его страну. Работает быстро, почти не расходует трафик и тестирует много профилей одновременно.

Таймаут рядом с параметром Режим проверки скорости (по умолчанию 5000 мс) ограничивает каждую часть теста.

Предупреждение

Тест скорости передаёт столько данных, сколько успеет до истечения таймаута, — и так для каждого профиля. Тестирование большой группы может израсходовать много трафика, что важно, если в вашем тарифе есть лимит. Этот трафик учитывается в столбце Трафик (Traffic) каждого профиля.

Сортировка и фильтрация

Чтобы отсортировать профили группы:

  • Щёлкните заголовок столбца, чтобы отсортировать по нему. Щёлкните ещё раз, чтобы изменить порядок на обратный. Throne сохраняет новый порядок.
  • При сортировке по задержке первым щелчком самые быстрые профили оказываются вверху. За ними следуют профили, не прошедшие тест, а непротестированные — в самом конце.
  • Начиная с 1.4.0, группа остаётся отсортированной. Небольшая стрелка рядом с названием отсортированного столбца показывает сортировку и её направление. После тестов, обновления подписки или импорта Throne снова расставляет профили по порядку. Чтобы сохранить текущий порядок и прекратить сортировку, щёлкните заголовок столбца правой кнопкой мыши и выберите Отключить сортировку (Stop Sorting).
  • Щёлкните заголовок Результат теста правой кнопкой мыши, чтобы выбрать, что показывает столбец (Показывать: (Include:) Выходной IP, Скорость), и по чему он сортируется (Сортировать по: (Sort By:) Пингу (Latency), Скорости скачивания (↓) (Download Speed), Скорости отдачи (↑) (Upload Speed), Выходному IP (IP Out)).
  • Щёлкните заголовок Трафик правой кнопкой мыши, чтобы отсортировать по значению Всего (Total), Получено (↓) (Downloaded) или Отправлено (↑) (Uploaded).
  • Перетаскивайте строки, чтобы расположить их в любом порядке. Пока включён фильтр, это не работает. Перетаскивание строки также прекращает сортировку.

Обновление подписки расставляет профили в порядке, заданном провайдером, а затем Throne снова применяет сортировку группы. Чтобы после каждого обновления тестировать группу подписки и сортировать её по задержке, используйте её параметры Запускать тест задержки (Run URL test) и Сортировать по задержке (Sort by latency); см. После каждого обновления.

Чтобы отфильтровать список:

  1. Нажмите Ctrl+F или кнопку фильтра у правого края панели вкладок групп.
  2. Введите текст в поле под заголовком Тип (Type), Адрес (Address) или Название (Name) либо в поле Фильтр по странам... (Filter by country...) под заголовком Результат теста.

После этого в списке остаются только профили, содержащие этот текст; регистр не учитывается. В поле Адрес запрос port=443 показывает профили на порту 443, а port=1000:2000 — профили на портах от 1000 до 2000. Один конец диапазона можно не указывать, например port=8000:. Поле страны сравнивается с кодом страны из теста IP или теста скорости, например DE. Нажмите Ctrl+F ещё раз, чтобы скрыть поля; при этом они также очищаются.

Очистка

Начиная с 1.4.0, эти команды находятся в меню Группы → Очистка (Clean up). То же подменю появляется, если щёлкнуть правой кнопкой мыши вкладку текущей группы. Команды действуют на текущую группу.

Команда Сочетание клавиш Что удаляет
Удалить дубликаты (Remove Duplicates) Ctrl+Shift+D Профили, которые являются точными копиями более раннего профиля, включая название. Первая копия остаётся.
Удалить недоступные (Remove Unavailable) Ctrl+Shift+R Профили, последний тест которых не пройден. Запущенный профиль никогда не удаляется.
Удалить недействительные (Remove Invalid) Ctrl+Alt+I Профили, которые ядро отклоняет как недействительные.
Удалить небезопасные конфигурации (Remove Insecure Configs) – Профили, трафик которых недостаточно защищён: без шифрования, с TLS без проверки сертификатов или со старыми шифрами Shadowsocks.
Очистить результат теста для группы (Clear Group test result) Ctrl+Shift+C Только результаты тестов. Профили остаются. Эта команда находится прямо в меню Группы.

Перед удалением Throne запрашивает подтверждение, если не включён параметр Настройки → Основные настройки → Интерфейс (Style) → Не запрашивать подтверждение при удалении профилей (Skip confirmation When Deleting Profiles). Если Удалить дубликаты, Удалить недействительные или Удалить небезопасные конфигурации удаляет запущенный профиль, Throne его останавливает.

Чтобы увидеть, какие профили считаются небезопасными, включите Настройки → Основные настройки → Интерфейс → Отображать безопасность конфигураций (Show Config Security; только в расширенном режиме, см. Простой и расширенный режим). Тогда в столбце Тип отображается уровень безопасности каждого профиля, а небезопасные профили помечаются предупреждающим значком.

Автоматическая очистка:

  • Параметр группы Автоочистка недоступных профилей (Auto Clear Unavailable Profiles) удаляет профили, не прошедшие тест, после каждого теста задержки группы, не спрашивая подтверждения. См. Параметры группы.
  • Группа подписки может удалять дубликаты, небезопасные, недействительные и не прошедшие тест профили после каждого обновления. См. После каждого обновления.

Автовыбор

Автовыбор — это особый профиль. После запуска он выбирает лучший рабочий профиль из одной или нескольких групп, продолжает проверять остальные и переключается, когда текущий профиль начинает работать хуже или отказывает. Новые серверы из обновления подписки сами добавляются в него.

Чтобы создать автовыбор:

  1. Выберите вкладку группы, которую он должен использовать.
  2. Выберите Программа (Program) → Новый профиль (New profile, Ctrl+N). Откроется редактор, в котором в поле Тип (Type) уже выбран Автовыбор (Auto Selector).
  3. Введите Название (Name).
  4. В поле Серверы из (Servers from) отметьте группы, из которых автовыбор выбирает профили. Текущая группа уже отмечена.
  5. Нажмите OK, затем запустите новый профиль, как любой другой.

Редактор показывает сводку того, что произойдёт, например сколько профилей в отмеченных группах можно использовать. Основные параметры:

Параметр По умолчанию Назначение
Серверы из (Servers from) текущая группа Группы, профили которых использует автовыбор. Начиная с 1.4.0, это список ваших групп, и отметить можно несколько; их профили ранжируются вместе. Должна быть отмечена хотя бы одна группа. Архивные группы видны в списке, только пока они отмечены.
Фильтр по названию (Only names matching) пусто Необязательное регулярное выражение. Используются только профили, название которых ему соответствует, — например, чтобы выбрать одну страну или одного провайдера. Регистр не учитывается.
Распределить трафик между лучшими профилями (Share traffic between the best profiles) выкл. Выкл.: весь трафик идёт через один профиль, а остальные готовые профили находятся в резерве. Вкл.: трафик распределяется между рабочими профилями; см. Балансировка нагрузки (Load balancing) ниже.
Предпочтительный профиль (Preferred profile) – Появляется, только если вы выбрали профиль кнопкой Использовать этот профиль (Use this profile) в окне статистики. Использовать автовыбор (Use automatic) возвращает выбор автовыбору.

Каждый профиль работает так, как если бы вы запустили его отдельно: через Фронт-прокси (Front Proxy) и Выходной прокси (Landing Proxy) своей группы. Эти прокси группы, в которой находится сам автовыбор, не применяются. Столбец Адрес (Address) автовыбора показывает названия его групп. Если отмеченную группу удалить, сводка сообщит об этом, а при следующем сохранении группа исчезнет из списка.

Дополнительно… (Advanced…) показывает дополнительные параметры в разделах Какие профили использовать (Which profiles to use), Проверка доступности (Health checks), Переключение (Switching), Балансировка нагрузки и Адреса для проверки (Test endpoints). У всех параметров есть рабочие значения по умолчанию.

Параметр По умолчанию Назначение
Только страны (Only countries) пусто Коды стран через запятую, например DE,NL,FR. Используется страна, которую для каждого профиля нашёл тест IP или тест скорости, поэтому, пока параметр задан, профили без страны пропускаются. Определение выхода запущенного профиля не учитывается.
Запускать лучших (Run the best) 300 профилей Сколько профилей загружается в работающую конфигурацию. Автовыбор переключается между ними без переподключения.
Ранжировать не более (Rank at most) 1000 профилей Сколько профилей измеряется и хранится в рейтинге. Замены берутся из этого списка.
Срок доверия к результатам (Trust results for) 1440 мин Результаты тестов задержки не старше этого срока используются повторно вместо нового тестирования. 0 означает, что тест всегда выполняется заново.
Пропускать профили, не прошедшие тест (Skip failed profiles) вкл. Исключает профили, последний тест которых не пройден, пока этот результат считается достоверным.
Держать наготове (Keep ready) 3 профиля Сколько профилей постоянно подтверждены как рабочие, чтобы сразу подменить отказавший.
Часто проверять (Check closely) 8 профилей Сколько лучших профилей проверяется через каждый Интервал проверки (Check interval).
Интервал проверки (Check interval) 300 сек Как часто измеряются профили под тщательной проверкой.
Полный проход каждые (Full sweep every) 600 сек Сколько длится один проход по всем запущенным профилям.
Мониторинг текущего профиля (Watch profile in use) 15 сек Как часто отдельно проверяется профиль, через который идёт ваш трафик.
Число хранимых замеров (Samples kept) 10 Сколько последних проверок учитывается в рейтинге для средней задержки и джиттера.
Порог переключения (Switch tolerance) 300 мс Другой профиль должен быть быстрее как минимум на эту величину, чтобы автовыбор переключился на него.
Максимальная задержка (Maximum latency) без ограничений Профили медленнее этого значения никогда не выбираются.
Кол-во попыток при сбое (Failover attempts) 2 Если выбранный профиль не может подключиться, сколько других профилей сразу пробуется, прежде чем приложение получит ошибку.
Разрывать подключения при переключении (Drop connections on switch) вкл. Вкл.: после переключения из-за проблемы все соединения сразу переходят на новый профиль. Выкл.: начатые загрузки завершаются через старый профиль.
Режим (Mode; балансировка нагрузки) Переключение по таймеру (обеспечивает стабильность сеансов) (Rotate on a timer (keeps sessions stable)) Используется вместе с Распределить трафик между лучшими профилями. Другой режим — На каждое подключение (максимальное распределение) (Per connection (widest spread)): каждое новое подключение может пойти через другой профиль, и ваш выходной IP может меняться во время сеанса.
Переключать каждые (Rotate every) 30 сек Для режима по таймеру: сколько времени автовыбор остаётся на одном профиле, прежде чем новые подключения перейдут на следующий.
URL проверки (Test URL) пусто Адрес, по которому измеряются профили. Пустое значение означает глобальный URL теста задержки.
URL проверки связи (Connectivity URL) пусто Запрашивается без прокси, чтобы заметить, что подключение к интернету пропало. Пустое значение означает URL проверки Direct (Direct Test URL) из параметров тестов.

Как он работает:

  • Перед запуском он выполняет тест задержки для профилей, у которых нет результата новее срока Срок доверия к результатам, и ранжирует их. Затем загружает лучшие из них — столько, сколько задано в Запускать лучших, — в работающую конфигурацию. В логе появляются строки, начинающиеся с [Автовыбор] ([Auto selector]).
  • Если все запущенные профили не работают 20 секунд подряд, он пересобирается из следующих лучших профилей. Между повторными пересборками он ждёт всё дольше — от 60 секунд до 10 минут.
  • Если у компьютера нет подключения к сети, проверки приостанавливаются до его восстановления.

Пока автовыбор запущен, Утилиты → Статистика автовыбора (Auto Selector Stats) открывает окно его статистики. В таблице для каждого профиля показаны Профиль (Profile), Статус (Status), Задержка (Latency), Джиттер (Jitter), Проверки (Checks), Подключения (Connects), Последний успех (Last OK) и Примечания (Notes); Статус принимает значения Работает (Working), Нестабильный (Unstable), Не проверен (Not checked), Не работает (Failing) или Приостановлен (Paused). Флажок Показывать только профили с проблемами (Only show profiles with problems) скрывает рабочие профили. Кнопки:

  • Использовать этот профиль (Use this profile): использовать выбранный профиль вместо того, который выбрал рейтинг.
  • Вернуть автовыбор (Back to automatic): снова доверить выбор рейтингу.
  • Проверить все сейчас (Check all now): немедленно измерить все запущенные профили.

Ограничения:

  • Автовыбор не может быть звеном цепочки, а также Фронт-прокси (Front Proxy) или Выходной прокси (Landing Proxy) группы.
  • Он пропускает следующие профили своих групп: цепочки и другие профили автовыбора, OpenVPN и OpenConnect, Tailscale, дополнительное ядро (Extra Core), пользовательские полные конфигурации sing-box и пользовательские конфигурации, которые не удаётся прочитать. Полные конфигурации Xray пропускаются, если их нельзя совместить с фронт- или выходным прокси своей группы.

IP-сканер

Начиная с 1.4.0, Утилиты (Tools) → IP-сканер (IP Scanner) (только в расширенном режиме, см. Простой и расширенный режим) проверяет списки IP-адресов и оставляет те, что работают из вашей сети. Например, с его помощью можно найти незаблокированный адрес Cloudflare для профилей, серверы которых находятся за CDN, или рабочую конечную точку Cloudflare WARP. Результаты образуют IP-список, который группа или профиль могут использовать как адрес сервера.

В окне IP-сканер перечислены ваши сканирования с их состоянием и числом результатов. Наведите указатель на сканирование, чтобы запустить его, приостановить или возобновить, открыть или удалить. Перетаскивайте сканирования, чтобы изменить их порядок. Сканирование продолжается, если закрыть его окно.

Чтобы создать сканирование:

  1. Нажмите Новое сканирование (New scan) и введите Название (Name).
  2. Выберите Обычное сканирование (Generic scan), чтобы проверять адреса пингом, TCP, TLS или HTTP и при желании через один из ваших профилей. Выберите Сканирование WARP (WARP scan), чтобы искать конечные точки Cloudflare WARP, через которые устанавливается соединение WireGuard, AmneziaWG или MASQUE.
  3. Нажмите OK. Откроется окно сканирования.
  4. Задайте цели на вкладке Цели (Targets) и проверки на вкладке Этапы (Phases).
  5. Нажмите Запустить (Start). Окно показывает ход выполнения и последние строки лога, а вкладка Результаты (Results) заполняется.

Вкладка Цели:

Параметр По умолчанию Назначение
Исходный список IP (Base IP list) – Адреса для сканирования. Управление (Manage) открывает IP-списки. Сканирование WARP начинается со списка Cloudflare WARP (WireGuard), а Использовать встроенные диапазоны WARP (Use built-in WARP ranges) выбирает список и порты для выбранного режима WARP.
Порты (Ports) пусто; WARP: порты WireGuard Порты для сканирования через запятую или пробел. Список рядом определяет, как они сочетаются с портами, сохранёнными в IP-списке: Игнорировать порты списка (Ignore the list's ports), Объединить с портами списка (Merge with the list's ports) (по умолчанию) или Только порты списка (Only the list's ports). Адреса, оставшиеся без порта, сканируются на порту 443, а для обычного HTTP — на порту 80. При сканировании WARP кнопка Порты WARP (WARP ports) подставляет порты конечных точек Cloudflare.
Перемешивать порядок целей (Shuffle the target order) вкл. Сканирует адреса в случайном порядке.
Сканировать адреса IPv6 (Scan IPv6 addresses) выкл. Если выключено, диапазоны IPv6 из списка пропускаются.
Лимит результатов (Stop after (results)) без ограничения; WARP: 10 Сканирование завершается, когда набирает столько результатов.
Кол-во потоков (Concurrency) 64; WARP: 16 Сколько адресов проверяется одновременно на каждом этапе.
Интервал запуска (мс) (Spawn interval (ms)) 2 Задержка между запуском двух проверок.

На вкладке Этапы находятся проверки. Адрес должен пройти все включённые проверки в таком порядке:

Этап По умолчанию Что проверяет
ICMP (ping) выкл. Адрес отвечает на пинг.
TCP-подключение (TCP connect) вкл. Порт принимает TCP-соединение. Только для Обычное сканирование.
TLS / HTTP выкл. Рукопожатие TLS проходит успешно, и, если Метод (Method) не равен Нет (только хендшейк TLS) (None (TLS handshake only)), на HTTP-запрос приходит ответ 200 OK. Можно задать SNI, Заголовок Host (Host header), Path, Версия HTTP (HTTP version), версии TLS, uTLS fingerprint и фрагментацию TLS. Только для Обычное сканирование.
Тест конфигурации (Config test) выкл. Копия профиля, выбранного в поле Профиль (Profile), направленная на этот адрес, загружает URL проверки (Test URL). Так находятся адреса, которые действительно работают с вашим сервером, например адреса CDN. Только для Обычное сканирование.
Тест WARP (WARP test) вкл. Соединение WARP через этот адрес работает в режиме, выбранном в поле Режим (Mode): WireGuard, AmneziaWG или MASQUE. Только для Сканирование WARP.

Для Тест WARP нужна учётная запись WARP — Идентификатор (Identity). Вариант по умолчанию, Отдельный для этого сканирования (рекомендуется) (Dedicated for this scan (recommended)), требует одного нажатия Зарегистрировать (Register): так в Cloudflare регистрируется новое устройство WARP. Можно также выбрать Из профиля (From a profile) или Встроенные настройки WARP (Built-in WARP settings).

Вкладка Результаты показывает каждый адрес с его портом и задержкой (столбцы Порт (Port) и Задержка (Latency)). Щёлкните заголовок столбца, чтобы отсортировать. Кнопки:

  • Сохранить как список IP (Save as IP list): копирует результаты в новый IP-список.
  • Копировать (Copy): копирует выбранные записи или все записи, если ничего не выбрано.
  • Экспорт (Export): сохраняет результаты в текстовый файл.
  • Удалить выбранные (Remove selected): удаляет выбранные записи.

Если у сканирования уже есть результаты, Запустить спрашивает, что делать. Сканировать с начала (Scan from the beginning) очищает результаты и снова сканирует базовый список. Перепроверить текущие результаты (Rescan current results) проверяет заново только результаты и удаляет те, что перестали работать. Приостановить (Pause) сохраняет ход выполнения, и Продолжить (Resume) продолжает его позже. Если изменить цели приостановленного сканирования, его можно запустить только с начала. Пока сканирование идёт, его параметры менять нельзя.

IP-списки

Нажмите Списки IP (IP Lists) в окне IP-сканер, чтобы управлять списками, которые читают сканирования и которые могут использовать группы и профили. Сразу есть пять списков: Cloudflare CDN, Fastly CDN, Gcore CDN, Cloudflare WARP (WireGuard) и Cloudflare WARP (MASQUE). Если вы их удалите, Импорт (Import) → Добавить списки по умолчанию (Add default lists) добавит их снова.

  • Создать (New) создаёт список. Его Источник (Source) — Вручную (Manual) (записи пишете вы), URL (адрес http или https, который загружает Throne) или Набор правил (Rule-set) (диапазоны IP набора правил, например geoip-ir, или URL набора правил). Для списка URL или Набор правил кнопка Загрузить сейчас (Fetch now) загружает его сразу, а Автообновление (Auto update) → Включить (Enable) обновляет его через заданное в Каждые (Every) число минут, не меньше 30.
  • Пишите по одной записи на строку, например 1.2.3.4, 1.2.3.0/24, 1.2.3.4:443, [2606:4700::1]:443, 1.2.3.0/24 443 или 1.2.3.1-1.2.3.9.
  • Импорт создаёт списки Из текста… (From text…), Из файла… (From file…) (текстовые и CSV-файлы или наборы правил sing-box, до 50 МБ каждый), По URL… (From URL…) или Из набора правил… (From rule-set…).
  • Дублировать (Duplicate) копирует список, а Экспорт сохраняет его в текстовый файл.

Результаты каждого сканирования тоже образуют список с пометкой «Результат сканирования» (Result of scan) и названием сканирования. Группа или профиль могут использовать его напрямую, но Сканировать с начала его очищает; для списка, который не меняется, используйте Сохранить как список IP. При удалении сканирования вы выбираете, удалять ли вместе с ним и его список результатов.

На Android

В Throne для Android те же тесты и тот же автовыбор.

  • На экране Конфигурация (Profiles) в меню ⋮ есть пункты URL-тест (URL test), Тест IP и страны (IP & country test), Тест скорости (Speed test), Тест скорости текущего соединения (Speed test current connection) (в 2.0.3; в версиях новее 2.0.3 он находится в меню, которое открывается долгим нажатием на полосу внизу экрана) и Остановить тест (Stop testing) для текущей группы. Там же есть Очистить результаты теста (Clear test results), Удалить (Remove) с пунктами Дубликаты (Duplicates), Недоступные (Unavailable), Недействительные (Invalid) и Небезопасные конфигурации (Insecure configs), а также Сортировка (Sort). Для выбранных профилей используйте Тест (Test) в меню выделения.
  • Перед тестом скорости нескольких профилей приложение запрашивает подтверждение: «Speed testing can use significant data.» (тест скорости может израсходовать много трафика).
  • Панель тестирования показывает ход выполнения, счётчики Работает (Working), Неудачно (Failed), Ожидание (Pending) и Пропущено (Skipped), диаграмму задержек (≤100 ms, ≤300 ms, >300 ms, fail), самый быстрый профиль, страны и число различных выходных IP. На ней также есть действия, например Сортировать по задержке (Sort by latency) или Сортировать по скорости (Sort by speed), Удалить недоступные (Remove unavailable) (с числом профилей, не прошедших тест), Подключиться к самому быстрому (Connect to fastest) (Выбрать самый быстрый (Select fastest), если вы не подключены) и Скрыть результаты теста (Dismiss test results).
  • Пока подключение активно, нажмите на панель статистики с надписью «Подключено, нажмите для проверки подключения» (Connected, tap to check connection), чтобы проверить текущее подключение. Результат выглядит как «HTTP-соединение установлено за 120 мс» (Success: HTTP handshake took 120ms) или «Ошибка: …» (Failed: …). Начиная с 2.0.3 результат выглядит как «HTTPS: 120 мс» или «HTTP: 120 мс».
  • Начиная с 2.0.2, на панели статистики также показывается выходной IP-адрес подключения с флагом страны, а в портретной ориентации — страна и город. В 2.0.2 нажмите на панель и удерживайте, чтобы увидеть их полностью. После подключения и после каждого нажатия на панель Throne через прокси обращается к сервису определения IP; в 2.0.2 это всегда ip-api.com. Начиная с 2.0.3 панель показывает только флаг и страну, а долгое нажатие на панель вместо этого открывает Графики в реальном времени (Live graphs) (после 2.0.3 — меню с пунктами Графики в реальном времени и Тест скорости текущего соединения).
  • Начиная с 2.0.3 в Настройки (Settings) → Тестирование (Testing), в разделе Exit country, есть Look up exit country (по умолчанию включено) и Lookup service с теми же сервисами, что и на компьютере. Если определение выключено, панель не показывает страну. В 2.0.3 Automatic опрашивает ip-api.com, ipwho.is, ipinfo.io и Cloudflare в этом порядке; после 2.0.3 он, как на компьютере, сначала опрашивает IP2Location.io.
  • В Throne для Android нет IP-сканера. Начиная с 2.0.3 сортировка, выбранная в Сортировка (Sort), сохраняется, как на компьютере, а Ручной порядок (Manual order) её отменяет.
  • Чтобы создать автовыбор, выберите Добавить профиль (Add profile) → Ручные настройки (Manual settings) → Автовыбор (Auto selector). Параметры и значения по умолчанию те же, что и в версии для компьютера, а их английские названия написаны с одной заглавной буквой, например Серверы из (Servers from), Только совпадающие имена (Only names matching) и Запускать лучших (Run the best). Начиная с 2.0.3 Серверы из открывает список, в котором можно отметить одну или несколько групп. Нажмите на строку состояния автовыбора на экране Конфигурация, чтобы открыть Статистика автовыбор (Auto selector stats) с кнопками Использовать этот профиль (Use this profile), Вернуть к автоматическому (Back to automatic) и Проверить все сейчас (Check all now).
