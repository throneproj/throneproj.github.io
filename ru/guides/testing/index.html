Тестирование и автовыбор

Как проверять профили на задержку, выходной IP и скорость, сортировать и фильтровать список, удалять нерабочие профили и поручить автовыбору поиск лучшего сервера.

Throne умеет тестировать ваши профили и помогает оставить только хорошие. На этой странице описаны тест задержки, тест IP и страны и тест скорости, сортировка и фильтрация, очистка списка, а также автовыбор, который сам подбирает для вас лучший сервер.

Тесты не останавливают запущенный профиль. Профили автовыбора тесты пропускают — вместо этого тестируйте группу, которую использует автовыбор.

Тест задержки

Тест задержки проверяет, что профиль работает, и измеряет его задержку. Throne дважды запрашивает URL теста задержки (Latency Test URL) через профиль и показывает, сколько миллисекунд занял второй запрос.

Чтобы запустить тест задержки:

  • Выбранные профили: щёлкните их правой кнопкой мыши и выберите Тест задержки выбранного профиля (Url Test Selected, Ctrl+Shift+S).
  • Вся группа: выберите Группы (Groups) → Тест задержки всей группы (Url Test Group, Ctrl+Shift+G) или щёлкните вкладку группы правой кнопкой мыши и выберите Тест задержки выбранной группы (Url Test selected Group).
  • Запущенный профиль: щёлкните имя профиля в левой части строки состояния. Throne один раз проверит текущее подключение и покажет в строке состояния Результат теста: (Test Result:) со временем или Недоступен (Unavailable).

Пока идёт тест, в контекстном меню и в меню Группы появляется пункт Остановить тестирование (Stop Testing, Ctrl+.).

В столбце Результат теста (Test Result) отображается одно из следующих значений:

Результат Значение
Время, например 85 ms Профиль работает. Время отображается зелёным до 100 мс, жёлтым до 300 мс и красным при большем значении.
Недоступен (Unavailable) Тест не пройден. В логе есть строка с ошибка теста (test error) и причиной.
Подключение успешно (Connect OK) Профиль OpenVPN или OpenConnect подключился, но тестовый URL через него не ответил.

Параметры тестов находятся в Настройки (Settings) → Основные настройки (Basic Settings) → Общие (Common), в группе Проверка (Testing):

Параметр По умолчанию Назначение
URL теста задержки (Latency Test URL) http://cp.cloudflare.com/ Адрес, который Throne запрашивает через каждый профиль.
Таймаут (Timeout; рядом с Кол-во потоков) 3000 мс Ограничение времени для каждого запроса. Не делайте его слишком маленьким: профилям с мультиплексированием нужно больше времени на первый запрос, и при коротком таймауте они помечаются как нерабочие.
Кол-во потоков (Concurrency) 10 Сколько профилей тестируется одновременно.
Direct Test URL пусто Запрашивается без прокси, чтобы автовыбор мог отличить пропавшее подключение к интернету от нерабочих серверов. Укажите адрес, который открывается в вашей сети без прокси. Пустое значение означает, что Throne использует состояние сети, которое сообщает операционная система.

Чтобы скопировать результаты выбранных профилей, щёлкните их правой кнопкой мыши и выберите Поделиться (Share) → Копировать результат теста (Copy Test Result).

Тест IP и страны

Этот тест показывает выходной IP-адрес каждого профиля и его страну. Именно этот адрес видят сайты.

  • Выбранные профили: щёлкните их правой кнопкой мыши и выберите Разрешить выход. IP выбранных (Resolve Selected Out IP).
  • Вся группа: выберите Группы → Разрешить выход. IP для группы (Resolve out IP for group).

Throne запрашивает https://api.ip2location.io/ через каждый профиль. После этого в столбце Результат теста отображается флаг страны, а также выходной IP, если включено отображение Выходной IP (Out IP) — см. Сортировка и фильтрация. Тест использует Таймаут и Кол-во потоков теста задержки.

Страна используется фильтром по странам и параметром автовыбора Только страны (Only countries). О сервисах, к которым обращается Throne, см. Конфиденциальность и сетевые запросы.

Тест скорости

Тест скорости измеряет скорость скачивания и отдачи через профиль.

  • Выбранные профили: щёлкните их правой кнопкой мыши и выберите Тест скорости выбранного профиля (Speedtest Selected, Ctrl+Shift+P).
  • Вся группа: выберите Группы → Тест скорости всей группы (Speedtest Group, Ctrl+Alt+P) или щёлкните вкладку группы правой кнопкой мыши и выберите Тест скорости выбранной группы (Speed Test selected Group).
  • Текущее подключение: пока профиль запущен, выберите Утилиты (Tools) → Тест скорости текущего профиля (Speedtest Current, F6).

Throne тестирует профили по одному. Затем в столбце Результат теста отображается скорость скачивания после ↓ и скорость отдачи после ↑, если включено отображение Скорость (Speed).

Что именно делает тест, выбирается в Настройки → Основные настройки → Общие → Режим проверки скорости (Speedtest mode):

Режим Что делает
Скачивание (↓) + загрузка (↑) (Download + Upload; по умолчанию) Находит ближайший сервер Speedtest, затем измеряет скорость скачивания и отдачи.
Только скачивание (↓) (Only Download) Измеряет только скорость скачивания.
Только загрузка (↑) (Only Upload) Измеряет только скорость отдачи.
Простое скачивание (Simple Download) Скачивает файл по адресу из URL для простого теста скачивания (Simple Download URL), по умолчанию http://cachefly.cachefly.net/1mb.test. Поиск сервера не выполняется.
Только проверка страны (Only Country) Только находит ближайший сервер Speedtest и показывает его страну. Работает быстро, почти не расходует трафик и тестирует много профилей одновременно.

Таймаут рядом с параметром Режим проверки скорости (по умолчанию 5000 мс) ограничивает каждую часть теста.

Предупреждение

Тест скорости передаёт столько данных, сколько успеет до истечения таймаута, — и так для каждого профиля. Тестирование большой группы может израсходовать много трафика, что важно, если в вашем тарифе есть лимит. Этот трафик учитывается в столбце Трафик (Traffic) каждого профиля.

Сортировка и фильтрация

Чтобы отсортировать профили группы:

  • Щёлкните заголовок столбца, чтобы отсортировать по нему. Щёлкните ещё раз, чтобы изменить порядок на обратный. Throne сохраняет новый порядок.
  • При сортировке по задержке первым щелчком самые быстрые профили оказываются вверху. За ними следуют профили, не прошедшие тест, а непротестированные — в самом конце.
  • Щёлкните заголовок Результат теста правой кнопкой мыши, чтобы выбрать, что показывает столбец (Включить: (Include:) Выходной IP, Скорость), и по чему он сортируется (Сортировать по: (Sort By:) Пингу (задержке) (Latency), Скорости скачивания (↓) (Download Speed), Скорости загрузки (↑) (Upload Speed), Выходному IP (IP Out)).
  • Щёлкните заголовок Трафик правой кнопкой мыши, чтобы отсортировать по значению Всего (Total), Получено (↓) (Downloaded) или Отправлено (↑) (Uploaded).
  • Перетаскивайте строки, чтобы расположить их в любом порядке. Пока включён фильтр, это не работает.

Обновление подписки возвращает профилям порядок, заданный провайдером. Чтобы группа подписки сортировалась после каждого обновления, используйте её параметр Sort by latency; см. После каждого обновления.

Чтобы отфильтровать список:

  1. Нажмите Ctrl+F или кнопку фильтра у правого края панели вкладок групп.
  2. Введите текст в поле под заголовком Тип (Type), Адрес (Address) или Название (Name) либо в поле Фильтр по странам... (Filter by country...) под заголовком Результат теста.

После этого в списке остаются только профили, содержащие этот текст; регистр не учитывается. В поле Адрес запрос port=443 показывает профили на порту 443, а port=1000:2000 — профили на портах от 1000 до 2000. Один конец диапазона можно не указывать, например port=8000:. Поле страны сравнивается с кодом страны из теста IP или теста скорости, например DE. Нажмите Ctrl+F ещё раз, чтобы скрыть поля; при этом они также очищаются.

Очистка

Эти команды находятся в меню Группы. Они действуют на текущую группу.

Команда Сочетание клавиш Что удаляет
Удалить дубликаты (Remove Duplicates) Ctrl+Shift+D Профили, которые являются точными копиями более раннего профиля, включая название. Первая копия остаётся.
Удалить недоступные (Remove Unavailable) Ctrl+Shift+R Профили, последний тест которых не пройден. Запущенный профиль никогда не удаляется.
Удалить недействительные (Remove Invalid) Ctrl+Alt+I Профили, которые ядро отклоняет как недействительные.
Удалить небезопасные конфигурации (Remove Insecure Configs) – Профили, трафик которых недостаточно защищён: без шифрования, с TLS без проверки сертификатов или со старыми шифрами Shadowsocks.
Очистить результат теста для группы (Clear Group test result) Ctrl+Shift+C Только результаты тестов. Профили остаются.

Перед удалением Throne запрашивает подтверждение, если не включён параметр Настройки → Основные настройки → Интерфейс (Style) → Пропустить подтверждение при удалении профилей (Skip confirmation When Deleting Profiles). Если Удалить дубликаты, Удалить недействительные или Удалить небезопасные конфигурации удаляет запущенный профиль, Throne его останавливает.

Чтобы увидеть, какие профили считаются небезопасными, включите Настройки → Основные настройки → Интерфейс → Отображать безопасность конфигураций (Show Config Security). Тогда в столбце Тип отображается уровень безопасности каждого профиля, а небезопасные профили помечаются предупреждающим значком.

Автоматическая очистка:

  • Параметр группы Автоочистка недоступных профилей (Auto Clear Unavailable Profiles) удаляет профили, не прошедшие тест, после каждого теста задержки группы, не спрашивая подтверждения. См. Параметры группы.
  • Группа подписки может удалять дубликаты, небезопасные, недействительные и не прошедшие тест профили после каждого обновления. См. После каждого обновления.

Автовыбор

Автовыбор — это особый профиль. После запуска он выбирает лучший рабочий профиль из одной группы, продолжает проверять остальные и переключается, когда текущий профиль начинает работать хуже или отказывает. Новые серверы из обновления подписки сами добавляются в него.

Чтобы создать автовыбор:

  1. Выберите вкладку группы, которую он должен использовать.
  2. Выберите Программа (Program) → Новый профиль (New profile, Ctrl+N). Откроется редактор, в котором в поле Тип (Type) уже выбран Автовыбор (Auto Selector).
  3. Введите Название (Name).
  4. Проверьте поле Серверы из (Servers from). Это группа, из которой автовыбор выбирает профили.
  5. Нажмите OK, затем запустите новый профиль, как любой другой.

Редактор показывает сводку того, что произойдёт, например сколько профилей группы можно использовать. Основные параметры:

Параметр По умолчанию Назначение
Серверы из (Servers from) текущая группа Группа, профили которой использует автовыбор.
Только соответствующие названия (Only names matching) пусто Необязательное регулярное выражение. Используются только профили, название которых ему соответствует, — например, чтобы выбрать одну страну или одного провайдера. Регистр не учитывается.
Распределить трафик между лучшими профилями (Share traffic between the best profiles) выкл. Выкл.: весь трафик идёт через один профиль, а остальные готовые профили находятся в резерве. Вкл.: трафик распределяется между рабочими профилями; см. Балансировка нагрузки (Load balancing) ниже.
Предпочтительный профиль (Preferred profile) – Появляется, только если вы выбрали профиль кнопкой Использовать этот профиль (Use this profile) в окне статистики. Использовать автовыбор (Use automatic) возвращает выбор автовыбору.

Дополнительно… (Advanced…) показывает дополнительные параметры в разделах Какие профили использовать (Which profiles to use), Проверка доступности (Health checks), Переключение (Switching), Балансировка нагрузки и Конечные точки тестирования (Test endpoints). У всех параметров есть рабочие значения по умолчанию.

Параметр По умолчанию Назначение
Только страны (Only countries) пусто Коды стран через запятую, например DE,NL,FR. Используется страна из теста IP, поэтому, пока параметр задан, профили, для которых тест IP ни разу не выполнялся, пропускаются.
Запустить лучших (Run the best) 300 профилей Сколько профилей загружается в работающую конфигурацию. Автовыбор переключается между ними без переподключения.
Ранжировать только (Rank at most) 1000 профилей Сколько профилей измеряется и хранится в рейтинге. Замены берутся из этого списка.
Верить тестам на (Trust results for) 1440 мин Результаты тестов задержки не старше этого срока используются повторно вместо нового тестирования. 0 означает, что тест всегда выполняется заново.
Пропускать неудачные профили (Skip failed profiles) вкл. Исключает профили, последний тест которых не пройден, пока этот результат считается достоверным.
Держать наготове (Keep ready) 3 профиля Сколько профилей постоянно подтверждены как рабочие, чтобы сразу подменить отказавший.
Тщательная проверка (Check closely) 8 профилей Сколько лучших профилей проверяется через каждый Интервал проверки (Check interval).
Интервал проверки (Check interval) 300 сек Как часто измеряются профили под тщательной проверкой.
Полный проход каждые (Full sweep every) 600 сек Сколько длится один проход по всем запущенным профилям.
Мониторинг текущего профиля (Watch profile in use) 15 сек Как часто отдельно проверяется профиль, через который идёт ваш трафик.
Сохраненные тесты (Samples kept) 10 Сколько последних проверок учитывается в рейтинге для средней задержки и джиттера.
Толерантность (Switch tolerance) 300 мс Другой профиль должен быть быстрее как минимум на эту величину, чтобы автовыбор переключился на него.
Максимальная задержка (Maximum latency) без ограничений Профили медленнее этого значения никогда не выбираются.
Кол-во попыток при сбое (Failover attempts) 2 Если выбранный профиль не может подключиться, сколько других профилей сразу пробуется, прежде чем приложение получит ошибку.
Разрыв соединений при переключении (Drop connections on switch) вкл. Вкл.: после переключения из-за проблемы все соединения сразу переходят на новый профиль. Выкл.: начатые загрузки завершаются через старый профиль.
Режим (Mode; балансировка нагрузки) Переключение по таймеру (обеспечивает стабильность сеансов) (Rotate on a timer (keeps sessions stable)) Используется вместе с Распределить трафик между лучшими профилями. Другой режим — На каждое подключение (наибольший диапазон) (Per connection (widest spread)): каждое новое подключение может пойти через другой профиль, и ваш выходной IP может меняться во время сеанса.
Переключать каждые (Rotate every) 30 сек Для режима по таймеру: сколько времени автовыбор остаётся на одном профиле, прежде чем новые подключения перейдут на следующий.
URL проверки (Test URL) пусто Адрес, по которому измеряются профили. Пустое значение означает глобальный URL теста задержки.
URL для подключения (Connectivity URL) пусто Запрашивается без прокси, чтобы заметить, что подключение к интернету пропало. Пустое значение означает Direct Test URL из параметров тестов.

Как он работает:

  • Перед запуском он выполняет тест задержки для профилей, у которых нет результата новее срока Верить тестам на, и ранжирует их. Затем загружает лучшие из них — столько, сколько задано в Запустить лучших, — в работающую конфигурацию. В логе появляются строки, начинающиеся с [Автовыбор] ([Auto selector]).
  • Если все запущенные профили не работают 20 секунд подряд, он пересобирается из следующих лучших профилей. Между повторными пересборками он ждёт всё дольше — от 60 секунд до 10 минут.
  • Если у компьютера нет подключения к сети, проверки приостанавливаются до его восстановления.

Пока автовыбор запущен, Утилиты → Статистика автовыбора (Auto Selector Stats) открывает окно его статистики. В таблице для каждого профиля показаны Профиль (Profile), Статус (Status), Задержка (Latency), Джиттер (Jitter), Проверки (Checks), Подключения (Connects), Последний ОК (Last OK) и Примечания (Notes); Статус принимает значения Работает (Working), Нестабильный (Unstable), Не проверено (Not checked), Неудачный (Failing) или Приостановленный (Paused). Флажок Показывать только профили с проблемами (Only show profiles with problems) скрывает рабочие профили. Кнопки:

  • Использовать этот профиль (Use this profile): использовать выбранный профиль вместо того, который выбрал рейтинг.
  • Вернуть автовыбор (Back to automatic): снова доверить выбор рейтингу.
  • Проверить все сейчас (Check all now): немедленно измерить все запущенные профили.

Ограничения:

  • Автовыбор не может быть звеном цепочки, а также Фронт-прокси (Front Proxy) или Выходной прокси (Landing Proxy) группы.
  • Он пропускает следующие профили группы: цепочки и другие профили автовыбора, OpenVPN и OpenConnect, Tailscale, дополнительное ядро (Extra Core), пользовательские полные конфигурации sing-box и пользовательские конфигурации, которые не удаётся прочитать. Полные конфигурации Xray пропускаются, если их нельзя совместить с фронт- или выходным прокси группы.

На Android

В Throne для Android те же тесты и тот же автовыбор.

  • На экране Конфигурация (Profiles) в меню ⋮ есть пункты URL test, IP & country test, Speed test, Speed test current connection и Stop testing для текущей группы. Там же есть Очистить результаты теста (Clear test results), Remove (Duplicates, Unavailable, Invalid, Insecure configs) и Sort. Для выбранных профилей используйте Test в меню выделения.
  • Перед тестом скорости нескольких профилей приложение запрашивает подтверждение: «Speed testing can use significant data.» (тест скорости может израсходовать много трафика).
  • Панель тестирования показывает ход выполнения, счётчики Working, Failed, Pending и Skipped, диаграмму задержек (≤100 ms, ≤300 ms, >300 ms, fail), самый быстрый профиль, страны и число различных выходных IP. На ней также есть действия, например Sort by latency или Sort by speed, Remove unavailable (с числом профилей, не прошедших тест), Connect to fastest (Select fastest, если вы не подключены) и Dismiss test results.
  • Пока подключение активно, нажмите на панель статистики с надписью «Подключено, нажмите для проверки подключения» (Connected, tap to check connection), чтобы проверить текущее подключение. Результат выглядит как «HTTP-соединение установлено за 120 мс» (Success: HTTP handshake took 120ms) или «Ошибка: …» (Failed: …).
  • Чтобы создать автовыбор, выберите Добавить профиль (Add profile) → Ручные настройки (Manual settings) → Auto selector. Параметры и значения по умолчанию те же, что и в версии для компьютера, а их названия написаны с одной заглавной буквой, например Servers from, Only names matching и Run the best. Нажмите на строку состояния автовыбора на экране Конфигурация, чтобы открыть Auto selector stats с кнопками Use this profile, Back to automatic и Check all now.
