Цепочки прокси и пользовательские конфигурации

Как связать несколько профилей в цепочку, добавить группе фронт-прокси и выходной прокси, написать JSON для sing-box или Xray вручную и запустить другую прокси-программу как дополнительное ядро.

Эта страница пригодится, когда одного сервера недостаточно или когда профилю нужны параметры, которых нет в обычных редакторах. Здесь описаны цепочки прокси, фронт-прокси и выходные прокси для групп, пользовательские JSON-конфигурации и профили дополнительного ядра (Extra Core).

Цепочки прокси

Профиль-цепочка пропускает ваш трафик через несколько профилей по очереди. Каждый сервер видит только предыдущий сервер, а последний подключается к сайту.

Создание цепочки

  1. Откройте Программа (Program) → Новый профиль (New profile) или нажмите Ctrl+N.
  2. Установите Тип (Type) в значение Цепочка прокси (Chain Proxy) и введите Название (Name).
  3. Нажмите Выбор профиля (Select Profile). Редактор скроется, а главное окно перейдёт в режим выбора.
  4. Дважды щёлкните профиль для следующего звена или выделите его и нажмите Enter. Редактор вернётся, и профиль будет добавлен.
  5. Повторите шаги 3 и 4 для каждого звена.
  6. Перетаскиванием расставьте строки в нужном порядке. Кнопки в каждой строке заменяют или удаляют это звено.
  7. Нажмите OK.

Режим выбора завершается только после выбора профиля. Если вы выбрали не тот профиль, удалите его кнопкой в его строке.

Порядок звеньев

В редакторе написано «Порядок трафика — сверху вниз» (Traffic order is from top to bottom). Сначала ваше устройство подключается к верхнему профилю. Затем трафик проходит через каждый профиль ниже, а нижний профиль подключается к сайту. Сайты видят адрес нижнего профиля.

Если сверху A, а под ним B, трафик идёт так: ваше устройство → A → B → интернет.

Правила и ограничения

  • Цепочка не может содержать другую цепочку.
  • Профиль автовыбора не может быть звеном, потому что сам переключает серверы. Кроме того, автовыбор пропускает профили-цепочки.
  • Профили Польз. (sing-box конфигурация) (Custom (sing-box config)) не могут быть звеньями. Профили Польз. (sing-box outbound) (Custom (sing-box outbound)) и Польз. (Xray outbound) (Custom (Xray outbound)) — могут.
  • Цепочка может содержать один профиль Доп. ядро (Extra Core), и он должен быть верхним звеном. В предупреждении Throne он назван «последним звеном» (final hop): имеется в виду звено, к которому ваше устройство подключается первым.
  • Цепочка может содержать один профиль Польз. (Xray конфигурация) (Custom (Xray config)). Он тоже должен быть верхним звеном, и его нельзя сочетать с профилем Доп. ядро или с другими звеньями Xray.
  • Все звенья Xray должны идти подряд: звенья sing-box, затем звенья Xray, затем снова звенья sing-box. См. Xray в цепочках.
  • Тесты задержки (URL test) пропускают цепочки, в которых есть профиль Доп. ядро или Польз. (Xray конфигурация).

Часть правил Throne проверяет, когда вы добавляете звено или сохраняете цепочку, а остальные — при её запуске. Если проверка не пройдена, причина показывается в сообщении или в логе.

Цепочка также может быть outbound правила маршрутизации, если ни одно из её звеньев не является профилем Доп. ядро или профилем с полной конфигурацией.

Фронт-прокси и выходной прокси

Группа может добавить одно звено перед каждым своим профилем и одно звено после него. Это работает как цепочка, но создавать профили-цепочки не нужно.

  1. Щёлкните правой кнопкой мыши по вкладке группы и выберите Редактировать выбранную группу (Edit selected Group).
  2. Выберите Фронт-прокси (Front Proxy), Выходной прокси (Landing Proxy) или оба. Чтобы найти профиль среди всех профилей, введите часть его названия. None убирает звено.
  3. Нажмите OK.

Тогда трафик идёт так: ваше устройство → Фронт-прокси → запущенный вами профиль → Выходной прокси → интернет. Когда WARP включён, он идёт после выходного прокси.

  • Фронт-прокси помогает, когда серверы группы недоступны напрямую, но доступны через другой сервер.
  • С выходным прокси сайты видят один и тот же выходной сервер, какой бы профиль группы вы ни запустили.

Throne строит из этих звеньев цепочку, поэтому действуют ограничения цепочек. Например, фронт-прокси или выходной прокси не может быть профилем-цепочкой, а в группе с фронт-прокси нельзя запустить профиль Доп. ядро или Польз. (Xray конфигурация). Профили автовыбора в этих списках не предлагаются. Об остальных настройках группы см. Подписки и группы.

Пользовательские конфигурации

Пользовательский профиль содержит JSON для ядра в исходном виде. Используйте его для параметров, которых нет в обычных редакторах. Создайте его через Программа → Новый профиль, выбрав один из этих типов:

Тип Что вы вводите Столбец Тип
Польз. (sing-box outbound) Один outbound или endpoint sing-box Custom … Outbound
Польз. (sing-box конфигурация) Полная конфигурация sing-box Custom Config
Польз. (Xray outbound) Один outbound Xray Custom Xray … Outbound
Польз. (Xray конфигурация) Полная конфигурация Xray Custom Xray Config

Редактор JSON (Json Editor) открывает JSON в большом окне. Для двух типов sing-box он проверяет JSON по схеме sing-box и перечисляет ошибки. Форматирование JSON (Format) приводит текст в порядок.

Минимальный профиль Польз. (sing-box outbound):

{
  "type": "socks",
  "server": "203.0.113.10",
  "server_port": 1080
}

При импорте JSON:

  • Конфигурация sing-box с outbounds или endpoints разбивается на обычные профили — по одному на каждый поддерживаемый outbound. Отдельный объект outbound sing-box становится профилем Польз. (sing-box outbound).
  • В Xray JSON outbound типа VLESS становятся VLESS (Xray), а остальные outbound — Польз. (Xray outbound). JSON-список полных конфигураций Xray превращается в профили Польз. (Xray конфигурация), по одному на конфигурацию; Throne удаляет их inbound и добавляет свои.
  • Никакой импорт не создаёт Польз. (sing-box конфигурация). Этот тип создаётся только вручную.

Полные конфигурации

  • Польз. (sing-box конфигурация): Throne запускает вашу конфигурацию точно в том виде, в каком она написана. Он не добавляет свои inbound, TUN, профиль маршрутизации, настройки DNS, WARP, фронт-прокси и выходной прокси. Inbound должны быть в самой конфигурации.
  • Польз. (Xray конфигурация): Throne добавляет в вашу конфигурацию локальный SOCKS-inbound и ставит перед ним sing-box. Режим TUN, профиль маршрутизации и настройки DNS продолжают действовать. Внутри Xray outbound выбирает собственный раздел routing вашей конфигурации.

Полные конфигурации не могут быть outbound правила маршрутизации или конечной точкой профиля маршрутизации. Автовыбор может использовать профили Польз. (Xray конфигурация), каждый в собственном экземпляре Xray, но пропускает профили Польз. (sing-box конфигурация).

Дополнительное ядро (Extra Core)

Профиль Доп. ядро запускает на вашем компьютере другую прокси-программу и направляет в неё трафик. Используйте его для протокола, который Throne не поддерживает. Программа должна открыть локальный SOCKS-сервер; Throne подключается к нему как к любому SOCKS-прокси. Дополнительное ядро доступно только в версии для компьютера.

  1. Откройте Программа → Новый профиль.
  2. Установите Тип в значение Доп. ядро.
  3. Заполните поля, описанные ниже.
  4. Нажмите OK и запустите профиль.
Поле Назначение
Путь к ядру (Core path) Запускаемая программа. Кнопка Выбрать файл (Choose from file) позволяет её выбрать; Throne запоминает пути, выбранные ранее.
Аргументы (Args) Аргументы командной строки. Throne заменяет %s путём к временному файлу с текстом из поля Конфигурация (Config). Значения с пробелами заключайте в кавычки, как в командной оболочке.
Конфигурация Содержимое конфигурационного файла программы. Программа получает его, только если в поле Аргументы есть %s.
Адрес SOCKS (Socks address) Адрес SOCKS-сервера программы. По умолчанию 127.0.0.1.
Порт SOCKS (Socks port) Порт SOCKS-сервера программы. Он должен совпадать с конфигурацией программы и не должен совпадать с портом, который прослушивает сам Throne.
Не включать логирование (No logs) Скрывает вывод программы на вкладке Логи (Logs).

Например, если программа читает конфигурацию через -c <file>, укажите в поле Аргументы значение -c %s и вставьте конфигурацию в поле Конфигурация.

Как это работает:

  • Throne запускает программу, когда вы запускаете профиль, и останавливает её, когда вы останавливаете профиль. После этого временный файл конфигурации удаляется.
  • Вывод программы появляется на вкладке Логи в строках с Extra Core:, если не отмечен флажок Не включать логирование.
  • Если программа завершится сама, Throne остановит профиль («Extra Core exited, stopping profile...» — дополнительное ядро завершило работу, профиль останавливается).
  • Программа работает с обычными правами пользователя, даже если ядро Throne имеет права администратора или root для режима TUN.

Профиль Доп. ядро не может быть outbound правила маршрутизации. В цепочке он должен быть верхним звеном. Тесты задержки и автовыбор его пропускают.

Android

  • Цепочки прокси работают так же: Добавить профиль (Add profile) → Ручные настройки (Manual settings) → Прокси-цепочка (Proxy chain). Верхняя строка — первый сервер, к которому подключается ваше устройство, а нижняя — выход. Действуют те же ограничения.
  • У групп есть те же параметры Front proxy и Landing proxy.
  • У профиля Пользовательская конфигурация (Custom config) те же четыре типа (Config type), а редактор JSON проверяет его по схеме sing-box.
  • Профили дополнительного ядра есть только в версии для компьютера. Если такой профиль есть в резервной копии с компьютера, Android сохраняет его, но запустить не может.
