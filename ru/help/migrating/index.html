Переход с Nekoray / NekoBox

Где в Throne находятся функции Nekoray и NekoBox и как перенести серверы, подписки и настройки.

Throne — продолжение Nekoray, поэтому большая часть работает так же, но некоторые функции переместились или были заменены. На этой странице показано, где их найти и как перенести данные. Предыстория — в ответе Чем Throne отличается от Nekoray?

Где это теперь?

В Nekoray / NekoBox вы использовали… В Throne используйте…
Меню Сервер (Server) Щелчок правой кнопкой мыши по списку профилей. Строка меню скрыта.
Меню Настройки (Preferences) Кнопку Настройки (Settings) на панели инструментов: Основные настройки (Basic Settings), Настройки маршрутизации (Routing Settings), Настройки режима TUN (Tun Settings), Настройки горячих клавиш (Hotkey Settings) и другие.
Группы подписок Те же группы — под кнопкой Группы (Groups). Чтобы обновить группу, щёлкните правой кнопкой мыши по её вкладке → Обновить подписку (Update subscription).
Настройки TUN-режима (Tun Settings) → Пропускать процессы (Bypass Process Name) (программы, трафик которых идёт в обход туннеля) Правила processName: в поле Напрямую (Direct) вашего профиля маршрутизации, например processName:game.exe. Или щёлкните правой кнопкой мыши подключение на вкладке Подключения (Connections) → Append process "<name>" to → Direct.
Настройки TUN-режима → Режим белого списка (Whitelist mode) (через туннель идут только перечисленные программы) Профиль маршрутизации, в котором для Outbound по умолчанию (Default outbound) выбрано direct, а программы (processName:…) или сайты указаны в поле Прокси (Proxy).
Настройки TUN-режима → Пропускать CIDR (Bypass CIDR) Настройки режима TUN → Обход частного диапазона (Private Range Bypass) (диапазоны адресов, которые идут в обход туннеля) или правила ip: в поле Напрямую.
Пресет (Preset) маршрутизации для вашей страны Маршруты (Routing) → Скачать профили (Download Profiles) → China, Iran или Russia.
Outbound по-умолчанию (Default Outbound) со значением bypass или block Outbound по умолчанию со значением direct или block в профиле маршрутизации. block доступен начиная с 1.2.0.
Темы вроде FlatGray, LightBlue и BlackSoft Основные настройки → Интерфейс (Style) → Тема (Theme). Эти темы вернулись в версии 1.1.5.
Скопировать ссылки для выбранных (Neko links) (Copy links of selected (Neko Links)) Стандартные ссылки для обмена. Throne не умеет читать ссылки nekoray:// и sn://.
Перехват (Hijack) (его DNS-сервер и Настройки перенаправления (Redirect Settings)) или Системный DNS (System DNS) в Throne 1.3.1 и более ранних версиях Режим TUN (Tun Mode). Эти функции объявлены устаревшими в 1.3.1 и будут удалены в следующем релизе.
NekoBox for Android Throne для Android 2.0.0. См. ниже.

Для маршрутизации по приложениям включите Режим TUN (Tun Mode). Трафик приложений, которые игнорируют системный прокси, никогда не доходит до Throne, поэтому в режиме системного прокси правила к ним не применяются. См. Маршрутизация и Вкладка «Подключения».

Перенос данных

Из Nekoray

Throne не умеет читать папку конфигурации Nekoray, и инструмента для импорта из неё нет. Перенесите данные вручную:

  1. В Nekoray скопируйте URL каждой подписки из настроек её группы.
  2. В Throne скопируйте один URL подписки, нажмите Ctrl+V в главном окне и выберите Создать новую группу подписки (Create new subscription group). Повторите это для каждой подписки.
  3. Для серверов, которые вы добавляли вручную: выделите их в Nekoray и выберите Сервер (Server) → Поделиться (Share) → Скопировать ссылки для выбранных (Copy links of selected). Затем в Throne нажмите Ctrl+V, чтобы импортировать их.
  4. Заново настройте маршрутизацию: скачайте профиль для своей страны через Маршруты (Routing) → Скачать профили (Download Profiles) или добавьте собственные правила. См. Маршрутизация.
  5. Проверьте настройки, которые вы меняли в Nekoray, например прослушиваемый порт, DNS-серверы и горячие клавиши, и задайте их заново в Throne.

Не запускайте Nekoray и Throne одновременно с включённым режимом TUN или системным прокси.

Из Throne 1.0.x

В Throne 1.1.0 JSON-файлы в стиле Nekoray заменены базой данных (throne.db), и читать старые файлы новая версия не умеет. Если обновить 1.0.x поверх старой установки, ваши профили, группы и настройки в новой версии не появятся (#1765). Сохраните копию папки старой версии и перенесите подписки, ссылки для обмена и профили маршрутизации вручную, как описано выше. В #1202 описаны шаги для ручного переноса и приведён скрипт от сообщества, который не является официальным.

Начиная с 1.1.3 данные между версиями Throne и между компьютерами можно переносить через Основные настройки (Basic Settings) → Резервное копирование и восстановление (Backup and Restore). См. Резервное копирование, обновление и перенос.

Из NekoBox for Android

Раньше Throne для Android назывался NekoBox for Android. Версия 2.0.0 заново построена на ядре версии для компьютера и не может обновить более старую версию:

  • Она подписана новым ключом, поэтому сначала нужно удалить старую версию.
  • Она запускается пустой и не может восстановить старые резервные копии Android (файлы резервных копий и .zip-файлы WebDAV версий 1.6.x и более ранних). Она восстанавливает только файлы .thrbackup, включая резервные копии, созданные в Throne для компьютера.

Перед удалением старой версии скопируйте URL своих подписок, а для серверов, которые вы добавляли вручную, — их ссылки для обмена. Если вы также пользуетесь Throne для компьютера, можно вместо этого восстановить на телефоне резервную копию с компьютера; см. Резервное копирование, обновление и перенос.
