Как сообщить об ошибке

Что проверить перед отправкой сообщения об ошибке, как собрать логи и данные диагностики и что указать в issue.

Хороший отчёт об ошибке помогает разработчикам быстро найти причину. На этой странице описано, что проверить в первую очередь, как собрать логи и что написать в issue.

Сообщайте об ошибках здесь:

  • Throne для компьютера: github.com/throneproj/Throne/issues
  • Throne для Android: github.com/throneproj/ThroneForAndroid/issues

С вопросами о том, как пользоваться Throne для компьютера, обращайтесь не в issue, а в категорию Q&A на GitHub Discussions.

Предупреждение

Все issue публичны. Никогда не публикуйте URL подписок, токены, пароли, UUID, закрытые ключи или адреса серверов. Перед публикацией удалите их из логов, снимков экрана и конфигураций. Throne для компьютера не удаляет их за вас, а при неудачном обновлении подписки в лог записывается полный URL подписки. Такое уже случалось: пользователь опубликовал ссылку на подписку вместе с токеном в публичном issue, и ему пришлось её сбросить. Если вы по ошибке опубликовали секретные данные, попросите провайдера их сбросить.

Перед отправкой

  1. Обновитесь до последней версии через Утилиты (Tools) → Проверить наличие обновлений (Check For Update) или со страницы загрузок. Многие ошибки уже исправлены.
  2. Поищите своё сообщение об ошибке среди существующих issue — открытых и закрытых.
  3. Прочитайте FAQ и Устранение неполадок.
  4. Попробуйте чистую конфигурацию: выйдите из Throne, переименуйте папку config, запустите Throne и настройте только то, что нужно, чтобы показать проблему. Укажите в отчёте, возникает ли проблема и в этом случае. Чтобы вернуться, выйдите из Throne, удалите новую папку config и верните старой папке прежнее имя.
  5. Если вы установили Throne из WinGet, Scoop, AUR или Nix, проверьте также официальную сборку. Разработчики не поддерживают эти пакеты.
  6. Если не работает только один сервер, проверьте его в другом приложении. Если он не работает и там, обратитесь к своему провайдеру.

Сбор логов

Версия для компьютера

Throne показывает свой лог на вкладке Логи (Logs) внизу главного окна и записывает те же строки в logs/throne.log в папке конфигурации (Настройки (Settings) → Открыть папку конфигурации (Open Config Folder)).

Чтобы записать подробный лог:

  1. Откройте Настройки (Settings) → Основные настройки (Basic Settings) → Логирование (Logging).
  2. Установите для Уровень логирования Sing-box (Sing-box Log level) значение debug. Для VLESS (Xray) и других профилей Xray также установите для Уровень логирования Xray (Xray Log level) значение debug.
  3. Увеличьте Макс. кол-во строк в логах (Max log lines), например до 2000. Throne отбрасывает строки лога ядра сверх этого числа в секунду, а вкладка Логи хранит только это количество строк.
  4. Нажмите ОК (OK), затем перезапустите Throne через Программа (Program) → Перезапустить программу (Restart Program).
  5. Воспроизведите проблему.
  6. Приложите logs/throne.log к issue. Можно также щёлкнуть по тексту на вкладке Логи, нажать Ctrl+A, затем Ctrl+C и вставить текст.
  7. Когда закончите, верните уровень логирования sing-box к info, а уровень логирования Xray — к warning.

Полезно знать:

  • throne.log начинается заново при каждом запуске Throne, поэтому скопируйте его до перезапуска Throne. Когда он превышает 4 МБ, более старые части сохраняются в файлах с throne.log.1 по throne.log.3.
  • В первых строках throne.log указаны версия Throne, версия Qt, операционная система и архитектура процессора.
  • После сбоя при следующем запуске лог аварийно завершённого сеанса сохраняется как logs/crashed-<date>-<time>.log, а в лог записывается «В прошлый раз Throne не завершил работу корректно». Хранятся последние пять аварийных логов.
  • Windows: при сбое Throne показывает «Throne crashed» (Throne аварийно завершил работу) и сохраняет отчёт в папке crashes: файл .txt и файл .dmp с именем Throne_<version>_<architecture>_<date>-<time>. Приложите файл .txt, а по возможности и файл .dmp.

Android

  1. Откройте боковое меню и нажмите Журналы (Logs).
  2. Оставьте включённым Hide sensitive data. Этот параметр включён по умолчанию и скрывает URL, учётные данные, UUID, ключи, публичные IP-адреса и названия сетей Wi-Fi. Включите Hide destinations, чтобы скрыть также посещённые домены.
  3. Нажмите Share logs или Save logs… и приложите файл к issue.

После сбоя приложение предлагает лог, очищенный от конфиденциальных данных. См. Устранение неполадок на Android.

Диагностика

Если Throne зависает, перестаёт отвечать или сильно нагружает процессор, разработчики могут попросить файл диагностики (Diagnostics). Он записывает, что делает ядро, в течение 30 секунд.

  1. Приведите Throne в состояние, в котором проявляется проблема, например запустите профиль и дождитесь зависания. Не перезапускайте Throne.
  2. Откройте Настройки (Settings) → Основные настройки (Basic Settings) → Diagnostics.
  3. Отметьте параметры, о которых попросил разработчик: Lock contention, Execution trace (larger file) или Include Throne logs.
  4. Нажмите Start и подождите 30 секунд.
  5. Нажмите Show in folder и приложите файл throne-profile-<date>-<time>.zip. Throne сохраняет эти файлы в папке diagnostics рядом с папкой config, а не внутри неё; см. Папка данных.

Start работает, только пока запущено ядро. Запись не содержит сведений о ваших конфигурациях, но в ней указаны версия Throne, операционная система и несколько настроек, например включён ли режим TUN и тип запущенного профиля. Include Throne logs добавляет ваши логи, в которых есть посещённые домены и адреса серверов.

Что указать

Используйте шаблон issue и заполните все поля:

Пункт Где найти
Версия Throne Версия для компьютера: заголовок окна, например Throne 1.3.1, или первые строки throne.log. Android: О приложении (About).
Операционная система и её версия Например, Windows 11 24H2, Ubuntu 24.04, macOS 15 или Android 14.
Способ установки ZIP, установщик Windows, .deb, .rpm, установочный скрипт для Linux или менеджер пакетов (WinGet, Scoop, AUR, Nix, RPM-репозиторий).
Режим Режим TUN (Tun Mode), Системный прокси (System Proxy) или оба. Для режима TUN также значение Stack в окне Настройки TUN (Tun Settings).
Тип профиля Значение из столбца Тип (Type) в списке профилей, например VLESS (Xray). Не сама ссылка.
Шаги воспроизведения Пронумерованные шаги, которые с самого начала показывают проблему.
Ожидаемый и фактический результат Что вы ожидали и что произошло на самом деле. Копируйте сообщения об ошибках текстом.
Логи Отладочный лог, файлы сбоя или файл диагностики, как описано выше.

Для проблем с маршрутизацией выберите шаблон Routing Issue. В нём запрашивается ваш профиль маршрутизации: откройте Настройки (Settings) → Настройки маршрутизации (Routing Settings) → Маршрут (Route), выберите профиль и нажмите Экспорт (Export). Будет скопирована ссылка throne://route/…. Перед публикацией проверьте, нет ли в ней личных доменов или адресов.

Если разработчик попросит вашу конфигурацию, щёлкните профиль правой кнопкой мыши → Поделиться (Share) → Экспортировать конфиг Sing-box (Export Sing-box config). Перед публикацией замените пароли, UUID, ключи и адреса серверов на xxxx.
