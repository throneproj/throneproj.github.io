Глоссарий

Краткие объяснения терминов, которые встречаются в Throne: от профилей и маршрутизации до режима TUN, DNS и параметров обхода цензуры.

На этой странице каждый термин, который встречается в Throne, объясняется одним предложением. Чтобы узнать больше, перейдите по ссылке в последнем столбце.

Профили и группы

Термин Значение Подробнее
Profile (профиль) Одна запись сервера или прокси в списке с её протоколом, адресом и настройками. Быстрый старт
Group (группа) Вкладка главного окна, в которой хранятся профили; группа бывает типа Стандартный (Basic), когда профили добавляете вы, или типа Подписка (Subscription), когда она заполняется по URL. Подписки и группы
Subscription (подписка) URL от вашего провайдера, который возвращает список профилей; Throne загружает их в группу и может позже обновлять. Подписки и группы
Share link (ссылка для обмена) Однострочная ссылка на один профиль, например vless://… или ss://…, которую понимают и другие приложения. Протоколы и форматы импорта
Deep link (глубокая ссылка) Ссылка throne://, которая даёт Throne команду выполнить действие, например добавить подписку или профиль маршрутизации. Глубокие ссылки
Throne link (ссылка Throne) Глубокая ссылка throne://add/…, которая содержит один профиль; её можно получить командой Копировать ссылки выбранных (Диплинк) (Copy links of selected (Deep Links)). Глубокие ссылки
Chain (цепочка) Профиль типа Цепочка прокси (Chain Proxy), который пропускает трафик через несколько профилей один за другим. Цепочки прокси и пользовательские конфигурации
Front / landing proxy (фронт-прокси / выходной прокси) Параметры группы, которые добавляют по одному дополнительному профилю перед каждым профилем группы (фронт-прокси) или после него (выходной прокси). Цепочки прокси и пользовательские конфигурации
Auto selector (автовыбор) Тип профиля, который проверяет серверы группы и автоматически использует лучшие из них. Тестирование и автовыбор
URL test (тест задержки, URL-тест) Тест задержки, при котором через профиль открывается URL теста задержки (Latency Test URL) и измеряется, сколько времени это занимает. Тестирование и автовыбор

Ядро и режимы подключения

Термин Значение Подробнее
Core (ядро) ThroneCore — фоновая программа, которая передаёт ваш трафик; окно Throne только управляет ею. Что такое Throne
sing-box Движок с открытым исходным кодом, на котором построен ThroneCore; он отвечает за режим TUN, маршрутизацию, DNS и большинство протоколов. sing-box или Xray
Xray Второй движок, который работает внутри ядра для профилей VLESS (Xray) и конфигураций Xray. sing-box или Xray
Inbound (входящее подключение) Способ, которым трафик попадает в Throne: смешанный порт, адаптер TUN или пользовательский inbound. Настройки входящих подключений
Outbound (исходящее подключение) Способ, которым трафик покидает Throne: через профиль (прокси), напрямую или никак (блокировка). Маршрутизация
Mixed port (смешанный порт) Локальный порт, который принимает подключения как SOCKS5-, так и HTTP-прокси; по умолчанию 127.0.0.1:2080. Настройки входящих подключений
System proxy (системный прокси) Режим Системный прокси (System Proxy), который указывает смешанный порт в системных настройках прокси, чтобы приложения, учитывающие эти настройки, использовали Throne. Системный прокси
TUN (режим TUN) Режим TUN (Tun Mode), который создаёт виртуальный сетевой адаптер, чтобы трафик всех приложений проходил через Throne. Режим TUN
Stack (стек) Способ обработки пакетов в режиме TUN: system (сетевой стек вашей системы), gvisor (стек, встроенный в ядро) или mixed (system для TCP, gVisor для UDP). Параметры TUN
Strict route (строгий маршрут) Параметр TUN, который не даёт трафику идти в обход туннеля; в Windows 10 и новее он включён по умолчанию. Защита от утечек DNS в Windows
MTU Максимальный размер пакета для адаптера TUN: по умолчанию 1500 на компьютере и 9000 на Android. Параметры TUN

Маршрутизация и DNS

Термин Значение Подробнее
Routing profile (профиль маршрутизации) Именованный набор правил плюс outbound по умолчанию; одновременно активен ровно один профиль маршрутизации. Маршрутизация
Rule (правило) Условие (например, домен, диапазон IP-адресов, набор правил или программа) и действие для подходящих под него подключений; правила проверяются сверху вниз. Маршрутизация
Rule-set (набор правил) Готовый список доменов (geosite-…) или диапазонов IP-адресов (geoip-…) для правил, который загружается как двоичный файл .srs. Наборы правил
Default outbound (outbound по умолчанию) Куда идёт подключение, если ни одно правило не подошло: proxy, direct, block или warp-bypass. Маршрутизация
Direct (напрямую) Подключение идёт через ваше обычное интернет-соединение, без прокси. Маршрутизация
Block (блокировка) Подключение отклоняется. Маршрутизация
warp-bypass Подключение идёт через ваш профиль, но в обход WARP, когда WARP включён. Cloudflare WARP
Remote routing profile (удалённый профиль маршрутизации) Профиль маршрутизации, который Throne загружает по URL и может обновлять автоматически. Удалённые профили
Sniffing (сниффинг) Throne считывает доменное имя из начала подключения, поэтому правила для доменов работают, даже когда приложение подключается по IP-адресу. Маршрутизация
DNS routing (DNS-маршрутизация) Параметр Включить DNS-маршрутизацию (Enable DNS Routing): домены, подпадающие под ваши правила direct, разрешаются через DNS для прямых запросов, а все остальные запросы идут на DNS-сервер по умолчанию (Default DNS server), по умолчанию удалённый. DNS
Remote DNS / direct DNS (удалённый DNS / DNS для прямых запросов) Удалённый DNS (по умолчанию https://8.8.8.8/dns-query) используется через прокси и является сервером по умолчанию; DNS для прямых запросов (по умолчанию localhost, системный резолвер) используется без прокси, отвечает для доменов, подпадающих под правила direct, и определяет адреса ваших серверов. Настройки DNS
FakeIP (поддельные IP) Режим DNS (по умолчанию выключен), который отвечает временными поддельными адресами и сопоставляет их обратно с настоящими доменными именами. FakeIP

Протоколы и обход цензуры

Термин Значение Подробнее
Reality Параметр безопасности для VLESS, благодаря которому подключение выглядит как посещение настоящего постороннего сайта. sing-box или Xray
XHTTP Транспорт Xray, который передаёт подключение внутри обычных HTTP-запросов. sing-box или Xray
uTLS Делает рукопожатие TLS похожим на рукопожатие распространённого браузера, например Chrome. Пресеты для обхода цензуры
ECH Encrypted Client Hello — скрывает имя сервера внутри рукопожатия TLS. Пресеты для обхода цензуры
TLS fragment (фрагментация TLS) Разбивает первое сообщение TLS (Client Hello) на мелкие части, чтобы пройти через некоторые фильтры цензуры. Пресеты для обхода цензуры
Multiplex (mux) (мультиплексирование) Передаёт много подключений внутри одного подключения к серверу с помощью smux, h2mux или yamux. Пресеты для обхода цензуры
WARP Бесплатный VPN-сервис Cloudflare, который Throne может добавить последним звеном после вашего профиля. Cloudflare WARP
MASQUE Туннельный протокол поверх HTTP/3 или HTTP/2; в Throne есть тип профиля MASQUE, и WARP может его использовать. Cloudflare WARP

Конфиденциальность, файлы и безопасность

Термин Значение Подробнее
HWID Аппаратный идентификатор, который запрашивают некоторые провайдеры; Throne отправляет его, только если вы это включите. Конфиденциальность и сетевые запросы
OTP (одноразовый пароль) Одноразовые пароли (коды TOTP или HOTP), которые запрашивают некоторые серверы OpenVPN и OpenConnect; Throne хранит их в Утилиты (Tools) → Менеджер OTP (OTP Manager). Менеджер OTP
.thrbackup Файл резервной копии Throne; создавать и восстанавливать его умеют и приложение для компьютера, и приложение для Android. Резервное копирование и восстановление
Portable mode (портативный режим) Throne хранит данные в папке config рядом с программой, а не в папке пользователя. Папка данных
