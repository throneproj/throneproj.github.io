Быстрый старт

Добавьте серверы, проверьте их, выберите профиль маршрутизации и подключитесь через Throne в Windows, Linux или macOS.

Эта страница проведёт вас от только что установленного Throne до работающего подключения. Вам понадобится ссылка на подписку или ссылка для обмена от вашего провайдера либо данные вашего собственного сервера. Если Throne ещё не установлен, см. Установка. Для Android см. Throne для Android.

Добавление серверов

Throne хранит каждый сервер как профиль. Профили входят в группы — это вкладки над списком профилей. Подписка — это группа, которую Throne скачивает по URL и может позже обновлять.

Вставка ссылки на подписку

  1. Скопируйте URL подписки. Он начинается с https://.
  2. В главном окне нажмите Ctrl+V или выберите Программа (Program) → Добавить профиль из буфера обмена (Add profile from clipboard).
  3. Throne спросит «Как обновить?». Выберите в списке Создать новую группу подписки (Create new subscription group) и нажмите ОК (OK).

Throne создаёт группу с именем хоста из URL и сразу скачивает её профили.

Два других варианта не создают подписку:

Вариант Что происходит
Добавить профили в эту группу (Add profiles to this group) Профили однократно импортируются в текущую группу. Throne не сохраняет URL, поэтому позже обновить эти профили нельзя.
Импортировать профиль HTTP-прокси (Import HTTP proxy profile) URL воспринимается как адрес HTTP-прокси-сервера.

Добавление подписки через меню «Группы»

  1. Нажмите Группы (Groups) → Добавить новую группу (Add new Group).
  2. Введите Название (Name).
  3. В поле Тип (Type) выберите Подписка (Subscription). Изменить тип позже нельзя.
  4. Вставьте URL подписки в поле URL.
  5. Нажмите ОК (OK).
  6. Щёлкните правой кнопкой мыши по вкладке новой группы и выберите Обновить подписку (Update subscription).

При создании группы ничего не скачивается — это делает шаг 6. В дальнейшем текущую группу можно обновлять через Группы (Groups) → Обновить подписку (Update subscription) (Ctrl+U). Об автоматических обновлениях и настройках для провайдера см. Подписки и группы.

Добавление отдельных профилей

Профили, добавленные этими способами, попадают в группу, вкладка которой выбрана.

  • Ссылки для обмена, например vless://, ss:// или trojan://: скопируйте одну или несколько ссылок, по одной на строку, и нажмите Ctrl+V.
  • QR-код на экране: нажмите Программа (Program) → Сканировать QR-код (Scan QR Code) (Ctrl+Shift+Q). Throne считывает QR-коды со всех ваших экранов.
  • Файлы и изображения: перетащите файлы конфигурации, изображения с QR-кодами или текст ссылок в главное окно или нажмите Программа (Program) → Добавить профиль из файла (Add profile from File(s)) (Ctrl+O).
  • Вручную: нажмите Программа (Program) → Новый профиль (New profile) (Ctrl+N).

Все поддерживаемые ссылки и файлы перечислены на странице Протоколы и форматы импорта.

Проверка серверов

Тест задержки подключается через каждый профиль и измеряет задержку.

  1. Щёлкните любой профиль в списке, затем нажмите Ctrl+A, чтобы выделить все профили группы.
  2. Щёлкните выделенные профили правой кнопкой мыши и выберите Тест задержки выбранного профиля (Url Test Selected) (Ctrl+Shift+S).

Чтобы проверить всю группу без выделения, нажмите Группы (Groups) → Тест задержки всей группы (Url Test Group) (Ctrl+Shift+G).

В столбце Результат теста (Test Result) показывается задержка в миллисекундах или Недоступен (Unavailable), если тест не прошёл. Щёлкните заголовок столбца Результат теста, чтобы отсортировать список по нему, и щёлкните ещё раз, чтобы изменить порядок на обратный.

Чтобы удалить профили, не прошедшие тест, нажмите Группы (Groups) → Удалить недоступные (Remove Unavailable) (Ctrl+Shift+R). В группе подписки следующее обновление снова добавит их, если они всё ещё есть в списке провайдера.

О тестах скорости, тестах IP и автоматическом выборе сервера см. Тестирование и автовыбор.

Выбор маршрутизации

Маршрутизация определяет, какой трафик идёт через прокси, а какой — напрямую в интернет. Этот шаг необязателен: встроенный профиль маршрутизации Default направляет весь трафик через прокси.

Если вы хотите, чтобы сайты вашей страны открывались напрямую, без прокси, скачайте готовый профиль маршрутизации:

  1. Нажмите Маршруты (Routing) → Скачать профили (Download Profiles) и выберите China, Iran или Russia.
  2. Throne спросит «Добавить эти удалённые профили маршрутизации?» и покажет их список. Оставьте отмеченным Авто-обновление (Auto update) и нажмите ОК (OK).
  3. Снова откройте меню Маршруты (Routing). Ваши профили маршрутизации перечислены внизу, отмеченный профиль активен.
  4. Нажмите нужный профиль маршрутизации. Если профиль запущен, Throne перезапустит его с новой маршрутизацией.
Профиль маршрутизации Через прокси Напрямую
Bypass China, Bypass Iran, Bypass Russia Весь остальной трафик Сайты и IP-адреса этой страны, а также ваша локальная сеть
Proxy China Blocked, Proxy Russia Blocked Только сайты, заблокированные в этой стране Весь остальной трафик
Proxy Antizapret, Proxy Refilter (Россия) Только сайты из этих списков блокировок Весь остальной трафик

Одновременно активен только один профиль маршрутизации, поэтому выберите один из них. Удалять Default или другие профили не нужно. О создании собственных правил см. Маршрутизация.

Подключение

  1. Щёлкните профиль, который хотите использовать.
  2. Нажмите Enter или кнопку запуска справа от Утилиты (Tools). Её всплывающая подсказка — Запустить (Start).
  3. Отметьте Системный прокси (System Proxy) или Режим TUN (Tun Mode) рядом с кнопкой запуска.
Режим Что делает
Системный прокси (System Proxy) Пока запущен профиль, прописывает в системных настройках прокси локальный порт Throne (по умолчанию 127.0.0.1:2080). Его используют браузеры и другие приложения, которые следуют системным настройкам прокси. См. Системный прокси.
Режим TUN (Tun Mode) Создаёт виртуальный сетевой адаптер, который перехватывает трафик всех приложений, включая те, что игнорируют настройки прокси. Нужны права администратора или root. См. Режим TUN.

Оба режима можно включить одновременно. Тогда в заголовке окна будет [Tun+Системный прокси] ([Tun+System Proxy]). Если не отмечен ни один режим, приложения, которые вы настроите сами, всё равно могут использовать Throne как SOCKS5- или HTTP-прокси по адресу 127.0.0.1:2080. О выборе режима см. Какой режим выбрать.

Когда вы впервые отмечаете Режим TUN (Tun Mode), Throne запрашивает нужные ему права:

  • Windows: Throne предложит запустить его от имени администратора. Нажмите Да (Yes) и подтвердите запрос Windows. Throne перезапустится от имени администратора, и Режим TUN будет включён. Если брандмауэр Windows спросит, разрешить ли ThroneCore, разрешите.
  • Linux: Throne предложит выдать своему ядру права root. Нажмите Да (Yes) и введите пароль. Затем снова отметьте Режим TUN.
  • macOS: Throne предложит выдать своему ядру права root. Нажмите Да (Yes) — откроется Терминал. Введите пароль в Терминале, затем снова отметьте Режим TUN.

Подробности и альтернативные способы см. в разделе Права для режима TUN.

Проверка подключения

В левом нижнем углу окна отображается запущенный профиль в виде [группа] профиль. Через мгновение под ним появляются страна и город вашего выходного IP-адреса.

Щёлкните этот текст, чтобы проверить запущенный профиль. Если подключение работает, Throne покажет Результат теста: <n> ms (Test Result: <n> ms), а если нет — Результат теста: Недоступен (Test Result: Unavailable). Если тест не прошёл, попробуйте другой профиль или см. Устранение неполадок.

Остановка и выход

  • Чтобы отключиться, снова нажмите ту же кнопку (теперь её подсказка — Остановить (Stop)) или нажмите Ctrl+S.
  • Закрытие окна только сворачивает Throne в системный трей. Чтобы выйти, нажмите Программа (Program) → Выход (Exit) или выберите Выход в меню трея.
  • Если включён пункт Программа (Program) → Запомнить последний профиль (Remember last profile), при старте Throne снова запускает ваш последний профиль и включает Системный прокси (System Proxy) и Режим TUN (Tun Mode), если они были включены. Пункт Программа → Запускать вместе с системой (Start with system) запускает Throne при входе в систему.
Предупреждение

Всегда выходите из Throne через Выход (Exit). Если процесс Throne будет принудительно завершён, пока запущен профиль с включённым параметром Системный прокси (System Proxy), система продолжит использовать прокси, который уже не работает, и сайты перестанут загружаться. См. FAQ.

Дальнейшие шаги

  • Подписки и группы: автоматические обновления, а также настройки User-Agent и HWID, которые нужны некоторым провайдерам.
  • Маршрутизация: собственные правила, например чтобы направлять через прокси только несколько сайтов.
  • Тестирование и автовыбор: тесты скорости и автоматическое переключение на работающий сервер.
  • Режим TUN: параметры TUN и побочные эффекты.
  • DNS: DNS-серверы и тесты на утечку.
  • Устранение неполадок и FAQ: помощь, когда что-то не работает.
