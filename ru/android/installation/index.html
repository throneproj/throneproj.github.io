Установка и обновление

Выбор нужного APK, установка Throne для Android, переход с 1.x или NekoBox и обновление приложения.

Для работы Throne для Android нужен Android 7.0 или новее. Приложение работает на телефонах, планшетах и Android TV.

Выбор нужного APK

В каждом релизе есть отдельный APK для каждого типа процессора (ABI):

APK Типичные устройства
Throne-<version>-arm64-v8a.apk Почти все телефоны и планшеты последних лет
Throne-<version>-armeabi-v7a.apk Старые 32-битные телефоны, многие ТВ-приставки и ТВ-стики
Throne-<version>-x86_64.apk Эмуляторы, некоторые Chromebook и компьютеры

Значение имеет система Android, а не процессор: у многих ТВ-приставок 64-битный процессор, но 32-битный Android, поэтому им нужен armeabi-v7a. С adb ABI выводит эта команда:

adb shell getprop ro.product.cpu.abi

Если не уверены, попробуйте arm64-v8a. Если Android его не установит, используйте armeabi-v7a.

Скачивание и проверка

Скачайте APK на странице загрузок или в релизах на GitHub. Чтобы убедиться, что файл не повреждён (необязательно), поместите его в одну папку с файлом SHA256SUMS из того же релиза и выполните:

sha256sum -c --ignore-missing SHA256SUMS

Для вашего файла должно быть выведено OK. В macOS выполните shasum -a 256 Throne-2.0.6-arm64-v8a.apk, в Windows — Get-FileHash .\Throne-2.0.6-arm64-v8a.apk -Algorithm SHA256 и сравните контрольную сумму со строкой для вашего файла в SHA256SUMS.

Установка

Если у вас установлен Throne для Android 1.x, сначала прочитайте раздел Переход с 1.x или NekoBox.

  1. Откройте скачанный APK.
  2. Если Android блокирует установку, нажмите в сообщении Настройки (Settings) и включите Разрешить установку из этого источника (Allow from this source). На Android 7 вместо этого включите Неизвестные источники (Unknown sources) в настройках безопасности Android.
  3. Вернитесь назад и нажмите Установить (Install).
  4. Откройте Throne и ответьте на вопросы при первом запуске. См. Разрешения и работа в фоне.

Об установке на Android TV см. Android TV.

Переход с 1.x или NekoBox

Начиная с 2.0.0 Throne для Android подписан новым ключом и использует новый формат данных. Android не может установить его поверх 1.x, приложение запускается без профилей, групп и настроек и не восстанавливает старые резервные копии (файлы throne_backup_….json и файлы .zip на WebDAV) — только файлы .thrbackup.

Предупреждение

При удалении старого приложения удаляются все его профили, группы, правила маршрутизации и настройки. Сохраните всё нужное заранее.

  1. В старом приложении скопируйте URL каждой подписки: боковое меню → Группы (Group), нажмите кнопку редактирования группы (значок карандаша) и скопируйте Ссылка для подписки (Subscription Link). Не используйте Поделиться подпиской (Share Subscription): этот пункт копирует ссылку sn://, которую новое приложение прочитать не может.
  2. Экспортируйте профили, которые получены не из подписки: меню группы → Экспортировать (Export) → Экспорт в файл (Export to file). Профили WireGuard, SSH, ShadowTLS, Mieru, цепочки и профили с пользовательской конфигурацией экспортируются как ссылки sn://, которые импортировать нельзя, поэтому запишите их настройки.
  3. Если вы пользуетесь Throne для компьютера с теми же профилями, можно вместо этого создать резервную копию там и восстановить её на телефоне. См. Перенос между компьютером и Android.
  4. Удалите старое приложение и установите новое.
  5. Снова добавьте подписки (Добавить профиль (Add profile) → Импорт из буфера обмена (Import from clipboard) → Создать новую группу подписок (Create new subscription group)), импортируйте экспортированный файл (Добавить профиль → Импортировать из файла (Import from file)) или восстановите резервную копию с компьютера (боковое меню → Инструменты (Tools) → Восстановить (Restore)).

У исходного приложения NekoBox for Android другое имя пакета, поэтому Throne устанавливается рядом с ним. Throne не может прочитать его данные и резервные копии: переносите подписки по их ссылкам.

Обновление из приложения

Сборки с GitHub обновляются сами:

  1. Откройте в боковом меню О приложении (About) и нажмите Проверить обновления (Check for updates).
  2. Если есть более новая версия, нажмите Обновить (Update).
  3. В первый раз Throne попросит разрешение на установку приложений. Нажмите Открыть настройки (Open settings), разрешите и вернитесь назад.
  4. Throne скачивает и проверяет APK. Подтвердите установку, когда Android попросит.

Пока приложение заменяется, подключение останавливается, а после обновления запускается снова.

В Настройки (Settings) → Основные (General) → Обновления (Updates) параметр Проверять обновления ежедневно (Check for updates daily) уведомляет о новых версиях, а Разрешить обновления до beta-версий (Allow updating to beta versions) также предлагает предварительные выпуски со страницы релизов на GitHub. Оба по умолчанию выключены.

Android устанавливает обновление, только если оно подписано тем же ключом, что и установленное приложение. Поэтому сборка из другого источника и сборка с GitHub не могут обновлять друг друга. Чтобы перейти с одной на другую, создайте резервную копию (боковое меню → Инструменты → Создать резервную копию (Create backup)), удалите приложение, установите другую сборку и восстановите копию. Об ошибках обновления см. Проблемы с обновлением.

Throne для Android пока нет в F-Droid (#37).

Предварительные сборки

В предварительных сборках (preview) есть самые новые изменения. Они предназначены для тестирования, поэтому в них могут быть ошибки. Разработчики собирают предварительную сборку вручную, когда им нужны тестировщики. Она 14 дней доступна в запуске GitHub Actions, который её собрал, и для её скачивания нужна учётная запись GitHub.

У предварительной сборки собственное имя пакета — com.nb4a.throne.debug, поэтому она устанавливается рядом со стабильным приложением, со своими профилями и настройками. Она не обновляется сама, и встроенное средство обновления её не предлагает. В командах adb и в приложениях автоматизации используйте com.nb4a.throne.debug вместо com.nb4a.throne.
