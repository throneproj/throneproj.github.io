Ответы на частые вопросы ищите в [FAQ](@/help/faq.ru.md), а если что-то не работает, воспользуйтесь страницей [Устранение неполадок](@/help/troubleshooting.ru.md). Если вы пользуетесь Throne для Android, см. [Устранение неполадок на Android](@/android/troubleshooting.ru.md).

Чтобы сообщить об ошибке, сначала прочитайте страницу [Как сообщить об ошибке](@/help/bug_reports.ru.md), затем создайте issue в репозитории [Throne для компьютера](https://github.com/throneproj/Throne/issues) или [Throne для Android](https://github.com/throneproj/ThroneForAndroid/issues). Вопросы об использовании Throne для компьютера задавайте в [категории Q&A на GitHub Discussions](https://github.com/throneproj/Throne/discussions/categories/q-a).
