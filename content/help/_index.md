Start with the [FAQ](@/help/faq.md) for common questions, and use [Troubleshooting](@/help/troubleshooting.md) when something does not work. For Throne for Android, see [Android Troubleshooting](@/android/troubleshooting.md).

To report a bug, read [Reporting a Bug](@/help/bug_reports.md) first, then open an issue for [Throne desktop](https://github.com/throneproj/Throne/issues) or [Throne for Android](https://github.com/throneproj/ThroneForAndroid/issues). Ask questions about using Throne desktop in the [Q&A category of GitHub Discussions](https://github.com/throneproj/Throne/discussions/categories/q-a).
