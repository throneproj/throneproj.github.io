برای پرسش‌های رایج، از [پرسش‌های متداول](@/help/faq.fa.md) شروع کنید و وقتی چیزی کار نمی‌کند، به [عیب‌یابی](@/help/troubleshooting.fa.md) مراجعه کنید. اگر از Throne برای Android استفاده می‌کنید، [عیب‌یابی Android](@/android/troubleshooting.fa.md) را ببینید.

برای گزارش یک باگ، ابتدا [گزارش باگ](@/help/bug_reports.fa.md) را بخوانید، سپس یک issue برای [Throne دسکتاپ](https://github.com/throneproj/Throne/issues) یا [Throne برای Android](https://github.com/throneproj/ThroneForAndroid/issues) باز کنید. پرسش‌های مربوط به استفاده از Throne دسکتاپ را در [دستهٔ Q&A در GitHub Discussions](https://github.com/throneproj/Throne/discussions/categories/q-a) مطرح کنید.
