Сочетания клавиш работают, когда окно Throne активно. **macOS:** `Ctrl` означает `Cmd`, а `Alt` — `Option`, поэтому `Ctrl+Shift+S` — это `Cmd+Shift+S`. На клавиатуре ноутбука Mac клавиша `Del` — это `Fn+Delete`.

## Главное окно {#main-window}

В меню `Настройки` (Settings) и `Маршруты` (Routing) нет сочетаний клавиш по умолчанию. Столбец «Можно изменить» показывает, можно ли назначить другое сочетание, см. [Изменение сочетания клавиш](#change-shortcuts).

В строке состояния щёлкните запущенный профиль, чтобы выполнить для него тест задержки, или `Mixed: …`, чтобы открыть `Основные настройки` (Basic Settings).

### Меню «Программа» {#program-menu}

| Действие | Сочетание клавиш | Можно изменить |
| --- | --- | --- |
| `Скрыть окно` (Hide window) | `Ctrl+H` (macOS: также `Cmd+W`) | Да |
| `Новый профиль` (New profile) | `Ctrl+N` | Да |
| `Вставить из буфера обмена` (Paste from clipboard) | `Ctrl+V` | Нет |
| `Импорт из файла` (Import from file) | `Ctrl+O` | Да |
| `Сканировать QR-код` (Scan QR code) | `Ctrl+Shift+Q` | Да |

Чтобы импортировать файлы, изображения с QR-кодом или ссылки, их также можно перетащить в окно.

### Меню «Группы» {#groups-menu}

Действия с группой применяются к группе открытой вкладки.

| Действие | Сочетание клавиш | Можно изменить |
| --- | --- | --- |
| `Обновить подписку` (Update subscription) | `Ctrl+U` | Да |
| `Тест` (Test) → `Тест задержки` (URL test) | `Ctrl+Shift+G` | Да |
| `Тест` → `Тест скорости` (Speed test) | `Ctrl+Alt+P` | Да |
| `Тест` → `Преобразовать домены в IP` (Resolve domains) | `Ctrl+Shift+I` | Да |
| `Тест` → `Остановить тестирование` (Stop testing) | `Ctrl+.` | Да |
| `Тест` → `Очистить результаты` (Clear results) | `Ctrl+Shift+C` | Да |

`Остановить тестирование` работает, только пока идет тест. Щелкните вкладку группы правой кнопкой мыши, чтобы открыть меню группы; перетаскивайте вкладки, чтобы изменить порядок групп.

### Меню «Утилиты» {#tools-menu}

| Действие | Сочетание клавиш | Можно изменить |
| --- | --- | --- |
| `Поиск настроек` (Search Settings) | `Ctrl+K` | Да |
| `Тест скорости текущего подключения` (Speed test current connection) | `F6` | Да |

`Поиск настроек` открывает окно [Поиск настроек](#command-palette). `Тест скорости текущего подключения` работает, только когда профиль запущен.

## Поиск настроек {#command-palette}

`Поиск настроек` (Search Settings) находит команды меню и параметры по названию. Нажмите `Ctrl+K` в главном окне или выберите `Утилиты` (Tools) → `Поиск настроек`.

- Введите одно или несколько слов. Пункт подходит, если все слова есть в его названии или пути, например `Основные настройки › Подключение › Локальный прокси`. В переведенном интерфейсе многие пункты находятся и по английским словам.
- Начните запрос с `>`, чтобы искать только команды, или с `@`, чтобы искать только параметры. Один символ `@` показывает все параметры.
- Нажмите `Enter` или дважды щелкните пункт, чтобы выполнить его. `Esc` закрывает окно.

Поиск находит параметры окон `Основные настройки` (Basic Settings), `Настройки маршрутизации` (Routing Settings), `Настройки режима TUN` (Tun Settings), `Предустановленные настройки` (Preset Settings) и `Настройки интеграции` (Integration Settings), а также команды, которые меню показывают в данный момент, включая меню списка профилей и ваши профили маршрутизации.

Одновременно может быть открыто только одно из этих окон: окно настроек, `Управление группами` (Manage Groups), `Менеджер OTP` (OTP Manager), `Статистика трафика` (Traffic Statistics) и `О программе` (About). Пока одно из них открыто, `Поиск настроек` затеняет пункты, которые открыли бы другое окно.

## Список профилей {#profile-list}

Щелкните профиль правой кнопкой мыши, чтобы открыть его меню. Если щелкнуть правой кнопкой мыши пустое место списка, откроется меню с пунктами `Новый профиль`, `Вставить из буфера обмена`, `Импорт из файла`, `Сканировать QR-код`, `Добавить подписку` (Add subscription) и `Выбрать все` (Select all).

| Действие | Сочетание клавиш | Можно изменить |
| --- | --- | --- |
| `Запустить` (Start) | `Enter` | Нет |
| `Остановить` (Stop) | `Ctrl+S` | Да |
| `Тест` (Test) → `Тест задержки` (URL test) | `Ctrl+Shift+S` | Да |
| `Тест` → `Тест скорости` (Speed test) | `Ctrl+Shift+P` | Да |
| `Поделиться` (Share) → `Копировать ссылку` (Copy link) | `Ctrl+C` | Нет |
| `Поделиться` → `Копировать deep link` (Copy deep link) | `Ctrl+Alt+C` | Нет |
| `Поделиться` → `Экспортировать конфиг` (Export config) | `Ctrl+E` | Да |
| `Дублировать` (Clone) | `Ctrl+D` | Да |
| `Закрепить вверху` (Pin to top) / `Открепить` (Unpin) ([закрепление](@/guides/testing.ru.md#pin)) | – | Да |
| `Сбросить трафик` (Reset traffic) | `Ctrl+R` | Да |
| `Удалить` (Delete) | `Del` | Нет |
| `Выбрать все` | `Ctrl+A` | Нет |

Другие клавиши и действия мышью в списке:

| Клавиша или действие | Что происходит |
| --- | --- |
| Двойной щелчок по профилю | Открывает редактор профиля. |
| `Esc` | Снимает выделение. В строке фильтра закрывает строку фильтра. |
| Перетаскивание строки | Перемещает профиль. Не работает, пока активен фильтр. |
| `Ctrl+F` | Показывает или скрывает строку фильтра. При скрытии фильтры сбрасываются. |
| `Up` в первой строке, `Down` в строке фильтра | Переход между списком и строкой фильтра. |

### Действия без сочетания по умолчанию {#no-default}

У большинства остальных пунктов меню нет сочетания по умолчанию, но его можно назначить, например: `Изменить` (Edit), `Закрепить вверху`, `Добавить подписку`, `Проверка сервисов` (Service check), `Выходной IP` (Exit IP), `Копировать результат теста` (Copy test result), команды `Очистка` (Clean up), `Управление группами` (Manage groups), окна настроек, окна меню `Утилиты` (Tools), варианты `Выход через` (Exit through), `Блокировать рекламу` (Block ads), `Поиск маршрута` (Route lookup), `Переключить WARP` (Toggle WARP), `Перезапустить ядро` (Restart core) и `Обновить ширину колонок` (Refresh column widths).

## Изменение сочетания клавиш {#change-shortcuts}

1. Откройте `Настройки` → `Настройки интеграции` (Integration Settings) → `Сочетания клавиш` (Shortcuts). Каждое действие указано вместе с путем в меню, например `Группы › Тест › Тест задержки`.
2. Щёлкните поле рядом с действием и нажмите новое сочетание клавиш. `Backspace` удаляет сочетание.
3. Нажмите `ОК` (OK).

Сочетания, отмеченные выше как «Нет», и `Ctrl+F` изменить нельзя. Если сочетание уже использует другое действие или глобальная горячая клавиша, окно называет конфликт и не сохраняет изменения, пока вы не измените одно из сочетаний.

## Глобальные горячие клавиши {#global-hotkeys}

Глобальные горячие клавиши работают в любом приложении, даже когда окно Throne скрыто. По умолчанию ни одна из них не задана.

1. Откройте `Настройки` → `Настройки интеграции` (Integration Settings) → `Глобальные горячие клавиши` (Global Hotkeys).
2. Щёлкните поле горячей клавиши и нажмите сочетание клавиш.
3. Нажмите `ОК`.

| Горячая клавиша | Что делает |
| --- | --- |
| `Показать/скрыть главное окно` (Trigger main window) | Показывает главное окно или скрывает его, если оно активно, как щелчок по значку в трее. |
| `Управление группами` (Manage groups) | Открывает `Управление группами` (Manage Groups). |
| `Открыть настройки маршрутизации` (Open Routing Settings) | Открывает `Настройки маршрутизации` (Routing Settings). |
| `Режим прокси` (Proxy mode) | Открывает у указателя мыши меню `Режим прокси` с пунктами `Системный прокси` (System proxy) и `Режим TUN` (Tun mode). |
| `Вкл./выкл. системный прокси` (Toggle system proxy) | Включает или выключает `Системный прокси`. |
| `Запустить/остановить профиль` (Start/Stop Profile) | Останавливает запущенный профиль или запускает последний профиль, если ни один не запущен. |
| `Вкл./выкл. режим TUN` (Toggle Tun mode) | Включает или выключает `Режим TUN`. |

- В горячей клавише должна быть клавиша `Ctrl`, `Alt` или `Meta` (`Cmd` в macOS), если только это не функциональная клавиша, например `F9`.
- Сочетание, которое уже занято другой программой или системой, не работает. После нажатия `ОК` Throne перечисляет горячие клавиши, которые не удалось зарегистрировать.
- Пока открыто окно `Настройки интеграции`, глобальные горячие клавиши не действуют.
- **Linux:** глобальные горячие клавиши работают в сеансах X11 и KDE Plasma Wayland (в KDE Plasma они также отображаются в системных настройках сочетаний клавиш, в разделе `Throne`), но не в других сеансах Wayland.

Чтобы управлять Throne с макропада, Stream Deck или из скрипта, используйте [thronectl](@/advanced/api.ru.md#example-hotkey).

## Значок в трее {#tray}

Throne показывает значок в системном трее (в macOS — в строке меню). Значок меняется, пока запущен профиль и когда включен `Системный прокси` (System proxy) или `Режим TUN` (Tun mode). Наведите на него указатель, чтобы увидеть запущенный профиль и режим.

- **Windows и Linux:** щёлкните значок, чтобы показать или скрыть окно. Щёлкните его правой кнопкой мыши, чтобы открыть меню трея.
- **macOS:** щёлкните значок, чтобы открыть меню трея.

Закрытие окна не завершает работу Throne: он продолжает работать в трее. Чтобы выйти, выберите `Выход` (Quit) в меню трея или в меню `Программа`.

**macOS:** пока окно скрыто, значка Throne в Dock нет. Если Throne закреплён в Dock, щёлкните его значок в Dock или снова откройте Throne из Finder, чтобы показать окно.

**Linux:** GNOME показывает значки в трее, только если установлено расширение AppIndicator ([#1623](https://github.com/throneproj/Throne/issues/1623)). Без значка в трее запустите Throne ещё раз, чтобы вернуть его скрытое окно.

### Меню трея {#tray-menu}

Первая строка меню трея показывает подключенный профиль. В его подменю `Программа` (Program) есть пункты `Запускать вместе с системой` (Start with system), `Запоминать последний профиль` (Remember last profile) и `Разрешить подключаться другим устройствам` (Allow other devices to connect), как в меню `Программа` главного окна.

| Пункт | Что делает |
| --- | --- |
| `Подключиться` (Connect) / `Отключиться` (Disconnect) | Останавливает запущенный профиль или запускает профиль, выбранный в списке; если ничего не выбрано — последний профиль, а если его нет — первый профиль открытой группы. |
| `Профиль: <name>` (`Profile: <name>`) | Запускает профиль, выбранный по группе или найденный по названию. Если показывать нечего, пункт называется `Выбрать профиль` (Select profile). |
| `Маршрутизация: <name>` (`Routing: <name>`) | Делает профиль маршрутизации активным и перезапускает запущенный профиль. |
| `Системный прокси`, `Режим TUN` | Включают и выключают эти режимы, как в главном окне. |
| `Коды OTP` (OTP codes) | Щелкните запись OTP, чтобы скопировать ее текущий код. |
| `Показать окно` (Show window) | Показывает главное окно. |
| `Программа` → `Запоминать последний профиль` | При следующем запуске Throne снова запускает профиль, который работал при выходе, и снова включает `Системный прокси` и `Режим TUN`, если они были включены. Профиль, который вы остановили сами, не запоминается. |
| `Программа` → `Разрешить подключаться другим устройствам` | Открывает локальный порт прокси для вашей сети, см. [Доступ из локальной сети](@/guides/proxy_modes.ru.md#lan-sharing). |
| `Перезапуск` (Restart) → `Перезапустить ядро` (Restart core), `Перезапустить программу` (Restart program) | Перезапускает ядро или сам Throne. |
| `Выход` (Quit) | Завершает работу Throne. |

`Запускать вместе с системой` запускает Throne при входе в систему. Для этого Throne добавляет задание в Планировщик заданий в Windows, объект входа в macOS и файл `Throne.desktop` с параметром `-tray` в `~/.config/autostart` в Linux. В Windows и macOS окно открывается при входе в систему, если не включен параметр `Скрывать главное окно при запуске` (Hide main window at startup). В Windows задание запускает Throne от имени обычного пользователя, даже если у ядра есть [права администратора](@/guides/tun_mode.ru.md#privileges-windows). От имени администратора оно запускает Throne, только если вы воспользовались запасным вариантом `Перезапустить от имени администратора` (Restart as administrator) и не включен параметр `Всегда запускать Throne от имени обычного пользователя` (Always start as standard user).

### Настройки трея {#tray-settings}

В `Настройки` → `Основные настройки` → `Общие` (General) → `Окно` (Window):

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `Скрывать главное окно при запуске` (Hide main window at startup) | Выкл. | Throne запускается только со значком в трее, как с параметром командной строки `-tray`. |
| `Откл. сворачивание в трей` (Disable tray) | Выкл. | Убирает значок из трея. После этого закрытие окна завершает работу Throne. |

{% alert_warning() %}
Не включайте `Откл. сворачивание в трей` вместе с `Скрывать главное окно при запуске` или `-tray`: Throne запустится без окна и без значка в трее. Если это произошло, запустите Throne еще раз, и уже запущенный Throne покажет свое окно.
{% end %}
