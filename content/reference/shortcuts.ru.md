На этой странице перечислены сочетания клавиш Throne для компьютера и глобальные горячие клавиши, которые можно настроить, а также описано, что делает значок в трее. Сочетания клавиш работают, когда окно Throne активно. Глобальные горячие клавиши работают в любом приложении, в том числе когда окно Throne скрыто. Здесь же описана палитра команд, которая находит команды и параметры по названию.

**macOS:** `Ctrl` на этой странице означает `Cmd` на Mac, а `Alt` — `Option`. Например, `Ctrl+Shift+S` — это `Cmd+Shift+S`. На клавиатуре ноутбука Mac клавиша `Del` — это `Fn+Delete`.

## Главное окно {#main-window}

Кнопки панели инструментов `Программа` (Program), `Настройки` (Settings), `Группы` (Groups), `Маршрутизация` (Routing) и `Утилиты` (Tools) открывают меню главного окна. В меню `Настройки` и `Маршрутизация` сочетаний клавиш нет. Начиная с версии 1.4.0, щелчок правой кнопкой мыши по профилю маршрутизации внизу меню `Маршрутизация` (Routing) открывает этот профиль в редакторе, не делая его активным; см. [Профили маршрутизации](@/guides/routing.ru.md#profiles).

Начиная с 1.4.0 новая установка запускается в простом режиме, который скрывает часть пунктов с этой страницы, например `Преобразовать домены группы в IP` (Resolve Domain for group), `Экспортировать конфиг` (Export config) и `Сбросить трафик` (Reset Traffic). См. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode).

Столбец «Можно изменить» показывает, можно ли назначить другое сочетание в `Настройки` → `Настройки интеграции` (Integration Settings) (до 1.4.0 этот пункт назывался `Настройки горячих клавиш`). См. [Изменение сочетания клавиш](#change-shortcuts).

### Меню «Программа» {#program-menu}

| Действие | Сочетание клавиш | Можно изменить |
| --- | --- | --- |
| `Скрыть окно` (Hide window) | `Ctrl+H` (macOS: также `Cmd+W`) | Да |
| `Новый профиль` (New profile) | `Ctrl+N` | Да |
| `Добавить профиль из буфера обмена` (Add profile from clipboard) | `Ctrl+V` | Нет |
| `Добавить профиль из файла` (Add profile from File(s)) | `Ctrl+O` | Да |
| `Сканировать QR-код` (Scan QR Code) | `Ctrl+Shift+Q` | Да |

Чтобы импортировать файлы, изображения с QR-кодом или ссылки, их также можно перетащить в окно.

В меню `Программа` есть также `Проверить наличие обновлений` (Check For Update), а начиная с 1.4.0 — `О программе` (About). `О программе` показывает версии Throne, sing-box, Xray-core, Qt и Go. До 1.4.0 пункт `Проверить наличие обновлений` находился в меню `Утилиты` (Tools).

### Меню «Группы» {#groups-menu}

Действия с группой применяются к группе открытой вкладки.

| Действие | Сочетание клавиш | Можно изменить |
| --- | --- | --- |
| `Тест задержки всей группы` (Url Test Group) | `Ctrl+Shift+G` | Да |
| `Тест скорости всей группы` (Speedtest Group) | `Ctrl+Alt+P` | Да |
| `Преобразовать домены группы в IP` (Resolve Domain for group) | `Ctrl+Shift+I` | Да |
| `Очистить результат теста для группы` (Clear Group test result) | `Ctrl+Shift+C` | Да |
| `Обновить подписку` (Update subscription) | `Ctrl+U` | Да |
| `Очистка` (Clean up) → `Удалить дубликаты` (Remove Duplicates) | `Ctrl+Shift+D` | Да |
| `Очистка` → `Удалить недоступные` (Remove Unavailable) | `Ctrl+Shift+R` | Да |
| `Очистка` → `Удалить недействительные` (Remove Invalid) | `Ctrl+Alt+I` | Да |
| `Остановить тестирование` (Stop Testing) | `Ctrl+.` | Да |

`Остановить тестирование` появляется в меню, только пока идёт тест. Начиная с 1.4.0 действия удаления вместе с `Удалить небезопасные конфигурации` (Remove Insecure Configs) находятся в подменю `Очистка`.

Щёлкните вкладку группы правой кнопкой мыши, чтобы открыть эту группу и её меню. В меню вкладки есть пункты `Добавить новую группу` (Add new Group), `Редактировать выбранную группу` (Edit selected Group), `Удалить выбранную группу` (Delete selected Group), `Обновить подписку` (Update subscription), `Тест задержки выбранной группы` (Url Test selected Group) и `Тест скорости выбранной группы` (Speed Test selected Group). Перетащите вкладку, чтобы изменить порядок групп.

### Меню «Утилиты» {#tools-menu}

| Действие | Сочетание клавиш | Можно изменить |
| --- | --- | --- |
| `Search Settings` | `Ctrl+K` | Да |
| `Тест скорости текущего профиля` (Speedtest Current) | `F6` | Да |

`Search Settings` открывает [палитру команд](#command-palette) (начиная с 1.4.0). `Тест скорости текущего профиля` работает, только когда профиль запущен.

### Строка состояния {#status-bar}

- Щёлкните запущенный профиль в левой части строки состояния, чтобы выполнить для него тест задержки.
- Щёлкните `Mixed: …` в середине строки состояния, чтобы открыть `Основные настройки` (Basic Settings).

## Палитра команд {#command-palette}

Начиная с 1.4.0 палитра команд находит команды меню и параметры по названию. Чтобы открыть её, нажмите `Ctrl+K` в главном окне или выберите `Утилиты` (Tools) → `Search Settings`. Палитра открывается в отдельном окне `Search Settings`.

- Без запроса палитра показывает команды меню `Программа` (Program), `Настройки` (Settings), `Группы` (Groups), `Маршрутизация` (Routing), `Утилиты` (Tools) и `Сервер` (Server) — это меню списка профилей. В группе `Маршрутизация` также перечислены ваши профили маршрутизации. Показываются только те команды, которые меню показывают в данный момент.
- Чтобы искать, введите одно или несколько слов. Пункт подходит, если все слова есть в его названии или в пути после него, например `Основные настройки › Общие › Настройки inbound`. Результаты сгруппированы под заголовками `Команды` (Commands) и `Настройки` (Settings). В переведённом интерфейсе многие пункты находятся и по английским словам.
- Начните запрос с `>`, чтобы искать только команды, или с `@`, чтобы искать только параметры. Один символ `@` показывает все параметры.
- Перемещайтесь клавишами со стрелками, `Tab`, `Page Up` и `Page Down`. Нажмите `Enter` или дважды щёлкните пункт, чтобы выполнить его. `Esc` закрывает палитру.

Команда выполняется так же, как если бы вы выбрали её в меню. Справа показано её сочетание клавиш, а у команды, которую можно включить или выключить, например `Запускать вместе с системой` (Start with system), — переключатель. Недоступные в данный момент команды затенены.

Параметр открывает своё окно настроек на нужной вкладке, ставит курсор в поле параметра и ненадолго обводит его рамкой. Палитра находит параметры окон `Основные настройки` (Basic Settings), `Настройки маршрутизации` (Routing Settings), `Настройки режима TUN` (Tun Settings), `Предустановленные настройки` (Preset Settings) и `Настройки интеграции` (Integration Settings). После выполнения пункта палитра закрывается.

В простом режиме поиск находит и параметры, которые этот режим скрывает, — под заголовком «Настройки в расширенном режиме» (Settings in Advanced mode). Если выбрать такой параметр, Throne переключится в расширенный режим и затем откроет параметр. Команды меню, скрытые в простом режиме, в палитре не показываются. См. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode).

Одновременно может быть открыто только одно из этих окон: окна настроек, `Управление группами` (Manage Groups), `Менеджер OTP` (OTP Manager), `Статистика трафика` (Traffic Stats) и `О программе` (About). Пока одно из них открыто, палитра затеняет пункты, которые открыли бы другое окно, и добавляет к их пути `сначала закройте «<окно>»` (`close "<window>" first`). Палитра остаётся открытой, и эти пункты снова работают, как только вы закроете это окно. Пункты самого открытого окна работают по-прежнему.

Щёлкните список профилей правой кнопкой мыши, чтобы открыть его меню. В нём есть те же четыре действия добавления, что и в меню `Программа`, а также следующие:

| Действие | Сочетание клавиш | Можно изменить |
| --- | --- | --- |
| `Запустить` (Start) | `Enter` | Нет |
| `Остановить` (Stop) | `Ctrl+S` | Нет |
| `Поделиться` (Share) → `Экспортировать конфиг` (Export config) | `Ctrl+E` | Да |
| `Поделиться` → `Копировать ссылки выбранных` (Copy links of selected) | `Ctrl+C` | Нет |
| `Поделиться` → `Копировать ссылки выбранных (deep links)` (Copy links of selected (Deep Links)) | `Ctrl+Alt+C` | Нет |
| `Удалить` (Delete) | `Del` | Нет |
| `Выбрать все` (Select All) | `Ctrl+A` | Нет |
| `Дублировать` (Clone) | `Ctrl+D` | Да |
| `Тест задержки` (Url Test Selected) | `Ctrl+Shift+S` | Да |
| `Тест скорости` (Speedtest Selected) | `Ctrl+Shift+P` | Да |
| `Сбросить трафик` (Reset Traffic) | `Ctrl+R` | Да |

Начиная с 1.4.0 `Экспортировать конфиг` открывает окно со сгенерированной конфигурацией sing-box, а для профилей, которые используют Xray, — ещё и с конфигурацией Xray на отдельной вкладке. `Копировать` (Copy) копирует конфигурацию открытой вкладки. До 1.4.0 этот пункт назывался `Экспортировать конфиг Sing-box` (Export Sing-box config), а у некоторых профилей был также пункт `Export Xray config`.

Другие клавиши и действия мышью в списке:

| Клавиша или действие | Что происходит |
| --- | --- |
| Двойной щелчок по профилю | Открывает редактор профиля. |
| `Esc` | Снимает выделение. |
| Перетаскивание строки | Перемещает профиль. Не работает, пока активен фильтр. |
| Щелчок по заголовку столбца | Сортирует по этому столбцу. Повторный щелчок сортирует в обратном направлении. Стрелка рядом с названием столбца показывает столбец сортировки и её направление. |
| `Ctrl+F` | Показывает или скрывает строку фильтра. При скрытии фильтры сбрасываются. |
| `Up` в первой строке | Переходит к строке фильтра, если она открыта. |
| `Down` в строке фильтра | Возвращает в список. |
| `Esc` в строке фильтра | Закрывает строку фильтра. |

### Действия без сочетания по умолчанию {#no-default}

Этим действиям можно назначить сочетание клавиш, по умолчанию у них его нет: `QR-код и ссылка` (QR Code and link), `Копировать результат теста` (Copy Test Result), `Преобразовать выбранный домен в IP` (Resolve Selected Domain), `Определить выходной IP выбранных` (Resolve Selected Out IP), `Очистить результат теста` (Clear Test Result), `Определить выходной IP группы` (Resolve out IP for group), `Обновить все подписки` (Update all subscriptions), `Удалить небезопасные конфигурации` (Remove Insecure Configs), `IP-сканер` (IP Scanner) и `Обновить ширину колонок` (Refresh Column Widths).

## Изменение сочетания клавиш {#change-shortcuts}

1. Откройте `Настройки` → `Настройки интеграции` (Integration Settings) (только в расширенном режиме, см. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode)).
2. Откройте вкладку `Сочетания клавиш` (Shortcuts). На ней перечислены все действия, сочетания которых можно изменить.
3. Щёлкните поле рядом с действием и нажмите новое сочетание клавиш. Чтобы удалить сочетание, щёлкните поле и нажмите `Backspace`.
4. Нажмите `ОК` (OK).

Сочетания, отмеченные в таблицах выше как «Нет», изменить нельзя; `Ctrl+F` тоже изменить нельзя. Начиная с 1.4.0 окно отмечает сочетание клавиш, которое уже использует другое действие или глобальная горячая клавиша, называет конфликт рядом с кнопками и не сохраняет изменения, пока вы не измените одно из сочетаний.

## Глобальные горячие клавиши {#global-hotkeys}

Глобальные горячие клавиши работают в любом приложении, даже когда окно Throne скрыто. По умолчанию ни одна из них не задана.

1. Откройте `Настройки` → `Настройки интеграции` (Integration Settings).
2. На вкладке `Глобальные горячие клавиши` (Global Hotkeys) (до 1.4.0 она называлась `Глобальные`) щёлкните поле горячей клавиши.
3. Нажмите сочетание клавиш.
4. Нажмите `ОК`.

| Горячая клавиша | Что делает |
| --- | --- |
| `Показать/скрыть главное окно` (Trigger main window) | Показывает главное окно или скрывает его, если оно активно. То же самое, что щелчок по значку в трее. Начиная с 1.4.0 работает и в macOS. |
| `Показать группы` (Show groups) | Открывает окно `Управление группами` (Manage Groups). |
| `Показать маршруты` (Show routes) | Открывает `Настройки маршрутизации` (Routing Settings). |
| `Режим прокси` (Proxy mode) | Открывает у указателя мыши меню `Режим работы` (Operation Mode) с пунктами `Системный прокси` (System Proxy) и `Режим TUN` (Tun Mode). |
| `Вкл./выкл. системный прокси` (Toggle System Proxy) | Включает или выключает `Системный прокси`. |
| `Запустить/остановить профиль` (Start/Stop Profile) | Останавливает запущенный профиль или запускает последний профиль, если ни один не запущен (начиная с 1.4.0). |
| `Вкл./выкл. режим TUN` (Toggle Tun Mode) | Включает или выключает `Режим TUN` (начиная с 1.4.0). |

- Глобальная горячая клавиша — это одно сочетание клавиш. В нём должна быть клавиша `Ctrl`, `Alt` или `Meta` (`Cmd` в macOS), если только это не функциональная клавиша, например `F9`. Так горячая клавиша не мешает вводить текст в других приложениях.
- Если сочетание клавиш уже занято другой программой или системным сочетанием, эта горячая клавиша не работает. После нажатия `ОК` Throne перечисляет горячие клавиши, которые не удалось зарегистрировать, а в логе появляется «Глобальная горячая клавиша не зарегистрирована» (Global hotkey not registered) с указанием причины. Выберите другое сочетание.
- Пока открыто окно `Настройки интеграции`, глобальные горячие клавиши не действуют.
- **Linux:** начиная с 1.4.0 глобальные горячие клавиши работают в сеансах X11 и в сеансах KDE Plasma Wayland. В KDE Plasma они также отображаются в системных настройках сочетаний клавиш, в разделе `Throne`. В других сеансах Wayland они недоступны, и на вкладке `Глобальные горячие клавиши` написано «Глобальные горячие клавиши не поддерживаются в этом сеансе рабочего стола.» (Global hotkeys are not supported in this desktop session.).

Чтобы управлять Throne с макропада, Stream Deck или из скрипта, можно также использовать [thronectl](@/advanced/api.ru.md#example-hotkey).

## Значок в трее {#tray}

Throne показывает значок в системном трее. В macOS значок находится в строке меню. Значок меняется, когда запущен профиль и когда включён `Системный прокси` или `Режим TUN`. Начиная с 1.4.0 он также показывает, что профиль запускается или останавливается. Наведите на него указатель, чтобы увидеть запущенный профиль и его местоположение. Во всплывающей подсказке также показан режим, если он включён, и активный профиль маршрутизации, если это не `Default`.

- **Windows и Linux:** щёлкните значок, чтобы показать окно или скрыть его, если оно активно. Щёлкните значок правой кнопкой мыши, чтобы открыть меню трея.
- **macOS:** щёлкните значок, чтобы открыть меню трея.

Закрытие окна не завершает работу Throne. Окно скрывается, а Throne продолжает работать в трее. Чтобы выйти, выберите `Выход` (Exit) в меню трея или в меню `Программа`.

**macOS:** пока окно скрыто, значка Throne в Dock нет. Начиная с 1.4.0, если Throne закреплён в Dock, щелчок по его значку в Dock показывает окно, даже свёрнутое. То же происходит, если снова открыть Throne из Finder.

**Linux:** GNOME показывает значки в трее, только если установлено расширение AppIndicator ([#1623](https://github.com/throneproj/Throne/issues/1623)). Даже без значка в трее скрытое окно можно вернуть: запустите Throne ещё раз, и уже запущенный Throne покажет своё окно.

### Меню трея {#tray-menu}

| Пункт | Что делает |
| --- | --- |
| `Показать окно` (Show Window) | Показывает главное окно. |
| `Подключиться` (Connect) / `Отключиться` (Disconnect) | Запускает профиль, если ни один не запущен, или останавливает запущенный (начиная с 1.4.0). Запускается профиль, выбранный в списке. Если ничего не выбрано, запускается последний профиль, а если его нет — первый профиль открытой группы. Пока профиль запускается или останавливается, пункт называется `Подключение` (Connecting) или `Отключение` (Disconnecting) и недоступен. |
| `Запускать вместе с системой` (Start with system) | Запускает Throne при входе в систему. |
| `Запоминать последний профиль` (Remember last profile) | При следующем запуске Throne снова запускает последний работавший профиль и снова включает `Системный прокси` и `Режим TUN`, если они были включены. |
| `Разрешить подключаться другим устройствам` (Allow other devices to connect) | Открывает локальный порт прокси для других устройств в вашей сети. См. [Доступ из локальной сети](@/guides/proxy_modes.ru.md#lan-sharing). |
| `Выбор профиля` (Select Profile) | Открывает небольшой список ваших групп. Выберите группу, а затем профиль, чтобы запустить его, или начните вводить текст для поиска по всем профилям. Запущенный профиль отмечен галочкой. Кнопка `Остановить: <name>` (`Stop: <name>`) останавливает его. |
| `Выбор маршрутизации` (Select Routing) | Показывает список ваших профилей маршрутизации. Выбранный профиль становится активным, а запущенный профиль перезапускается. |
| `Коды OTP` (OTP Codes) | Показывает список ваших профилей OTP. Щёлкните профиль, чтобы скопировать его текущий код. В простом режиме скрыт. |
| `Режим работы` (Operation Mode) → `Системный прокси`, `Режим TUN` | Включает или выключает системный прокси или режим TUN. |
| `Перезапустить ядро` (Restart Core) | Перезапускает ядро. |
| `Перезапустить программу` (Restart Program) | Перезапускает Throne. |
| `Выход` (Exit) | Завершает работу Throne. |

`Запускать вместе с системой` работает по-разному в каждой системе:

- **Windows:** Throne добавляет задание в Планировщик заданий. Окно открывается при входе в систему, если не включён параметр `Запускать приложение свёрнутым` (Hide dashboard at startup). При каждом запуске Throne настраивает задание на те же права, с которыми запущен сам: если Throne работает от имени администратора, задание тоже запускает его от имени администратора, если только не включён параметр `Всегда запускать Throne от имени обычного пользователя` (Always Start as Standard User).
- **Linux:** Throne добавляет файл `Throne.desktop` в `~/.config/autostart` с параметром `-tray`, поэтому программа запускается в трее.
- **macOS:** Throne добавляет объект входа. Окно открывается при входе в систему, если не включён параметр `Запускать приложение свёрнутым`.

Если Throne не может изменить запись автозапуска, он показывает «Не удалось обновить запись автозапуска:» (Could not update the autostart entry:) с указанием причины (начиная с 1.3.2).

### Настройки трея {#tray-settings}

Эти параметры находятся в `Настройки` → `Основные настройки` → `Интерфейс` (Style).

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `Запускать приложение свёрнутым` (Hide dashboard at startup) | Выкл. | Throne запускается только со значком в трее, а окно остаётся скрытым. Параметр командной строки `-tray` делает то же самое. |
| `Откл. сворачивание в трей` (Disable tray) | Выкл. | Убирает значок из трея. После этого закрытие окна завершает работу Throne. |

{% alert_warning() %}
Не включайте `Откл. сворачивание в трей` вместе с `Запускать приложение свёрнутым` или `-tray`. Тогда Throne запустится без окна и без значка в трее. Если это произошло, запустите Throne ещё раз: уже запущенный Throne покажет своё окно.
{% end %}
