На этой странице каждый термин, который встречается в Throne, объясняется одним предложением. Чтобы узнать больше, перейдите по ссылке в последнем столбце.

## Профили и группы {#profiles-and-groups}

| Термин | Значение | Подробнее |
| --- | --- | --- |
| Profile (профиль) | Одна запись сервера или прокси в списке с её протоколом, адресом и настройками. | [Быстрый старт](@/get_started/configuration.ru.md#add-servers) |
| Group (группа) | Вкладка главного окна, в которой хранятся профили; группа бывает типа `Стандартный` (Basic), когда профили добавляете вы, или типа `Подписка` (Subscription), когда она заполняется по URL. | [Подписки и группы](@/guides/subscriptions.ru.md#group-options) |
| Subscription (подписка) | URL от вашего провайдера, который возвращает список профилей; Throne загружает их в группу и может позже обновлять. | [Подписки и группы](@/guides/subscriptions.ru.md#add-subscription) |
| Share link (ссылка для обмена) | Однострочная ссылка на один профиль, например `vless://…` или `ss://…`, которую понимают и другие приложения. | [Протоколы и форматы импорта](@/reference/protocols.ru.md#share-links) |
| Deep link (глубокая ссылка) | Ссылка `throne://`, которая даёт Throne команду выполнить действие, например добавить подписку или профиль маршрутизации. | [Глубокие ссылки](@/advanced/deeplinks.ru.md#format) |
| Throne link (ссылка Throne) | Глубокая ссылка `throne://add/…`, которая содержит один профиль; её можно получить командой `Копировать ссылки выбранных (Диплинк)` (Copy links of selected (Deep Links)). | [Глубокие ссылки](@/advanced/deeplinks.ru.md#add) |
| Chain (цепочка) | Профиль типа `Цепочка прокси` (Chain Proxy), который пропускает трафик через несколько профилей один за другим. | [Цепочки прокси и пользовательские конфигурации](@/advanced/chains.ru.md#chains) |
| Front / landing proxy (фронт-прокси / выходной прокси) | Параметры группы, которые добавляют по одному дополнительному профилю перед каждым профилем группы (фронт-прокси) или после него (выходной прокси). | [Цепочки прокси и пользовательские конфигурации](@/advanced/chains.ru.md#front-landing) |
| Auto selector (автовыбор) | Тип профиля, который проверяет серверы группы и автоматически использует лучшие из них. | [Тестирование и автовыбор](@/guides/testing.ru.md#auto-selector) |
| URL test (тест задержки, URL-тест) | Тест задержки, при котором через профиль открывается `URL теста задержки` (Latency Test URL) и измеряется, сколько времени это занимает. | [Тестирование и автовыбор](@/guides/testing.ru.md#url-test) |

## Ядро и режимы подключения {#core-and-modes}

| Термин | Значение | Подробнее |
| --- | --- | --- |
| Core (ядро) | ThroneCore — фоновая программа, которая передаёт ваш трафик; окно Throne только управляет ею. | [Что такое Throne](@/get_started/_index.ru.md#what-is-throne) |
| sing-box | Движок с открытым исходным кодом, на котором построен ThroneCore; он отвечает за режим TUN, маршрутизацию, DNS и большинство протоколов. | [sing-box или Xray](@/advanced/xray.ru.md) |
| Xray | Второй движок, который работает внутри ядра для профилей `VLESS (Xray)` и конфигураций Xray. | [sing-box или Xray](@/advanced/xray.ru.md#vless-preference) |
| Inbound (входящее подключение) | Способ, которым трафик попадает в Throne: смешанный порт, адаптер TUN или пользовательский inbound. | [Настройки входящих подключений](@/guides/proxy_modes.ru.md#inbound-settings) |
| Outbound (исходящее подключение) | Способ, которым трафик покидает Throne: через профиль (прокси), напрямую или никак (блокировка). | [Маршрутизация](@/guides/routing.ru.md#how-routing-works) |
| Mixed port (смешанный порт) | Локальный порт, который принимает подключения как SOCKS5-, так и HTTP-прокси; по умолчанию `127.0.0.1:2080`. | [Настройки входящих подключений](@/guides/proxy_modes.ru.md#inbound-settings) |
| System proxy (системный прокси) | Режим `Системный прокси` (System Proxy), который указывает смешанный порт в системных настройках прокси, чтобы приложения, учитывающие эти настройки, использовали Throne. | [Системный прокси](@/guides/proxy_modes.ru.md#system-proxy) |
| TUN (режим TUN) | `Режим TUN` (Tun Mode), который создаёт виртуальный сетевой адаптер, чтобы трафик всех приложений проходил через Throne. | [Режим TUN](@/guides/tun_mode.ru.md) |
| Stack (стек) | Способ обработки пакетов в режиме TUN: `system` (сетевой стек вашей системы), `gvisor` (стек, встроенный в ядро) или `mixed` (system для TCP, gVisor для UDP). | [Параметры TUN](@/guides/tun_mode.ru.md#settings) |
| Strict route (строгий маршрут) | Параметр TUN, который не даёт трафику идти в обход туннеля; в Windows 10 и новее он включён по умолчанию. | [Защита от утечек DNS в Windows](@/advanced/windows_tun_mode.ru.md#strict-route) |
| MTU | Максимальный размер пакета для адаптера TUN: по умолчанию 1500 на компьютере и 9000 на Android. | [Параметры TUN](@/guides/tun_mode.ru.md#settings) |

## Маршрутизация и DNS {#routing-and-dns}

| Термин | Значение | Подробнее |
| --- | --- | --- |
| Routing profile (профиль маршрутизации) | Именованный набор правил плюс outbound по умолчанию; одновременно активен ровно один профиль маршрутизации. | [Маршрутизация](@/guides/routing.ru.md#profiles) |
| Rule (правило) | Условие (например, домен, диапазон IP-адресов, набор правил или программа) и действие для подходящих под него подключений; правила проверяются сверху вниз. | [Маршрутизация](@/guides/routing.ru.md#advanced-rules) |
| Rule-set (набор правил) | Готовый список доменов (`geosite-…`) или диапазонов IP-адресов (`geoip-…`) для правил, который загружается как двоичный файл `.srs`. | [Наборы правил](@/guides/routing.ru.md#rule-sets) |
| Default outbound (outbound по умолчанию) | Куда идёт подключение, если ни одно правило не подошло: `proxy`, `direct`, `block` или `warp-bypass`. | [Маршрутизация](@/guides/routing.ru.md#how-routing-works) |
| Direct (напрямую) | Подключение идёт через ваше обычное интернет-соединение, без прокси. | [Маршрутизация](@/guides/routing.ru.md#how-routing-works) |
| Block (блокировка) | Подключение отклоняется. | [Маршрутизация](@/guides/routing.ru.md#how-routing-works) |
| warp-bypass | Подключение идёт через ваш профиль, но в обход WARP, когда WARP включён. | [Cloudflare WARP](@/advanced/warp.ru.md#warp-bypass) |
| Remote routing profile (удалённый профиль маршрутизации) | Профиль маршрутизации, который Throne загружает по URL и может обновлять автоматически. | [Удалённые профили](@/guides/routing.ru.md#remote-profiles) |
| Sniffing (сниффинг) | Throne считывает доменное имя из начала подключения, поэтому правила для доменов работают, даже когда приложение подключается по IP-адресу. | [Маршрутизация](@/guides/routing.ru.md#advanced-rules) |
| DNS routing (DNS-маршрутизация) | Параметр `Включить DNS-маршрутизацию` (Enable DNS Routing): домены, подпадающие под ваши правила `direct`, разрешаются через DNS для прямых запросов, а все остальные запросы идут на `DNS-сервер по умолчанию` (Default DNS server), по умолчанию удалённый. | [DNS](@/guides/dns.ru.md#how-dns-works) |
| Remote DNS / direct DNS (удалённый DNS / DNS для прямых запросов) | Удалённый DNS (по умолчанию `https://8.8.8.8/dns-query`) используется через прокси и является сервером по умолчанию; DNS для прямых запросов (по умолчанию `localhost`, системный резолвер) используется без прокси, отвечает для доменов, подпадающих под правила `direct`, и определяет адреса ваших серверов. | [Настройки DNS](@/guides/dns.ru.md#settings) |
| FakeIP (поддельные IP) | Режим DNS (по умолчанию выключен), который отвечает временными поддельными адресами и сопоставляет их обратно с настоящими доменными именами. | [FakeIP](@/guides/dns.ru.md#fakeip) |

## Протоколы и обход цензуры {#protocols}

| Термин | Значение | Подробнее |
| --- | --- | --- |
| Reality | Параметр безопасности для VLESS, благодаря которому подключение выглядит как посещение настоящего постороннего сайта. | [sing-box или Xray](@/advanced/xray.ru.md#reality) |
| XHTTP | Транспорт Xray, который передаёт подключение внутри обычных HTTP-запросов. | [sing-box или Xray](@/advanced/xray.ru.md#vless-preference) |
| uTLS | Делает рукопожатие TLS похожим на рукопожатие распространённого браузера, например Chrome. | [Пресеты для обхода цензуры](@/advanced/presets.ru.md#utls) |
| ECH | Encrypted Client Hello — скрывает имя сервера внутри рукопожатия TLS. | [Пресеты для обхода цензуры](@/advanced/presets.ru.md#ech) |
| TLS fragment (фрагментация TLS) | Разбивает первое сообщение TLS (Client Hello) на мелкие части, чтобы пройти через некоторые фильтры цензуры. | [Пресеты для обхода цензуры](@/advanced/presets.ru.md#tls-fragment) |
| Multiplex (mux) (мультиплексирование) | Передаёт много подключений внутри одного подключения к серверу с помощью smux, h2mux или yamux. | [Пресеты для обхода цензуры](@/advanced/presets.ru.md#multiplex) |
| WARP | Бесплатный VPN-сервис Cloudflare, который Throne может добавить последним звеном после вашего профиля. | [Cloudflare WARP](@/advanced/warp.ru.md) |
| MASQUE | Туннельный протокол поверх HTTP/3 или HTTP/2; в Throne есть тип профиля `MASQUE`, и WARP может его использовать. | [Cloudflare WARP](@/advanced/warp.ru.md) |

## Конфиденциальность, файлы и безопасность {#files-and-security}

| Термин | Значение | Подробнее |
| --- | --- | --- |
| HWID | Аппаратный идентификатор, который запрашивают некоторые провайдеры; Throne отправляет его, только если вы это включите. | [Конфиденциальность и сетевые запросы](@/reference/privacy.ru.md#hwid) |
| OTP (одноразовый пароль) | Одноразовые пароли (коды TOTP или HOTP), которые запрашивают некоторые серверы OpenVPN и OpenConnect; Throne хранит их в `Утилиты` (Tools) → `Менеджер OTP` (OTP Manager). | [Менеджер OTP](@/advanced/vpn_profiles.ru.md#otp-manager) |
| .thrbackup | Файл резервной копии Throne; создавать и восстанавливать его умеют и приложение для компьютера, и приложение для Android. | [Резервное копирование и восстановление](@/guides/backup.ru.md#backup-restore) |
| Portable mode (портативный режим) | Throne хранит данные в папке `config` рядом с программой, а не в папке пользователя. | [Папка данных](@/reference/files.ru.md#data-folder) |
