На этой странице перечислены все типы профилей в Throne для компьютера 1.3.1 и Throne для Android 2.0.0, ссылки и файлы, которые Throne может импортировать, а также способы поделиться профилем. С её помощью можно проверить, поддерживает ли Throne ваш сервер, прежде чем его импортировать.

## Типы профилей {#protocols}

Чтобы создать профиль вручную, выберите на компьютере `Программа` (Program) → `Новый профиль` (New profile) (`Ctrl+N`), а на Android — `Добавить профиль` (Add profile) → `Ручные настройки` (Manual settings), и укажите тип. Тип существующего профиля изменить нельзя.

| Тип | Компьютер | Android | Примечания |
|---|---|---|---|
| `Автовыбор` (Auto Selector) | Да | Да | Выбирает лучший рабочий профиль группы и переключается автоматически. См. [Автовыбор](@/guides/testing.ru.md#auto-selector). |
| `Socks` | Да | Да | SOCKS версии 5 или 4. |
| `HTTP` | Да | Да | HTTP-прокси, при желании поверх TLS (HTTPS). |
| `Shadowsocks` | Да | Да | Включает шифры 2022 и плагины `obfs-local` и `v2ray-plugin`. |
| `VMess` | Да | Да | |
| `Trojan` | Да | Да | |
| `VLESS` | Да | Да | Реализация sing-box, с поддержкой REALITY. |
| `VLESS (Xray)` | Да | Да | Реализация Xray: XHTTP, REALITY, шифрование VLESS, Finalmask. См. [sing-box или Xray](@/advanced/xray.ru.md#vless-preference). |
| `Hysteria` | Да | Да | Hysteria 1 и Hysteria 2 в одном типе: версию выбирают в поле `Версия протокола` (Protocol Version). Поддерживает смену портов (port hopping) и обфускацию. |
| `TUIC` | Да | Да | |
| `Juicity` | Да | Да | |
| `Naive` | Да | Да | NaïveProxy поверх HTTPS или QUIC. На Android: `Naïve`. |
| `TrustTunnel` | Да | Да | |
| `AnyTLS` | Да | Да | |
| `Mieru` | Да | Да | |
| `Snell` | Да | Да | Snell версии 4 или 6. |
| `ShadowTLS` | Да | Да | |
| `WireGuard` | Да | Да | Для AmneziaWG отметьте `Включить Amnezia` (Enable Amnezia) (на Android: `Enable AmneziaWG`). Может создать учётную запись Cloudflare WARP, см. [WARP](@/advanced/warp.ru.md#generate). |
| `MASQUE` | Да | Да | HTTP/3 или HTTP/2. Может создать идентификационные данные Cloudflare WARP. |
| `OpenVPN` | Да | Да | Импортирует файлы `.ovpn`. Одноразовые пароли (OTP) работают только на компьютере. См. [OpenVPN](@/advanced/vpn_profiles.ru.md#openvpn). |
| `OpenConnect` | Да | Да | Серверы AnyConnect, GlobalProtect, Fortinet, F5, Pulse и Juniper (`nc`). OTP работает только на компьютере. См. [OpenConnect](@/advanced/vpn_profiles.ru.md#openconnect). |
| `Tailscale` | Да | Нет | Подключается к вашей сети Tailscale и может использовать выходной узел. См. [Tailscale](@/advanced/vpn_profiles.ru.md#tailscale). |
| `SSH` | Да | Да | |
| `Direct` | Да | Да | Без прокси. Укажите в профиле интерфейс для привязки (bind interface), чтобы трафик уходил через этот сетевой адаптер. |
| `Польз. (sing-box outbound)` (Custom (sing-box outbound)), `Польз. (sing-box конфигурация)` (Custom (sing-box config)) | Да | Да | Ваш собственный JSON для sing-box: один outbound или полная конфигурация, которая запускается без изменений. На Android: `Пользовательская конфигурация` (Custom config). См. [Пользовательские конфигурации](@/advanced/chains.ru.md#custom-config). |
| `Польз. (Xray outbound)` (Custom (Xray outbound)), `Польз. (Xray конфигурация)` (Custom (Xray config)) | Да | Да | То же самое для JSON Xray. |
| `Доп. ядро` (Extra Core) | Да | Нет | Запускает выбранную вами внешнюю программу и подключается к ней через её локальный SOCKS-порт. См. [Дополнительное ядро](@/advanced/chains.ru.md#extra-core). |
| `Цепочка прокси` (Chain Proxy) | Да | Да | Пропускает трафик последовательно через несколько профилей. На Android: `Прокси-цепочка` (Proxy chain). См. [Цепочки прокси](@/advanced/chains.ru.md#chains). |

Некоторые названия на Android отличаются только регистром букв, например `SOCKS` и `Auto selector`.

### Какой движок запускает профиль {#engines}

ThroneCore, ядро Throne, запускает все типы профилей с помощью sing-box, за двумя исключениями:

- `VLESS (Xray)`, `Польз. (Xray outbound)` и `Польз. (Xray конфигурация)` работают в движке Xray, встроенном в ядро.
- `Доп. ядро` запускает выбранную вами внешнюю программу.

Throne для Android использует то же ядро, поэтому там действуют те же правила. Цепочка может сочетать оба движка, но только в таком порядке: звенья sing-box, затем звенья Xray, затем снова звенья sing-box.

Когда вы импортируете ссылку `vless://`, её тип определяет параметр `Настройки` (Settings) → `Основные настройки` (Basic Settings) → `Ядро` (Core) → `Предпочтение Xray для VLESS` (Xray VLESS Preference). При значении по умолчанию, `XHTTP And Reality`, ссылки с XHTTP или REALITY становятся профилями `VLESS (Xray)`, а остальные — `VLESS`. Ссылки, которым нужна функция, доступная только в Xray (например, шифрование VLESS), всегда становятся `VLESS (Xray)`. См. [sing-box или Xray](@/advanced/xray.ru.md#vless-preference).

## Форматы импорта {#import-formats}

### Где импортировать {#where-to-import}

| Источник | Компьютер | Android |
|---|---|---|
| Буфер обмена | `Ctrl+V` или `Программа` → `Добавить профиль из буфера обмена` (Add profile from clipboard) | `Добавить профиль` → `Импорт из буфера обмена` (Import from clipboard) |
| Файлы | `Программа` → `Добавить профиль из файла` (Add profile from File(s)) (`Ctrl+O`) или перетащите файлы в главное окно | `Добавить профиль` → `Импортировать из файла` (Import from file) |
| QR-коды | `Программа` → `Сканировать QR-код` (Scan QR Code) (`Ctrl+Shift+Q`) считывает QR-коды на ваших экранах. Изображения с QR-кодами тоже можно импортировать как файлы. | `Добавить профиль` → `Отсканировать QR-код` (Scan QR code) (камерой или через `Выбрать изображение` (Select image)) |
| Подписки | Группа типа `Подписка` (Subscription), см. [Подписки и группы](@/guides/subscriptions.ru.md#add-subscription) | То же самое, в разделе `Группы` (Groups) |
| Ссылки | Ссылки `throne://`, см. [Глубокие ссылки](@/advanced/deeplinks.ru.md) | Ссылки `throne://` и ссылки протоколов, которые вы открываете в других приложениях |

Импортированные профили попадают в текущую группу. Если в буфере обмена находится один URL `http://` или `https://`, Throne спрашивает, как его использовать: как новую группу подписки, для однократного импорта в текущую группу или как HTTP-прокси.

### Поддерживаемые форматы {#formats}

Throne для компьютера и Throne для Android понимают одни и те же форматы во вставленном тексте, файлах, QR-кодах и ответах подписок.

| Формат | Результат |
|---|---|
| Ссылки для обмена, по одной на строку: `vless://`, `vmess://`, `ss://`, `trojan://`, `socks://`, `socks4://`, `socks4a://`, `socks5://`, `http://`, `https://`, `hysteria://`, `hysteria2://`, `hy2://`, `tuic://`, `juicity://`, `anytls://`, `mieru://`, `mierus://`, `snell://`, `tt://` (TrustTunnel), `shadowtls://`, `wg://`, `wireguard://`, `ssh://`, `naive+https://`, `naive+quic://` | По одному профилю на каждую ссылку |
| Ссылки Throne: `throne://add/…` и более старые `json://…` | Один профиль любого типа |
| Ссылки AmneziaVPN: `vpn://…` | Конфигурации, содержащиеся в ссылке |
| JSON sing-box: полная конфигурация или массив outbound | По одному профилю на каждый поддерживаемый outbound |
| JSON sing-box: один объект outbound | Один профиль `Польз. (sing-box outbound)` |
| JSON Xray: конфигурация, массив outbound или один outbound | `VLESS (Xray)` для outbound VLESS, `Польз. (Xray outbound)` для остальных |
| JSON Xray: массив полных конфигураций | По одному профилю `Польз. (Xray конфигурация)` на каждую конфигурацию |
| JSON SIP008 (Shadowsocks) | Профили `Shadowsocks` |
| YAML Clash или Mihomo со списком `proxies:` | Профили для записей `socks5`, `http`, `ss`, `vmess`, `vless`, `trojan`, `anytls`, `snell`, `hysteria`, `hysteria2`, `tuic`, `masque` и `ssh` |
| Файл `.conf` WireGuard или AmneziaWG | Один профиль `WireGuard` |
| Файл `.ovpn` OpenVPN | Один профиль `OpenVPN` |
| XML-профиль AnyConnect, командная строка `openconnect` или файл со строкой `protocol=` | Профили `OpenConnect` |
| Любой из перечисленных форматов в кодировке Base64 | Сначала декодируется, затем импортируется |

Записи, которые не являются прокси-серверами, пропускаются, например outbound sing-box `direct`, `block`, `selector` и `urltest` или outbound Xray `freedom` и `blackhole`. Чтобы запустить полную конфигурацию sing-box или Xray, создайте профиль `Польз. (sing-box конфигурация)` (Custom (sing-box config)) или `Польз. (Xray конфигурация)` (Custom (Xray config)) и вставьте в него конфигурацию. См. [Полные конфигурации](@/advanced/chains.ru.md#full-configs).

Оба приложения отклоняют файлы для импорта размером больше 50 MB (на Android это ограничение не касается файлов `.zip`) и ответы подписок больше 64 MB.

### Отличия на Android {#android-import}

- URL подписки также может быть адресом `content://`, который указывает на файл на устройстве.
- `Импортировать из файла` (Import from file) принимает и файл `.zip` и импортирует все файлы внутри него, например несколько конфигураций WireGuard или OpenVPN.
- Ссылки, начинающиеся с `clash://install-config?url=…`, открывают Throne и добавляют URL как подписку.
- Если в другом приложении нажать на ссылку протокола (например, `vless://…`) или на ссылку `throne://`, Throne откроется и перед импортом профиля спросит подтверждение.
- Системное меню «Поделиться» в Android предлагает Throne только для двоичных файлов (`application/octet-stream`), например резервных копий. Чтобы импортировать ссылку из мессенджера, скопируйте её и выберите `Импорт из буфера обмена` (Import from clipboard). Для других файлов используйте `Импортировать из файла`.
- Профили `Tailscale` и `Доп. ядро` (Extra Core) на Android использовать нельзя.

## Ссылки для обмена {#share-links}

### Типы ссылок {#link-types}

| Ссылка | Как выглядит | Кто может её прочитать |
|---|---|---|
| Стандартная ссылка | `vless://…`, `ss://…`, `hysteria2://…` и так далее | Throne и большинство других клиентов |
| Ссылка Throne | `throne://add/…` | Throne для компьютера и Throne для Android |
| Старая ссылка Throne | `json://…` | Throne, только для импорта |

**Стандартная ссылка** использует обычный формат ссылок протокола. У некоторых типов стандартной ссылки нет: `Автовыбор` (Auto Selector), `Цепочка прокси` (Chain Proxy), типы `Польз. (…)` (Custom), `Direct`, `Доп. ядро` (Extra Core), `MASQUE`, `OpenVPN` и `OpenConnect`. Для них Throne выдаёт вместо неё ссылку Throne. Если у такого профиля заданы расширенные параметры подключения, например интерфейс для привязки, Throne вместо ссылки Throne показывает неполную ссылку, которая содержит только эти параметры. Для таких профилей отметьте `Deep Link` или выберите `Копировать ссылки выбранных (Диплинк)` (Copy links of selected (Deep Links)). Для `Tailscale` тоже передавайте ссылку Throne: Throne 1.3.1 не может импортировать ссылку `ts://`, которую он показывает для таких профилей.

**Ссылка Throne** содержит настройки профиля в виде JSON, закодированного в Base64. Она работает для любого типа профиля, включая типы без стандартной ссылки, но прочитать её может только Throne. См. [Глубокие ссылки](@/advanced/deeplinks.ru.md#add). Ссылки `json://` — это формат ссылок Throne, который использовался до версии 1.2.0; Throne по-прежнему их импортирует.

Ссылка на профиль `Цепочка прокси` или `Автовыбор` хранит только внутренние номера профилей или группы, которые он использует, а не сами серверы. Она пригодна только в той же установке Throne.

### Обмен на компьютере {#share-desktop}

Щёлкните профиль в списке правой кнопкой мыши и откройте `Поделиться` (Share):

| Действие | Что вы получаете |
|---|---|
| `QR-код и ссылка` (QR Code and link) | Окно со стандартной ссылкой и её QR-кодом. Отметьте `Deep Link`, чтобы вместо неё показать ссылку Throne. Типы без стандартной ссылки обычно открываются с уже отмеченным `Deep Link` (см. выше). |
| `Скопировать ссылки выбранных` (Copy links of selected) (`Ctrl+C`) | Стандартные ссылки всех выбранных профилей, по одной на строку. Типы без стандартной ссылки обычно копируются как ссылки Throne (см. выше). |
| `Копировать ссылки выбранных (Диплинк)` (Copy links of selected (Deep Links)) (`Ctrl+Alt+C`) | Ссылки Throne всех выбранных профилей. |

Чтобы скопировать ссылки всей группы, откройте `Группы` (Groups) → `Редактировать текущую группу` (Edit current Group) и нажмите `Копировать ссылки профилей` (Copy profile share links) или `Копировать ссылки профилей (Диплинк)` (Copy profile share links (Deep Links)).

`Поделиться` → `Экспортировать конфиг Sing-box` (Export Sing-box config) и `Экспортировать конфиг Xray` (Export Xray config) копируют конфигурацию ядра, которую Throne создаёт для профиля. Это файл конфигурации для других клиентов, а не ссылка для обмена.

Чтобы импортировать QR-код, показанный на экране, выберите `Программа` → `Сканировать QR-код` (`Ctrl+Shift+Q`). Чтобы импортировать QR-код из файла изображения, перетащите файл в главное окно или откройте его через `Программа` → `Добавить профиль из файла`.

### Обмен на Android {#share-android}

Нажмите кнопку «Поделиться» у профиля. В макете `Два столбца` (Double column) вместо этого нажмите ⋮ → `Поделиться` (Share). В меню есть:

- `QR-код` (QR code) → `Стандарт` (Standard) или `Throne link`
- `Экспорт в буфер обмена` (Export to clipboard) → `Стандарт` или `Throne link`
- `Конфигурация` (Configuration) → `Экспорт в буфер обмена` или `Экспорт в файл` (Export to file): конфигурация ядра, которую создаёт Throne, а не ссылка для обмена

Пункта `Стандарт` нет, если у типа профиля нет стандартной ссылки. Цепочками на Android поделиться нельзя. Чтобы скопировать ссылки всей группы, откройте `Группы` (Groups), нажмите `More options` у группы и выберите `Copy profile share links` или `Copy profile share links (deep links)`.

Чтобы импортировать полученный профиль, выберите `Добавить профиль` → `Отсканировать QR-код` или `Импорт из буфера обмена`. Ссылка Throne из буфера обмена или QR-кода импортируется без дополнительного вопроса.
