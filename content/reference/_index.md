This section is for looking things up, not for reading from start to end. It lists the supported protocols and link formats, the keyboard shortcuts and tray menu, where Throne keeps its files and logs, which network requests Throne makes by itself, and what the terms in the app mean.

The commands of `thronectl` are in [Throne API & thronectl](@/advanced/api.md#commands), and the options of headless Throne in [Command Line & Data Directory](@/headless/command_line.md).

If you are new to Throne, start with [Get Started](@/get_started/_index.md) instead.
