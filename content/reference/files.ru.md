На этой странице описаны параметры командной строки Throne для компьютера, место, где Throne хранит ваши данные, назначение каждого файла, расположение логов и способ начать заново с настройками по умолчанию.

## Командная строка {#command-line}

Throne принимает следующие параметры:

| Параметр | Что делает |
| --- | --- |
| `-appdata` | Хранит данные в папке пользователя, а не рядом с программой. См. [Папка данных](#data-folder). |
| `-appdata <folder>` | Хранит данные в `<folder>`. Throne создаёт внутри неё папку `config`. |
| `-tray` | Запускает программу со скрытым окном. Появляется только значок в трее. |
| Ссылка `throne://` | Обрабатывает ссылку так, как если бы вы щёлкнули по ней. См. [Глубокие ссылки](@/advanced/deeplinks.ru.md). |
| Пути к файлам или URL `file://` | Импортирует файлы, как `Программа` (Program) → `Добавить профиль из файла` (Add profile from File(s)). |
| `--headless` | Запускает Throne без окна, как службу или в контейнере (начиная с 1.4.0). См. [Headless Throne](@/headless/_index.ru.md). |
| `--check`, `--health`, `--print-connection` | Проверяют, может ли этот компьютер запускать headless Throne, запрашивают состояние работающего headless Throne или выводят настройки для `thronectl` (начиная с 1.4.0). |

Примеры:

```bash
/opt/Throne/Throne -appdata
./Throne -appdata "$HOME/throne-test"
./Throne -tray
```

```powershell
.\Throne.exe -appdata D:\ThroneData
```

- Throne считает слово после `-appdata` папкой, если оно не начинается с `-`.
- Для одной папки данных может работать только один экземпляр Throne. Если Throne уже запущен, новый запуск передаёт свою ссылку или файлы работающему Throne, выводит его окно на передний план и завершается. Если папку данных использует headless Throne, новый запуск показывает «Throne работает в фоновом режиме» (Throne is running in the background) и завершается; см. [Устранение неполадок](@/help/troubleshooting.ru.md#background-throne).
- У headless Throne больше параметров и собственная папка данных. См. [Командная строка и каталог данных](@/headless/command_line.ru.md).
- **macOS:** чтобы передать параметры, запустите программу внутри пакета приложения, например `/Applications/Throne.app/Contents/MacOS/Throne -tray`. Ссылки, по которым вы щёлкаете, macOS передаёт уже запущенному Throne.

## Папка данных {#data-folder}

Throne хранит ваши данные в папке с именем `config`. Чтобы открыть её, выберите `Настройки` (Settings) → `Открыть папку конфигурации` (Open Config Folder) (только в расширенном режиме, см. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode)).

Throne работает в одном из двух режимов:

- **Портативный режим:** папка `config` находится внутри папки программы Throne.
- **Режим appdata:** папка `config` находится в папке пользователя. Throne использует этот режим, если запущен с `-appdata`, всегда в macOS, а также если не может записывать в собственную папку.

В режиме appdata папка находится здесь:

| Система | Папка данных |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Throne\config`, например `C:\Users\<you>\AppData\Local\Throne\config` |
| Linux | `~/.config/Throne/config` или `$XDG_CONFIG_HOME/Throne/config`, если задана переменная `XDG_CONFIG_HOME` |
| macOS | `~/Library/Preferences/Throne/config` |

Какой режим использует ваша копия, зависит от способа установки:

| Способ установки Throne | Режим | Папка данных |
| --- | --- | --- |
| ZIP для Windows | Портативный | `config` в распакованной папке `Throne` |
| Установщик Windows, для текущего пользователя (по умолчанию) | Портативный | `config` в папке установки, по умолчанию `%LOCALAPPDATA%\Throne\config` |
| Установщик Windows, для всех пользователей | Appdata (автоматически) | `%LOCALAPPDATA%\Throne\config` каждого пользователя |
| ZIP для Linux | Портативный | `config` в распакованной папке `Throne` |
| `.deb`, `.rpm` или скрипт установки для Linux | Appdata | `~/.config/Throne/config` |
| macOS | Appdata | `~/Library/Preferences/Throne/config` |

- Пункт в меню приложений, который создают пакеты `.deb` и `.rpm` и скрипт установки для Linux, запускает `/opt/Throne/Throne -appdata`.
- Если Throne не может записывать в собственную папку, например в `Program Files`, он сам переключается в режим appdata. В первый раз он копирует туда вашу существующую папку `config`. После этого он продолжает использовать папку пользователя, даже если запустить его от имени администратора.
- Пакеты из других источников (WinGet, Scoop, AUR, Nix) могут использовать другие папки. `Открыть папку конфигурации` всегда показывает нужную.

Несколько файлов хранятся рядом с папкой `config`, а не внутри неё: геофайлы Xray `geoip.dat` и `geosite.dat`, а также папка `diagnostics` с файлами из `Основные настройки` (Basic Settings) → `Диагностика` (Diagnostics). В портативном режиме это папка программы Throne. В режиме appdata — папка пользователя, например `%LOCALAPPDATA%\Throne`. Если вы указали для `-appdata` другую папку, то начиная с 1.4.0 это она; при первом запуске Throne копирует туда геофайлы из папки пользователя. До 1.4.0 эти файлы оставались в папке пользователя.

### Файлы в папке конфигурации {#config-files}

| Файл или папка | Что содержит |
| --- | --- |
| `throne.db` | Ваши профили, группы, профили маршрутизации, профили OTP и настройки в базе данных SQLite. Пока Throne работает, рядом с ним появляются `throne.db-wal` и `throne.db-shm`. |
| `throne_stats.db` | Историю трафика для `Утилиты` (Tools) → `Статистика трафика` (Traffic Stats): поминутные данные за последние 48 часов и почасовые данные за 90 дней. `Основные настройки` → `Интерфейс` (Style) → `Отключить агрегацию трафика` (Disable Traffic Aggregation) отключает её сбор. |
| `cache.db` | Кэш ядра: загруженные наборы правил, последний выбор профиля автовыбора и, если включён `Сохранять кэш в файл` (Save Cache To File), кэш DNS. |
| `logs/` | Файлы логов. См. [Логи](#logs). |
| `crashes/` | Аварийные дампы (только Windows). Хранятся 5 самых новых. |
| `icons/` | Собственные значки трея из `Основные настройки` → `Интерфейс` → `Включить пользовательские иконки` (Enable Custom Icons): `Off.png`, `Throne.png` (запущен профиль), `Proxy.png`, `Tun.png` и, начиная с 1.4.0, `Connecting.png`. Без `Connecting.png` Throne показывает `Off.png`, пока профиль запускается или останавливается. |
| `hwid` | Только Linux, начиная с 1.4.0: идентификатор устройства, который Throne создал, потому что в системе нет пригодного `/etc/machine-id` или `/var/lib/dbus/machine-id`. См. [HWID](@/reference/privacy.ru.md#hwid). |
| `.lock` | Начиная с 1.4.0: показывает, что эту папку использует Throne. Throne никогда не удаляет этот файл. |
| `dashboard/` | Файлы веб-панели для Clash API. Throne создаёт эту папку со страницей-заглушкой; замените заглушку файлами панели. |
| `sb-dashboard/` | Веб-панель, которую открывает `Утилиты` → `Открыть веб-панель` (Open Web dashboard). |

Чтобы перенести данные на другой компьютер или на Android, создайте резервную копию `.thrbackup`, а не копируйте файлы. См. [Резервное копирование и восстановление](@/guides/backup.ru.md#backup-restore).

## Логи {#logs}

Вкладка `Логи` (Logs) в нижней части главного окна показывает сообщения Throne и ядра. Щёлкните лог правой кнопкой мыши, чтобы скопировать текст или очистить лог командой `Очистить` (Clear).

- **Прокрутка:** пока вы находитесь в конце лога, вкладка показывает каждую новую строку. Начиная с 1.4.0, если прокрутить вверх, вид остаётся на месте, а новые строки ждут. Кнопка `К последним записям` (Jump to latest) в правом верхнем углу вкладки показывает, сколько строк ждёт; нажмите её или прокрутите лог до конца, чтобы их увидеть.
- **Фильтр:** начиная с 1.4.0 кнопка фильтра в правом верхнем углу вкладки открывает строку фильтра. Введите текст в поле `Фильтр логов` (Filter logs), чтобы показать только подходящие строки с выделенными совпадениями. `Учитывать регистр` (Match case) и `Регулярное выражение` (Regular expression) меняют способ сравнения текста, а строка фильтра показывает, сколько строк подходит. `Esc` или кнопка фильтра закрывает строку фильтра и снова показывает все строки. Этот фильтр меняет только отображение, но не строки, которые хранит Throne.

Параметры логов находятся в `Настройки` → `Основные настройки` → `Логирование` (Logging) (только в расширенном режиме):

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `Макс. кол-во строк в логах` (Max log lines) | `500` (`200` до 1.4.0) | Сколько строк хранит вкладка `Логи`. |
| `Уровень логирования Sing-box` (Sing-box Log level) | `info` | Насколько подробно пишет ядро: `trace`, `debug`, `info`, `warn`, `error`, `fatal` или `panic`. |
| `Уровень логирования Xray` (Xray Log level) | `warning` | Насколько подробно пишет Xray: `debug`, `info`, `warning`, `error` или `none`. |
| `Фильтрация логов` (Log Filtering) | Выкл. | `Использовать правила включения` (Enable Include Rules) показывает только строки, совпадающие с вашими ключевыми словами или регулярными выражениями. `Использовать правила исключения` (Enable Exclude Rules) скрывает совпадающие строки. Строки, которые скрывают эти правила, никогда не попадают на вкладку `Логи`, но остаются в файле лога. |

Параметр `Авто-скролл логов` (Auto-scroll log) удалён в 1.4.0.

Начиная с 1.4.0 вкладка `Логи` использует моноширинный шрифт. Чтобы выбрать другой, используйте `Шрифт логов` (Log Browser Font) и `Размер шрифта логов` (Log Browser Font Size) в `Настройки` → `Основные настройки` → `Интерфейс` (только в расширенном режиме). В списке показаны только моноширинные шрифты. По умолчанию Throne использует первый установленный шрифт из списка Consolas, Menlo, SF Mono, DejaVu Sans Mono, Noto Sans Mono и Ubuntu Mono с размером шрифта интерфейса.

Для отчёта об ошибке установите `Уровень логирования Sing-box` в значение `debug`, снова запустите профиль и воспроизведите проблему. Затем следуйте инструкциям на странице [Как сообщить об ошибке](@/help/bug_reports.ru.md#logs).

### Файл лога {#log-file}

Throne также записывает лог в файл `logs/throne.log` в папке конфигурации.

- Файл начинается с версии Throne, сведений о вашей операционной системе, параметров командной строки и папки логов.
- Он содержит всё, что есть на вкладке `Логи`, и более подробные сведения от самого Throne.
- Throne начинает новый файл при каждом запуске. Когда файл достигает 4 MB, Throne переименовывает его в `throne.log.1` и начинает новый. Хранится до трёх старых частей, от `throne.log.1` до `throne.log.3`.
- Если Throne завершил работу некорректно, он сохраняет лог этого сеанса как `crashed-YYYYMMDD-HHMMSS.log` в той же папке. Хранятся 5 самых новых. При следующем запуске на вкладке `Логи` появляется сообщение «[Предупреждение] В прошлый раз Throne не завершил работу корректно. Результаты диагностики сохранены в: …» («[Warn] Throne did not shut down cleanly last time. Diagnostics were saved to: …»), за которым следует путь к папке логов.

{% alert_warning() %}
Логи могут содержать домены, которые вы посещали, и адреса ваших серверов. Проверьте лог, прежде чем публиковать его.
{% end %}

**Android:** откройте боковое меню и нажмите `Журналы` (Logs). `Поделиться журналом` (Share logs) и `Сохранить журнал…` (Save logs…) экспортируют лог. `Скрывать конфиденциальные данные` (Hide sensitive data) по умолчанию включён. При экспорте он скрывает пароли, ключи, UUID, имена серверов, публичные IP-адреса, названия сетей Wi-Fi и пути в URL. Уровень логирования задаётся в `Настройки` (Settings) → `Ядро` (Core) → `Тип журнала` (Log level) (по умолчанию `warn`). См. [Устранение неполадок на Android](@/android/troubleshooting.ru.md#logs).

## Сброс Throne {#reset}

В Throne нет кнопки сброса. Чтобы начать заново с настройками по умолчанию, дайте Throne новую пустую папку конфигурации:

1. Если хотите что-то сохранить, сначала создайте резервную копию: `Настройки` → `Основные настройки` → `Резервное копирование и восстановление` (Backup and Restore) → `Создать резервную копию` (Create Backup...).
2. Выберите `Настройки` → `Открыть папку конфигурации`, чтобы увидеть, где находится папка.
3. Завершите работу Throne командой `Выход` (Exit) в меню трея или в меню `Программа`. Закрыть окно недостаточно.
4. Переименуйте папку `config`, например в `config-old`.
5. Запустите Throne. Он создаст новую папку `config` с настройками по умолчанию.

Чтобы вернуть часть старых данных, нажмите `Восстановить из копии` (Restore from Backup...) на той же вкладке и выберите только нужные части. См. [Резервное копирование и восстановление](@/guides/backup.ru.md#backup-restore).

Чтобы отменить сброс, завершите работу Throne, удалите новую папку `config` и переименуйте `config-old` обратно в `config`.

Сброс не затрагивает то, что хранится вне папки конфигурации: `Запускать вместе с системой` (Start with system) (это запись автозапуска операционной системы), регистрацию ссылок `throne://` и геофайлы Xray.

**Windows:** если вы установили Throne с помощью установщика, при удалении программа спросит «Also delete your Throne profiles, settings and logs?» (удалить также профили, настройки и логи Throne?). Выберите `Yes`, чтобы удалить и папку конфигурации.

**Android:** `Настройки` (Settings) → `Восстановить настройки по умолчанию` (Restore default settings) сбрасывает все настройки, но сохраняет профили, группы и профили маршрутизации. Затем приложение перезапускается. Чтобы удалить всё, очистите данные приложения в настройках приложений Android. Throne для Android хранит данные в закрытом хранилище приложения, которое файловые менеджеры открыть не могут, поэтому, чтобы скопировать данные наружу, используйте резервную копию `.thrbackup`.
