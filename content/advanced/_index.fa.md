این صفحه‌ها به موضوعات کاربران حرفه‌ای می‌پردازند: انتخاب میان هسته‌های sing-box و Xray، زنجیره‌های پروکسی و پیکربندی‌های سفارشی، پیش‌تنظیم‌های ضدسانسور، Cloudflare WARP، نمایه‌های OpenVPN، OpenConnect و Tailscale، محافظت از نشت DNS در Windows، [کیل‌سوییچ](@/advanced/kill_switch.fa.md)، لینک‌های عمیق `throne://` و [Throne API و thronectl](@/advanced/api.fa.md) برای اسکریپت‌ها و دستگاه‌های دیگر.

برای استفادهٔ روزمره به آن‌ها نیازی ندارید. اگر تازه با Throne آشنا شده‌اید، از [شروع سریع](@/get_started/configuration.fa.md) و [راهنماها](@/guides/_index.fa.md) شروع کنید. بیشتر این موضوعات دربارهٔ [Throne برای Android](@/android/_index.fa.md) هم صدق می‌کنند؛ کیل‌سوییچ و Throne API فقط در نسخهٔ دسکتاپ وجود دارند. برای اجرای Throne بدون پنجره، [Throne بدون رابط گرافیکی](@/headless/_index.fa.md) را ببینید.
