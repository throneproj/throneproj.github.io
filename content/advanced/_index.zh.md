这些页面介绍面向高级用户的主题：在 sing-box 与 Xray 核心之间进行选择、代理链与自定义配置、反审查预设、Cloudflare WARP、OpenVPN、OpenConnect 与 Tailscale 配置档、Windows 上的 DNS 泄漏防护、[断网保护（kill switch）](@/advanced/kill_switch.zh.md)、`throne://` 深度链接，以及供脚本和其他设备使用的 [Throne API 与 thronectl](@/advanced/api.zh.md)。

日常使用并不需要这些内容。如果你刚开始使用 Throne，请先阅读[快速入门](@/get_started/configuration.zh.md)和[使用指南](@/guides/_index.zh.md)。其中大部分主题也适用于 [Throne for Android](@/android/_index.zh.md)；断网保护和 Throne API 是桌面版功能。要在没有窗口的情况下运行 Throne，请参见[无界面 Throne](@/headless/_index.zh.md)。
