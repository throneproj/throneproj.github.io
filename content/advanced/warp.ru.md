WARP — бесплатный VPN-сервис Cloudflare. Throne может добавить WARP как дополнительное звено после вашего прокси. Тогда сайты видят адрес Cloudflare вместо адреса вашего прокси-сервера. Это помогает на сайтах, которые блокируют адреса VPN или дата-центров.

## Как WARP работает в Throne {#how-it-works}

Когда WARP включён, трафик идёт так: ваше устройство → запущенный вами профиль → WARP → интернет.

- WARP применяется к каждому запускаемому профилю, включая цепочки и профили автовыбора. Без него работают только профили `Пользовательский (конфигурация sing-box)` (Custom (sing-box config)). Если у группы есть выходной прокси, WARP идёт после него.
- WARP работает через ваш прокси, поэтому прокси должен пропускать трафик WARP:
  - Режим `WireGuard` использует UDP. Профиль должен пропускать UDP.
  - Режиму `MASQUE` поверх HTTP/3 тоже нужен UDP. MASQUE поверх HTTP/2 нужен только TCP.
- Правила и outbound по умолчанию могут направлять трафик через ваш прокси без WARP. См. [Трафик в обход WARP](#warp-bypass).

Настройка WARP состоит из двух шагов: один раз сгенерировать конфигурацию, затем включить WARP.

## Генерация конфигурации WARP {#generate}

1. Откройте `Маршрутизация` (Routing) → `Настройки маршрутизации` (Routing Settings).
2. Откройте вкладку `Warp`.
3. Выберите режим в поле `Режим` (Mode): `WireGuard` или `MASQUE`.
4. Нажмите `Сгенерировать конфигурацию Warp` (Generate Warp Config).
5. В первый раз Throne спросит, принимаете ли вы условия использования Cloudflare WARP. Нажмите `Да` (Yes).
6. Дождитесь, пока на кнопке появится «Успешно!» (Success!). Теперь поля выбранного режима заполнены.
7. Нажмите `OK`.

В простом режиме `Warp` — это раздел вкладки `Основные` (Common), в котором есть только `Включить Warp` (Enable Warp), `Режим` (Mode) и `Сгенерировать конфигурацию Warp` (Generate Warp Config). Поля ниже и `Домены регистрации…` (Registration Domains…) скрыты (только в расширенном режиме, см. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode)).

У каждого режима свои поля. Если позже вы переключите `Режим`, сгенерируйте конфигурацию и для этого режима.

| Режим | Поля |
| --- | --- |
| `WireGuard` | `Endpoint`, `Private Key`, `Public Key`, `Адреса интерфейса` (Interface Addresses), `Reserved` |
| `MASQUE` | `Endpoint`, `Private Key`, `Peer Public Key`, `Адреса интерфейса`, `SNI`, `Версия HTTP` (HTTP Version) |

`Версия HTTP` для MASQUE может быть `HTTP/3 (с откатом на HTTP/2)` (HTTP/3 (fallback to HTTP/2)) (по умолчанию), `Только HTTP/3` (HTTP/3 only) или `HTTP/2`. HTTP/3 работает поверх UDP. HTTP/2 работает поверх TLS по TCP и подходит там, где UDP заблокирован.

Каждая генерация регистрирует в Cloudflare новое устройство.

### Если регистрация не удаётся {#registration-fails}

Сервер регистрации Cloudflare, `api.cloudflareclient.com`, заблокирован в некоторых странах ([#1874](https://github.com/throneproj/Throne/issues/1874)). В этом случае регистрируйтесь через свой прокси:

1. Запустите рабочий профиль.
2. Откройте `Настройки` (Settings) → `Основные настройки` (Basic Settings) → `Прочее` (Miscellaneous) и отметьте `Использовать прокси` (Use proxy). В простом режиме `Использовать прокси` находится в разделе `Настройки сети` (Network Settings) вкладки `Общие` (Common). Когда включён `Системный прокси` (System Proxy), Throne и так отправляет собственные запросы через прокси.
3. Снова нажмите `Сгенерировать конфиг Warp`.

Если при включённом `Использовать прокси` или `Системный прокси` ни один профиль не запущен, генерация завершается ошибкой «Запрос через прокси, но профиль не запущен» (Request with proxy but no profile started).

Такие запросы Throne отправляет на свой локальный порт прокси. Начиная с версии 1.4.0, если включено `Отключить mixed inbound` (Disable Mixed Inbound), Throne вместо этого отправляет их напрямую, а режим TUN проводит их через запущенный профиль. Если режим TUN тоже выключен, генерация завершается ошибкой «Request with proxy but the mixed inbound is disabled and Tun Mode is off.» (запрос через прокси, но mixed inbound отключён, а режим TUN выключен).

Когда включён [kill switch](@/advanced/kill_switch.ru.md), собственные запросы Throne блокируются, если они не идут через Throne. Генерируйте конфиг, пока профиль запущен в режиме TUN или с включённым `Использовать прокси` (Use proxy).

В `Домены регистрации…` (Registration Domains…) хранятся домены API Cloudflare, по одному на строку. Throne перебирает их по порядку и использует первый, который принимает регистрацию. Пустой список означает `api.cloudflareclient.com`.

## Включение WARP {#enable}

Нажмите `Маршрутизация` → `Включить Warp` (Enable Warp). Галочка показывает, что WARP включён. Чтобы выключить WARP, нажмите этот пункт ещё раз. Запущенный профиль перезапускается с новой настройкой.

Можно также отметить `Включить Warp` на вкладке `Warp` и нажать `OK`. Затем запустите профиль заново, чтобы изменение вступило в силу.

Если WARP включён, а для текущего режима конфигурация не сгенерирована, профиль не запускается, и Throne показывает «Warp is enabled but its config has not been generated. Please generate the Warp config first in Routing Settings.» (WARP включён, но его конфигурация не сгенерирована; сначала сгенерируйте её в настройках маршрутизации). В простом режиме `Настройки маршрутизации` (Routing Settings) также показывают «У WARP ещё нет конфигурации: нажмите «Сгенерировать конфигурацию Warp».» (WARP has no config yet: click Generate Warp Config.), пока отмечен `Включить Warp` (Enable Warp), а для текущего режима нет конфигурации.

Чтобы проверить, что WARP работает, откройте сайт, который показывает ваш IP-адрес. Там должен быть адрес Cloudflare.

## Трафик в обход WARP {#warp-bypass}

`warp-bypass` — это outbound, который использует ваш профиль без звена WARP. Используйте его в профиле маршрутизации:

| Цель | `Outbound по умолчанию` (Default outbound) | Правила |
| --- | --- | --- |
| Большая часть трафика через WARP, некоторые сайты — без него | `proxy` | Добавьте эти сайты в поле `Warp-bypass`. |
| Большая часть трафика без WARP, некоторые сайты — через него | `warp-bypass` | Добавьте эти сайты в поле `Прокси` (Proxy). |

Список `Outbound по умолчанию` и поле `Warp-bypass` находятся в редакторе профиля маршрутизации: `Настройки маршрутизации` → вкладка `Маршрутизация` (Route) → выберите профиль → `Редактировать` (Edit). Расширенные правила тоже могут использовать `warp-bypass` в качестве outbound. Формат правил описан на странице [Маршрутизация](@/guides/routing.ru.md#simple-rules).

Когда WARP выключен, `warp-bypass` работает так же, как `proxy`.

## WARP как обычный профиль {#warp-profiles}

WARP можно сделать и отдельным профилем, например чтобы пользоваться им без другого прокси или в качестве звена цепочки.

1. Откройте `Программа` (Program) → `Новый профиль` (New profile).
2. Установите `Тип` (Type) в значение `WireGuard` или `MASQUE`.
3. Нажмите `Сгенерировать конфиг Warp` (Generate Warp Config, WireGuard) или `Сгенерировать учётные данные WARP` (Generate WARP identity, MASQUE). Throne заполнит ключи, адреса, MTU и адрес сервера.
4. Введите `Название` (Name) и нажмите `OK`.

Сам по себе такой профиль подключается к Cloudflare напрямую. Пока вы им пользуетесь, держите `Включить Warp` выключенным, иначе Throne добавит после него второе звено WARP.

## Android {#android}

- Настройки находятся в `Настройки` (Settings) → `Маршрутизация` (Routing) → `WARP`: `Включить WARP` (Enable WARP), `Режим` (Mode), поля каждого режима, `Создать конфигурацию` (Generate WARP config) и `Домены регистрации` (Registration domains).
- При первой генерации приложение попросит принять условия использования Cloudflare WARP.
- Если регистрация заблокирована, сначала подключитесь и включите `Настройки` → `Подписки` (Subscriptions) → `Использовать прокси` (Use proxy). В режиме `Только прокси` (Proxy only) запрос тоже идёт через прокси, пока запущен профиль. Если ни один профиль не запущен, генерация завершается ошибкой при включённом `Использовать прокси`. После 2.0.3 сам по себе режим `Только прокси` больше не приводит к ошибке: запрос тогда идёт напрямую.
- Чтобы быстро переключить WARP, откройте меню (⋮) экрана `Конфигурация` (Profiles) → `Маршрутизирующий профиль` (Routing profile), затем нажмите `Включить WARP` (Enable WARP) или `Отключить WARP` (Disable WARP).
- Если WARP включён, а конфигурация не сгенерирована, Android показывает «WARP включён, но его конфигурация не создана. Создайте её в Настройки › Маршрутизация › WARP.» (WARP is enabled but its config has not been generated. Generate it in Settings › Routing › WARP.).
- В редакторах профилей WireGuard и MASQUE есть кнопка `Создать идентификатор WARP` (Generate WARP identity).
