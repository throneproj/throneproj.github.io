These pages cover power-user topics: choosing between the sing-box and Xray cores, proxy chains and custom configs, anti-censorship presets, Cloudflare WARP, OpenVPN, OpenConnect and Tailscale profiles, DNS leak protection on Windows, the [kill switch](@/advanced/kill_switch.md), `throne://` deep links, and the [Throne API and thronectl](@/advanced/api.md) for scripts and other devices.

You do not need them for everyday use. If you are new to Throne, start with [Quick Start](@/get_started/configuration.md) and the [Guides](@/guides/_index.md). Most of these topics also apply to [Throne for Android](@/android/_index.md); the kill switch and the Throne API are desktop features. To run Throne without a window, see [Headless Throne](@/headless/_index.md).
