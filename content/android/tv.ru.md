Throne для Android работает и на устройствах Android TV: ТВ-приставках, ТВ-стиках и смарт-телевизорах. Сенсорный экран и камера ему не нужны, а управлять им можно с пульта. На этой странице описано, чем работа на телевизоре отличается от работы на телефоне.

## Установка на телевизор {#install-tv}

Скачайте APK на [странице загрузок](@/downloads.ru.md) и установите его самостоятельно. После установки Throne появится в списке приложений на главном экране телевизора.

### Выбор APK {#tv-apk}

Многие ТВ-приставки и стики работают на 32-битной системе Android, даже если их процессор 64-битный. Им нужен APK `armeabi-v7a`. Телевизорам с 64-битной системой Android нужен `arm64-v8a`.

Чтобы проверить свой телевизор, подключитесь к нему через adb (см. [Установка через adb](#install-adb)) и выполните команду из раздела [Выбор нужного APK](@/android/installation.ru.md#choose-apk). Без adb сначала попробуйте `arm64-v8a`. Если Android откажется его устанавливать, используйте `armeabi-v7a`.

### Установка через файловый менеджер {#install-file-manager}

1. Скопируйте APK на USB-накопитель и подключите его к телевизору или скачайте APK прямо на телевизоре.
2. Откройте APK в приложении файлового менеджера на телевизоре.
3. Когда Android спросит, разрешите файловому менеджеру устанавливать неизвестные приложения.
4. Подтвердите установку.

### Установка через adb {#install-adb}

1. На телевизоре включите параметры разработчика и отладку по USB. На многих устройствах для этого нужно открыть в настройках телевизора раздел «Об устройстве» (About) и семь раз нажать OK на пункте «Сборка» (Build). После этого переключатель отладки находится в параметрах разработчика. Названия на разных устройствах различаются.
2. На компьютере в той же сети выполните `adb connect` с IP-адресом телевизора.
3. Разрешите запрос на отладку, который появится на телевизоре.
4. Выполните `adb install` с файлом APK.

```bash
adb connect 192.168.1.50
adb install Throne-2.0.0-armeabi-v7a.apk
```

Throne 2.0.0 нельзя установить поверх более старой версии. См. [Переход с 1.x или NekoBox](@/android/installation.ru.md#upgrading).

## Управление с пульта {#navigation}

| Кнопка пульта | Что делает |
| --- | --- |
| Влево у левого края экрана | Открывает боковое меню навигации. Кнопки, вкладки и элементы панели инструментов, расположенные левее, сначала получают фокус. |
| Вправо при открытом боковом меню | Закрывает боковое меню. |
| Вниз в конце списка | Переводит фокус на кнопку подключения, а затем на полосу подключения внизу. |
| OK на профиле | Выбирает профиль. Если Throne подключён, переключается на этот профиль. |
| OK на выбранном профиле | Запускает или останавливает подключение. |
| Удержание OK на профиле | Включает множественный выбор, чтобы выполнять действия сразу с несколькими профилями. |
| Play/Pause | Запускает или останавливает подключение, пока Throne открыт. |

В языках с письмом справа налево боковое меню находится справа, поэтому кнопки «Влево» и «Вправо» меняются ролями.

Во время подключения полоса подключения внизу показывает «Подключено, нажмите для проверки подключения» (Connected, tap to check connection). Переведите на неё фокус и нажмите OK, чтобы проверить подключение.

### Переключение серверов {#switch-servers}

На ТВ-устройствах обычно нет виджетов главного экрана и кнопок в уведомлениях. На телевизоре на панели инструментов списка профилей есть две дополнительные кнопки: `Previous server` и `Next server`.

- Когда Throne подключён, они переключают подключение на предыдущий или следующий профиль текущей группы.
- Когда Throne остановлен, они только меняют выбранный профиль.

Они следуют порядку списка профилей. После последнего профиля они снова начинают с первого.

### Изменение порядка профилей {#reorder}

Перетаскивать профили с пульта нельзя. Вместо этого откройте меню ⋮ профиля и выберите `Move up` или `Move down`. Эти пункты есть на любом устройстве, но они скрыты, пока активен фильтр поиска. На экране `Группы` (Groups) в меню ⋮ группы тоже есть `Move up` и `Move down`.

## Добавление профилей без камеры {#import}

У телевизора обычно нет камеры, а скопировать текст в его буфер обмена сложно. Используйте вместо этого один из следующих способов:

- **Введите URL подписки.** Откройте `Группы` (Groups) → `New group`, в поле `Type` выберите `Подписка` (Subscription), введите `URL` и сохраните. Затем нажмите `Update subscription` у новой группы. Новая группа не обновляется автоматически.
- **Импортируйте текстовый файл.** Сохраните ссылки для обмена или URL подписки в текстовый файл на USB-накопителе. В списке профилей откройте `Добавить профиль` (Add profile) → `Импортировать из файла` (Import from file) и выберите файл.
- **Восстановите файл резервной копии.** Создайте резервную копию `.thrbackup` на телефоне или компьютере и скопируйте её на USB-накопитель. Откройте файл из файлового менеджера на телевизоре, и Throne предложит восстановить его. Также можно использовать `Инструменты` (Tools) → `Restore`. См. [Резервное копирование, обновление и перенос](@/guides/backup.ru.md#desktop-android).
- **Восстановите из WebDAV.** На телефоне настройте `Инструменты` (Tools) → `Настройки WebDAV` (WebDAV settings) и выполните `Резервное копирование в WebDAV` (Back up to WebDAV). На телевизоре укажите тот же сервер в `Инструменты` → `Настройки WebDAV`, затем выполните `Восстановление из WebDAV` (Restore from WebDAV).

### Через adb {#import-adb}

Если вы пользуетесь adb, есть ещё два способа. Чтобы открыть в Throne ссылку `throne://` или ссылку для обмена, отправьте её как ссылку:

```bash
adb shell am start -a android.intent.action.VIEW -d "throne://addsub/<base64>"
```

Если ссылка содержит `&`, заключите её в одинарные кавычки внутри двойных.

На устройствах без камеры пункт `Отсканировать QR-код` (Scan QR code) в приложении скрыт. Чтобы прочитать QR-код с изображения, откройте сканер через adb:

```bash
adb shell am start -n com.nb4a.throne/io.nekohasekai.sagernet.ui.ScannerActivity
```

Throne покажет «No camera: choose an image with a QR code» (камеры нет: выберите изображение с QR-кодом) и откроет выбор изображений. Выберите одно или несколько изображений с QR-кодами.

## Разрешение на VPN на телевизоре {#vpn-consent}

При первом подключении в режиме VPN Android попросит разрешить VPN. Выберите OK.

В некоторых сборках для телевизоров и AOSP нет экрана для этого вопроса. Тогда Throne показывает «VPN confirmation unavailable» (подтверждение VPN недоступно). Можно один раз разрешить VPN командой adb или использовать режим `Только прокси` (Proxy only). См. [Разрешение на VPN](@/android/permissions.ru.md#vpn-permission).

В режиме `Только прокси` Throne используют только приложения, которые вы направили на локальный прокси. Если в телевизоре есть настройка прокси для сетевого подключения, укажите в ней хост `127.0.0.1` и порт `2080` — значение параметра `Порт прокси SOCKS5` (Proxy port). Тогда Throne будут использовать приложения, которые следуют системным настройкам прокси. Удалите эту настройку, когда перестанете пользоваться Throne, потому что, пока прокси не запущен, эти приложения не смогут подключиться.

## Сохранение и открытие файлов {#files}

На некоторых ТВ-устройствах нет системного экрана для выбора места сохранения файла. Когда на таком устройстве вы сохраняете резервную копию, экспортируете профили или сохраняете логи, Throne сохраняет файл в `Download/Throne` и показывает полный путь в сообщении «No file picker» (нет средства выбора файлов). На Android 9 и старее это папка `Android/data/com.nb4a.throne/files`.

Для открытия файла, например через `Импортировать из файла` (Import from file) или `Restore`, нужно средство выбора файлов. Если Throne показывает «На вашем устройстве отсутствует стандартный селектор файлов Android, установите его, например Material Files.», установите приложение файлового менеджера, которое его предоставляет. Чтобы скопировать файл на телевизор через adb, используйте `adb push`, например:

```bash
adb push Throne-backup-20260925-120000.thrbackup /sdcard/Download/
```
