Throne для Android — это версия Throne для устройств на Android. Раньше она называлась NekoBox for Android. Начиная с версии 2.0.0 она работает на том же ядре, что и Throne для компьютера (ThroneCore), поэтому группы, подписки, профили маршрутизации, DNS, пресеты, автовыбор, WARP и резервные копии работают в обоих приложениях одинаково.

Страницы этого раздела описывают то, что относится только к Android: установку, разрешения, режимы VPN и прокси, виджеты, Android TV и устранение неполадок. Если вы впервые пользуетесь приложением, выполните шаги из раздела [Быстрый старт](#quick-start), а затем прочитайте страницу [Разрешения и работа в фоне](@/android/permissions.ru.md), чтобы Android не останавливал VPN.

Функции, общие для обоих приложений, описаны в этих руководствах:

- [Подписки и группы](@/guides/subscriptions.ru.md)
- [Маршрутизация](@/guides/routing.ru.md)
- [DNS](@/guides/dns.ru.md)
- [Тестирование и автовыбор](@/guides/testing.ru.md)
- [Cloudflare WARP](@/advanced/warp.ru.md)
- [Перенос между компьютером и Android](@/guides/backup.ru.md#desktop-android)

Пункт `Документы` (Documentation) в боковом меню приложения (выдвижной панели) открывает этот сайт.

## Быстрый старт {#quick-start}

1. Установите APK для своего устройства. Большинству телефонов нужен `arm64-v8a`. См. [Выбор нужного APK](@/android/installation.ru.md#choose-apk).
2. Откройте Throne. На Android 13 и новее разрешите уведомления.
3. Когда Throne покажет запрос «Keep Throne running» (оставить Throne работающим), нажмите `Allow` и подтвердите в диалоге Android. См. [Разрешения и работа в фоне](@/android/permissions.ru.md).
4. Скопируйте URL своей подписки.
5. На экране `Конфигурация` (Profiles) нажмите на панели инструментов `Добавить профиль` (Add profile) — значок страницы со знаком плюс, — а затем `Импорт из буфера обмена` (Import from clipboard). Чтобы вместо этого отсканировать QR-код, выберите `Отсканировать QR-код` (Scan QR code).
6. Throne распознает URL и спросит «How to update?» (как обновлять?). Нажмите `Create new subscription group`. Throne добавит группу, названную по имени хоста из URL, и загрузит её профили.
7. Нажмите на вкладку новой группы.
8. Нажмите ⋮ (`More options`) → `URL test`. На панели отображаются ход проверки и сводка результатов. У каждого профиля в списке показан его собственный результат.
9. Когда тест завершится, нажмите `Select fastest` или нажмите на работающий профиль.
10. Нажмите круглую кнопку подключения внизу экрана. В первый раз Android спросит, может ли Throne настроить VPN-подключение. Разрешите это.
11. Чтобы проверить подключение, нажмите на полосу внизу экрана («Подключено, нажмите для проверки подключения»). Если трафик проходит через профиль, на ней появится «HTTP-соединение установлено за … мс» (Success: HTTP handshake took …ms).

Если провайдер дал вам ссылку `throne://addsub/…`, откройте её на телефоне вместо шагов 4–6. Throne спросит «Add this subscription?» (добавить эту подписку?), добавит группу, загрузит её профили и откроет экран `Группы` (Groups). Затем откройте экран `Конфигурация` (Profiles) и продолжайте с шага 7.

Throne не появляется в меню Android «Поделиться», когда вы делитесь текстовой ссылкой из другого приложения. Вместо этого скопируйте ссылку и используйте `Импорт из буфера обмена` (Import from clipboard).

## Отличия от версии для компьютера {#differences}

У двух приложений общее ядро и большинство настроек. Вот что работает по-разному:

| Область | Throne для компьютера | Throne для Android |
| --- | --- | --- |
| Как трафик попадает в Throne | Флажки `Режим TUN` (Tun Mode) и `Системный прокси` (System Proxy) | `Настройки` (Settings) → `General` → `Сервисный режим` (Service mode): `VPN` (по умолчанию) или `Только прокси` (Proxy only). См. [Режимы VPN и прокси](@/android/modes.ru.md). |
| Выбор приложений | Правила маршрутизации по имени или пути процесса | Прокси для отдельных приложений — `Режим VPN для приложений` (Apps VPN mode) — и правила маршрутизации по приложениям |
| Резервные копии | Файлы `.thrbackup` | Файлы `.thrbackup`, в том числе на сервере WebDAV |
| MTU TUN по умолчанию | 1500 | 9000 |
| Уровень логирования ядра по умолчанию | `info` | `warn` |
| Ссылка `throne://add/…`, открытая из другого приложения | Сразу импортирует профиль | Сначала спрашивает «Импортировать профиль» (Import profile) |
| Raw-профили маршрутизации | Поддерживаются | Не поддерживаются. Raw-профили из резервной копии с компьютера сохраняются только для чтения. |
| TLS spoof, профили Tailscale и дополнительного ядра (Extra Core), менеджер OTP (OTP Manager), конечные точки OpenVPN и OpenConnect в профилях маршрутизации | Доступны | Недоступны |

Ссылки для обмена, например `vless://…`, открытые из другого приложения, тоже сначала вызывают вопрос «Импортировать профиль». Ссылки на профили, которые вы вставляете через `Импорт из буфера обмена` или сканируете как QR-код, импортируются без вопросов.

Кроме того, на Android есть виджеты главного экрана, плитка быстрых настроек и системная постоянная VPN (Always-on VPN). См. [Виджеты, плитка и автоматизация](@/android/widgets.ru.md) и [Постоянная VPN](@/android/permissions.ru.md#always-on). Правилам маршрутизации, которые проверяют подключённую сеть Wi-Fi, на Android нужен доступ к местоположению. См. [Местоположение для правил Wi-Fi](@/android/permissions.ru.md#location).

## Меню версии для компьютера на Android {#menus}

В общих руководствах показаны меню версии для компьютера. На Android те же параметры находятся здесь:

| Throne для компьютера | Throne для Android |
| --- | --- |
| `Группы` (Groups) → `Управление группами` (Manage Groups) | Боковое меню → `Группы` (Groups) |
| `Маршруты` (Routing) → `Настройки маршрутизации` (Routing Settings) → вкладка `Маршрут` (Route) | Боковое меню → `Маршруты` (Routing) |
| `Настройки маршрутизации` (Routing Settings) → вкладка `Основные` (Common) | `Настройки` (Settings) → `Routing` |
| `Настройки маршрутизации` → вкладка `DNS` | `Настройки` → `DNS` |
| `Настройки маршрутизации` → вкладка `Warp` | `Настройки` → `Routing` → `WARP` |
| `Настройки` (Settings) → `Настройки режима TUN` (Tun Settings) | `Настройки` → `TUN / VPN` |
| `Настройки` → `Предустановленные настройки` (Preset Settings) | `Настройки` → `Presets` |
| `Настройки` → `Основные настройки` (Basic Settings) → `Подписка` (Subscription) | `Настройки` → `Подписки` (Subscriptions) |
| `Настройки` → `Основные настройки` → `Резервное копирование и восстановление` (Backup and Restore) | Боковое меню → `Инструменты` (Tools) |
