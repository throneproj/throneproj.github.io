Подписка — это ссылка от вашего провайдера, по которой можно получить список серверов. Throne хранит каждую подписку в отдельной группе и умеет обновлять её за вас. На этой странице рассказано, как добавлять и обновлять подписки, какие параметры есть у группы и что делать, если обновление не удалось.

## Группы и подписки {#groups}

Каждая вкладка над списком профилей — это группа. У группы один из двух типов:

- **Стандартный (Basic).** Содержит профили, которые вы добавляете сами, например из ссылок, файлов, QR-кодов или через `Программа` (Program) → `Новый профиль` (New profile).
- **Подписка (Subscription).** Дополнительно имеет `URL`. Throne загружает список профилей с этого адреса и поддерживает группу в соответствии с ним.

Тип выбирается при создании группы. Изменить его позже нельзя.

{% alert_info() %}
Обновление приводит группу подписки в соответствие со списком провайдера. Оно удаляет профили, которых нет в списке, и отменяет изменения, которые вы внесли в остальные. Храните собственные профили в группе типа `Стандартный` (Basic).
{% end %}

## Добавление подписки {#add-subscription}

### Из буфера обмена {#from-clipboard}

1. Скопируйте адрес подписки. Он начинается с `https://` или `http://`.
2. В Throne нажмите `Ctrl+V` или выберите `Программа` → `Добавить профиль из буфера обмена` (Add profile from clipboard).
3. Throne покажет адрес и спросит «Как обновить?» (How to update?). Выберите `Создать новую группу подписки` (Create new subscription group) и нажмите `OK`.

Throne создаст группу, названную по имени хоста из адреса, и сразу загрузит её профили. Тот же вопрос появляется, когда адрес получен из файла, QR-кода или текста, перетащенного в окно. Три варианта работают так:

| Вариант | Результат |
| --- | --- |
| `Добавить профили в эту группу` (Add profiles to this group) | Загружает список один раз и добавляет профили в текущую группу. Throne не сохраняет адрес, поэтому эти профили никогда не обновляются. |
| `Создать новую группу подписки` (Create new subscription group) | Создаёт группу подписки и загружает её. |
| `Импортировать профиль HTTP-прокси` (Import HTTP proxy profile) | Считает адрес HTTP-прокси-сервером и добавляет его как один профиль. |

### Создание группы вручную {#create-group}

1. Выберите `Группы` (Groups) → `Добавить новую группу` (Add new Group).
2. Введите `Название` (Name).
3. В поле `Тип` (Type) выберите `Подписка` (Subscription).
4. Вставьте адрес в поле `URL`.
5. Нажмите `OK`.
6. Щёлкните новую вкладку правой кнопкой мыши и выберите `Обновить подписку` (Update subscription).

Создание группы не загружает её содержимое. Группа остаётся пустой до первого обновления на шаге 6.

`Группы` → `Управление группами` (Manage Groups) открывает окно со всеми группами. Там же можно создавать группы кнопкой `Новая группа` (New group). В каждой строке показаны тип, число профилей, адрес и время последнего обновления. Если провайдер передаёт сведения о квоте, в строке также отображаются `Использовано` (Used), `осталось` (Remain) и `истекает` (Expire), оставшееся время и, пока включено автоматическое обновление, интервал обновления. См. [Сведения от провайдера](#provider-info). В каждой строке есть кнопки `Изменить` (Edit) и `Удалить` (Remove), а в строках подписок — ещё и `Обновить подписку` (Update Subscription).

### По ссылке throne:// {#from-link}

Ссылка `throne://addsub/…`, например на сайте вашего провайдера, открывает окно `Добавить подписку` (Add subscription) с названием и адресом. Оставьте флажок `Авто-обновление` (Auto update) установленным, если группа должна участвовать в автоматических обновлениях, и нажмите `OK`. После этого Throne создаст группу и загрузит её. См. [Глубокие ссылки](@/advanced/deeplinks.ru.md#addsub).

## Обновление подписки {#update}

Чтобы обновить одну группу, воспользуйтесь одним из способов:

- Щёлкните вкладку группы правой кнопкой мыши и выберите `Обновить подписку` (Update subscription).
- Выберите вкладку и нажмите `Ctrl+U` или выберите `Группы` → `Обновить подписку`.
- Нажмите `Обновить подписку` (Update Subscription) рядом с группой в окне `Группы` → `Управление группами`.

`Группы` → `Обновить все подписки` (Update all subscriptions) обновляет все группы подписок, включая группы с флажком `Пропустить автоматическое обновление` (Skip automatic update).

Во время обновления Throne:

- Загружает список и сравнивает его с профилями в группе. Профили, которые не изменились, сохраняют результаты тестов. Изменённые профили обновляются. Новые профили добавляются, а профили, которых больше нет в списке, удаляются.
- Располагает профили в том же порядке, что и в списке провайдера. Если вы отсортировали группу по столбцу, после обновления Throne сортирует её снова (начиная с 1.4.0). См. [Сортировка и фильтрация](@/guides/testing.ru.md#sort-filter).
- Ничего не меняет, если в ответе нет ни одного профиля. В логе тогда появляется сообщение «No profiles found in the subscription: *group* was left unchanged.» (в подписке не найдено профилей, группа оставлена без изменений). Это защищает группу от пустого или заблокированного ответа. Если провайдер прислал вместе с пустым списком объявление, Throne показывает и его.
- Прекращает загрузку, если сервер не присылает данных в течение 10 секунд или если ответ больше 64 МБ.

Параметр `Настройки` (Settings) → `Основные настройки` (Basic Settings) → `Подписка` (Subscription) → `Очищать список серверов перед обновлением подписки` (Clear servers before updating subscription) по умолчанию выключен. Если его включить, Throne удаляет профили группы перед каждым обновлением, поэтому их результаты тестов теряются.

### Отчёт об изменениях {#change-report}

Каждое обновление записывает отчёт на вкладку `Логи` (Logs). Он начинается со слова `Изменение` (Change of) и названия группы. Каждая строка начинается с `[+]` (добавлен), `[~]` (обновлён), `[-]` (удалён) или `[=]` (сохранён). Если ничего не изменилось, в отчёте написано `Ничего` (Nothing).

После ручного обновления одной группы Throne также показывает отчёт в отдельном окне. Чтобы отключить это окно, снимите флажок `Настройки` → `Основные настройки` → `Подписка` → `Отображать окно с изменениями после обновления подписки вручную` (Show the changes window after a manual subscription update). Автоматические обновления и `Обновить все подписки` только пишут в лог.

Начиная с 1.4.0, отчёт также перечисляет проблемы: сколько записей не удалось импортировать или удалось импортировать только с предупреждениями, и почему — например, из-за недопустимого порта. Если при ручном обновлении или при импорте из буфера обмена или файла возникли проблемы, Throne показывает их в отдельном окне, а полный список — в подробностях этого окна.

### Профиль, который вы используете {#running-profile}

Обновление не останавливает и не удаляет профиль, к которому вы подключены. Если провайдер удалил его, Throne сохраняет профиль и указывает его в отчёте в разделе «Still in use, so kept instead of deleted» (ещё используется, поэтому сохранён, а не удалён). Чтобы вместо этого Throne останавливал и удалял такой профиль, включите `Настройки` → `Основные настройки` → `Подписка` → `Разрешить остановку активного профиля` (Allow stopping the active profile).

Если провайдер изменил параметры запущенного профиля, Throne сохраняет новые параметры, но подключение продолжает работать со старыми. Запустите профиль заново, чтобы применить новые параметры. Запущенный [автовыбор](@/guides/testing.ru.md#auto-selector) перезапускается сам, когда обновление заменяет используемые им профили.

## Сведения от провайдера {#provider-info}

Многие провайдеры передают вместе с подпиской сведения о вашем тарифе: израсходованный и общий трафик, дату окончания, название, ссылки на свой сайт и поддержку, объявление и рекомендуемую частоту обновления. Throne читает их из заголовков ответа `Subscription-UserInfo`, `Profile-Title`, `Profile-Web-Page-Url`, `Support-Url`, `Announce` и `profile-update-interval` или из строк-комментариев `#` с теми же названиями в начале подписки.

Начиная с 1.3.2, эти сведения для текущей группы показывает карточка над списком профилей:

- **Трафик:** полоса с израсходованным и общим трафиком и процентом или `∞`, если общего объёма нет. Полоса становится красной при 90 % и после окончания срока действия.
- **Срок действия:** оставшееся время, например `12 д.` (12d left), или `Истекла` (Expired). Он становится красным, когда остаётся 3 дня или меньше. Наведите на него указатель мыши, чтобы увидеть дату.
- **Интервал обновления:** `Каждый(ые) …` (Every …), пока включено автоматическое обновление. Наведите на него указатель мыши, чтобы узнать, откуда взят интервал.
- **`Портал` (Portal) и `Поддержка` (Support):** открывают ссылки провайдера в браузере.
- **Объявление:** сообщение провайдера. Щёлкните его, чтобы прочитать весь текст.

Карточка появляется, только если провайдер передаёт хотя бы одно из этих сведений. Те же сведения показываются при наведении указателя на вкладку группы, а в окне `Группы` → `Управление группами` видны трафик и срок действия.

## Автоматическое обновление {#auto-update}

По умолчанию автоматическое обновление выключено. Чтобы включить его:

1. Откройте `Настройки` → `Основные настройки` → `Подписка`.
2. Рядом с `Авто-обновление подписки` (Subscription auto update) установите флажок `Включить` (Enable).
3. Задайте `Интервал (в минутах; неверно, если значение меньше 30)` (Interval (minute, invalid if less than 30)). По умолчанию — 30.
4. Нажмите `OK`.

Как работает автоматическое обновление:

- У каждой группы подписки своё расписание. Throne обновляет группу, когда с её последнего обновления прошёл интервал. Группы с флажком `Пропустить автоматическое обновление` пропускаются.
- По умолчанию все группы используют указанный выше интервал. Начиная с 1.3.2, группа может задать собственный `Интервал обновления` (Update Interval) в дополнительных параметрах; см. ниже.
- Интервал меньше 30 минут означает, что автоматическое обновление выключено. Флажок `Включить` выше должен быть установлен для любого автоматического обновления, в том числе для групп с собственным интервалом.
- Throne проверяет это раз в минуту, а также через 10 секунд после запуска. Обновление, срок которого наступил, пока Throne был закрыт, выполняется вскоре после его открытия.
- На вкладке `Статистика выполнения` (Runtime Stats) в поле `След. обновл. подписки` (Next sub update) показано время до следующего обновления группы.
- Автоматическое обновление никогда не открывает окно изменений. Оно пишет в лог те же строки, что и ручное обновление.

Начиная с 1.3.2, можно также следовать интервалу, который провайдер предлагает в заголовке `profile-update-interval` (в часах). Установите флажок `Использовать интервал обновления, установленный сервером подписки` (Use the update interval sent by the server) на вкладке `Подписка` (по умолчанию он снят). Группы, провайдер которых не передаёт интервал, по-прежнему используют обычный интервал.

Для одной группы откройте её параметры, нажмите `Доп. настройки` (Advanced) и воспользуйтесь разделом `Обновление` (Update):

| Параметр | Назначение |
| --- | --- |
| `Интервал обновления` (Update Interval) | Минуты между автоматическими обновлениями этой группы, не меньше 30. `По умолчанию` (Keep Default) — интервал с вкладки `Подписка`. |
| `Интервал сервера` (Server Interval) | `Использовать` (Use) или `Игнорировать` (Ignore) интервал, который передаёт провайдер. `По умолчанию` следует флажку `Использовать интервал обновления, установленный сервером подписки`. Если провайдер не передаёт интервал, действует `Интервал обновления`. |

## Параметры группы {#group-options}

Чтобы изменить группу, щёлкните её вкладку правой кнопкой мыши и выберите `Редактировать выбранную группу` (Edit selected Group) или выберите `Группы` → `Редактировать текущую группу` (Edit current Group).

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `Название` (Name) | – | Название на вкладке. |
| `Тип` (Type) | `Стандартный` (Basic) | `Стандартный` или `Подписка` (Subscription). Изменить тип после создания группы нельзя. |
| `Фронт-прокси` (Front Proxy) | `None` | Профиль, через который сначала подключается каждый профиль этой группы. См. [Фронт- и выходной прокси](#front-landing-proxy). |
| `Выходной прокси` (Landing Proxy) | `None` | Профиль, через который трафик выходит после профиля группы. |
| `Автоочистка недоступных профилей` (Auto Clear Unavailable Profiles) | выкл. | После теста задержки профилей этой группы удаляет профили, не прошедшие тест, не спрашивая подтверждения. |
| `URL` | – | Адрес подписки. Только для групп подписок. |
| `Пропустить автоматическое обновление` (Skip automatic update) | выкл. | Исключает эту группу из автоматических обновлений. Ручное обновление по-прежнему работает. |
| `Доп. настройки` (Advanced) | – | Открывает окно `Advanced Group Settings` (начиная с 1.3.1). См. [Автоматическое обновление](#auto-update), [После каждого обновления](#after-update), [User-Agent и HWID](#user-agent-and-hwid), [Версия TLS и HTTP](#tls-http-version) и [Адрес сервера](#server-address). Начиная с 1.4.0, эта кнопка есть и у стандартных групп, но только с разделом `Server Address`. |

Если в группе есть профили, в окне также есть кнопки `Копировать ссылки профилей` (Copy profile share links) и `Копировать ссылки профилей (Диплинк)` (Copy profile share links (Deep Links)). Они копируют ссылки всех профилей группы.

## После каждого обновления {#after-update}

Начиная с версии 1.3.1 группа подписки может сама наводить порядок после каждого обновления. Откройте параметры группы, нажмите `Доп. настройки` (Advanced) и воспользуйтесь разделом `Обновление` (Update). По умолчанию все параметры выключены.

| Параметр | Назначение |
| --- | --- |
| `Сохранять рабочие профили` (Keep working profiles) | Профили, последний тест которых прошёл успешно, сохраняются, даже если подписка их больше не содержит. |
| `Удалять дубликаты профилей` (Remove duplicate profiles) | Удаляет профили, которые являются точными копиями другого профиля. |
| `Удалять небезопасные профили` (Remove insecure profiles) | Удаляет профили, трафик которых недостаточно защищён, — так же, как `Группы` → `Удалить небезопасные конфигурации` (Remove Insecure Configs). |
| `Удалять недействительные профили` (Remove invalid profiles) | Удаляет профили, которые отклоняет ядро. Пропускается, пока ядро недоступно. |
| `Запускать тест задержки` (Run URL test) | Тестирует профили группы после завершения обновления — после любого уже запущенного теста. |
| `Удалять недоступные профили` (Remove unavailable profiles) | Требует `Запускать тест задержки`. Удаляет профили, не прошедшие тест. |
| `Сортировать по задержке` (Sort by latency) | Требует `Запускать тест задержки`. Сортирует группу: самые быстрые профили — первыми. |

В отчёте об изменениях перечислены все профили, удалённые этими параметрами. Профиль, к которому вы подключены, они не удаляют, если не включён параметр `Разрешить остановку активного профиля` (Allow stopping the active profile).

## User-Agent и HWID {#user-agent-and-hwid}

При загрузке подписки Throne отправляет заголовок `User-Agent` с названием приложения. Некоторые провайдеры отдают разным приложениям разные списки или отказывают незнакомым приложениям. Значение можно изменить:

- Для всех групп: `Настройки` → `Основные настройки` → `Подписка` → `User Agent`. Если поле пустое, Throne отправляет `Throne/` и номер своей версии, например `Throne/1.3.1`.
- Для одной группы (начиная с 1.3.1): параметры группы → `Доп. настройки` (Advanced) → `Запрос` (Request) → `User Agent`. Если поле пустое, группа использует глобальное значение.

Некоторые провайдеры также требуют идентификатор устройства (HWID). Throne отправляет его, только если вы это включите:

- Для всех групп: на вкладке `Подписка` (Subscription) установите флажок `Включить отправку HWID, модели устройства и версии ОС при обновлении подписки` (Enable sending HWID, device model, and OS version when updating subscription). По умолчанию он снят. Наведите на него указатель мыши, чтобы увидеть значения, которые отправит Throne.
- Для одной группы: установите для `Отправлять HWID` (Send HWID) значение `По умолчанию` (Keep Default, следовать глобальной настройке), `Вкл.` (On) или `Выкл.` (Off). Поля `HWID`, `ОС` (OS), `Версия ОС` (OS Version) и `Модель устройства` (Device Model) переопределяют значения для этой группы. Изменять их можно, только пока для группы включена отправка HWID.

Чтобы отправлять другие значения для всех групп, заполните поле `Указать параметры системы вручную (опционально)` (Custom System Parameters (optional)) на вкладке `Подписка`. Используйте такой формат и опустите значения, которые не нужно менять:

```text
hwid=value,os=value,osVersion=value,model=value
```

Throne передаёт эти значения в заголовках `x-hwid`, `x-device-os`, `x-ver-os` и `x-device-model`. Что именно в них содержится, см. на странице [Конфиденциальность и сетевые запросы](@/reference/privacy.ru.md#hwid).

## Версия TLS и HTTP {#tls-http-version}

Некоторые серверы подписок отвечают на обычное подключение Throne капчей, страницей блокировки или ошибкой. Начиная с 1.3.2, можно изменить способ подключения к ним:

- Для всех групп: `Настройки` → `Основные настройки` → `Подписка` → `Версия TLS` (TLS Version) со значениями `Авто` (Auto), `TLS 1.2` и `TLS 1.3` и `Версия HTTP` (HTTP Version) со значениями `Авто` и `HTTP/1.1`. По умолчанию оба параметра имеют значение `Авто`. В режиме `Авто` Throne использует HTTP/2, если сервер его предлагает.
- Для одной группы: параметры группы → `Доп. настройки` (Advanced) → `Запрос` (Request) → `Версия TLS` и `Версия HTTP`. Значение `По умолчанию` (Keep Default) следует глобальной настройке.

`TLS 1.2` часто помогает, когда на обычное рукопожатие сервер отвечает капчей. `TLS 1.3` недоступен, если его не поддерживает TLS-библиотека вашей системы.

## Фронт- и выходной прокси {#front-landing-proxy}

Группа может направлять трафик всех своих профилей через два дополнительных профиля:

**Ваше устройство → `Фронт-прокси` → профиль этой группы → `Выходной прокси` → WARP (если включён) → интернет**

- Используйте `Фронт-прокси` (Front Proxy), когда ваше устройство не может напрямую подключиться к серверам группы.
- Используйте `Выходной прокси` (Landing Proxy), когда сайты должны видеть адрес выходного прокси, а не серверов группы.

Можно выбрать любой сохранённый профиль из любой группы; для поиска начните вводить текст в поле. Профили автовыбора не предлагаются, потому что они сами переключают серверы. О цепочках и правилах совмещения ядер см. [Цепочки прокси и пользовательские конфигурации](@/advanced/chains.ru.md#front-landing).

## Адрес сервера {#server-address}

Начиная с 1.4.0, группа может направить все свои профили на другой адрес, чем указан в их параметрах. Это полезно, когда серверы провайдера находятся за CDN и вы хотите использовать адрес этой CDN, который работает в вашей сети, — например, найденный [IP-сканером](@/guides/testing.ru.md#ip-scanner).

Откройте параметры группы, нажмите `Доп. настройки` (Advanced) и выберите вариант в разделе `Server Address`:

| Вариант | Назначение |
| --- | --- |
| `Profiles' own addresses` (по умолчанию) | Каждый профиль подключается к своему серверу. |
| `Fixed address` | Все профили подключаются к введённому имени хоста или IP-адресу. Вводите его без порта. |
| `IP list` | Все профили подключаются к первому адресу IP-списка. Окно показывает, какой это адрес. Вариант недоступен, пока у вас нет IP-списков. |

Профили сохраняют свои порты. Если сервером профиля было доменное имя, Throne по-прежнему отправляет это имя как имя сервера TLS (SNI) и как `Host` транспортов WebSocket, HTTPUpgrade, HTTP и XHTTP, если профиль не задаёт их сам. В столбце `Адрес` (Address) показан адрес, который каждый профиль использует на самом деле. Если IP-список пуст или удалён, профили используют свои адреса, а в логе появляется сообщение об этом.

Профиль может переопределить настройку группы: в редакторе профиля нажмите `Доп. настройки` (Advanced Settings) и установите для `Server Address` значение `Inherit from group` (по умолчанию), `Own address` или `IP list`. У профилей без одного постоянного адреса сервера — например, у цепочек, автовыбора, `Direct`, `Tailscale`, `Extra Core` и пользовательских конфигураций — этого параметра нет, и настройка группы на них не действует.

Если изменить адрес сервера группы, пока запущен один из её профилей, Throne перезапускает профиль.

## Поддерживаемые форматы {#formats}

Подписка может возвращать:

- Ссылки для обмена, например `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://` или `tuic://`, по одной на строку, обычным текстом или в кодировке Base64.
- YAML Clash или Mihomo со списком `proxies:`.
- JSON sing-box: полную конфигурацию или список outbound. Каждый поддерживаемый outbound становится профилем. Одиночный объект outbound становится одним пользовательским профилем outbound.
- JSON Xray. Outbound конфигурации становятся профилями. Список полных конфигураций Xray превращается в профили `Custom Xray Config` — по одному на каждую конфигурацию.
- SIP008 (JSON Shadowsocks), файлы `.conf` WireGuard и AmneziaWG, файлы `.ovpn` OpenVPN, XML-профили AnyConnect и ссылки `vpn://` AmneziaVPN.

Станет ли ссылка `vless://` профилем sing-box или Xray, зависит от параметра `Настройки` → `Основные настройки` → `Ядро` (Core) → `Предпочтение Xray для VLESS` (Xray VLESS Preference). Начиная с 1.4.0, этому параметру следуют и записи VLESS с REALITY в YAML Clash. Throne применяет его при импорте, поэтому после изменения параметра обновите подписки ещё раз. См. [sing-box или Xray](@/advanced/xray.ru.md#vless-preference). Полный список форматов приведён на странице [Протоколы и форматы импорта](@/reference/protocols.ru.md#import-formats).

## Проблемы {#problems}

Сначала откройте вкладку `Логи` (Logs). Каждое обновление записывает строки, начинающиеся с `>>>>>>>>` и `<<<<<<<<`, в том числе текст ошибки, если она возникла.

### Провайдер отказывает Throne или не присылает профили {#problem-user-agent}

Некоторые провайдеры отвечают только знакомым им приложениям. Тогда в логе появляется ошибка, например код состояния 403, или сообщение «No profiles found in the subscription» (в подписке не найдено профилей). Укажите в поле `User Agent` группы (параметры группы → `Доп. настройки` (Advanced)) значение, которое ожидает ваш провайдер. Пользователям, например, требовались значения `ClashMeta`, `sing-box` и `Happ/1.0`.

### Сервер возвращает веб-страницу или капчу {#problem-web-page}

Начиная с 1.4.0, Throne сообщает «The server returned a web page instead of a subscription» (сервер вернул веб-страницу вместо подписки), если в ответ пришла веб-страница, например капча или проверка на бота. Попробуйте `TLS 1.2` или `HTTP/1.1` в дополнительных параметрах группы (см. [Версия TLS и HTTP](#tls-http-version)) или другой `User Agent`.

Если при добавлении подписки первая загрузка не удалась, Throne сохраняет новую группу и сообщает об этом (начиная с 1.4.0). Измените её параметры и обновите её снова; добавлять подписку заново не нужно.

### Провайдер требует идентификатор устройства {#problem-hwid}

Если провайдер запрашивает идентификатор или отпечаток устройства, включите отправку HWID: установите для группы `Отправлять HWID` (Send HWID) в значение `Вкл.` (On) или включите отправку для всех групп на вкладке `Подписка` (Subscription).

### «Запрос через прокси, но профиль не запущен.» (Request with proxy but no profile started.) {#problem-no-profile}

Throne отправляет собственные запросы, например обновления подписок, через свой локальный прокси-порт, если включён параметр `Настройки` → `Основные настройки` → `Прочее` (Miscellaneous) → `Использовать прокси` (Use proxy). Он делает это и всякий раз, когда установлен флажок `Системный прокси` (System Proxy). Если ни один профиль не запущен, прокси нет, и запрос завершается этой ошибкой. Сначала запустите профиль или выключите `Использовать прокси` и `Системный прокси`.

### Адрес подписки заблокирован в вашей стране {#problem-blocked}

1. Запустите рабочий профиль.
2. Включите `Настройки` → `Основные настройки` → `Прочее` → `Использовать прокси`.
3. Обновите подписку.

Для `Использовать прокси` нужен локальный прокси-порт, поэтому этот параметр не работает, пока включён параметр `Отключить смешанный входящий порт` (Disable Mixed Inbound).

### Ссылки «crypt» из Happ и v2RayTun {#problem-crypt}

Ссылки, начинающиеся с `happ://crypt` или `v2raytun://crypt`, зашифрованы для этих приложений, и Throne не может их прочитать. Веб-страницы вида `…/dl/happ-link/…` тоже не являются подписками. Попросите у провайдера обычный адрес подписки, начинающийся с `https://`.

### Профили отображаются как `Custom Xray Config` {#problem-custom-config}

Если подписка возвращает список полных конфигураций Xray, Throne импортирует каждую конфигурацию как один профиль типа `Custom Xray Config`; в редакторе профиля этот тип называется `Польз. (Xray конфигурация)` (Custom (Xray config)). Throne удаляет из каждой конфигурации раздел `inbounds`, а остальное запускает как есть. Так задумано: такие конфигурации могут содержать балансировщики нагрузки и цепочки, которые работают только целиком. Конфигурация sing-box, напротив, разбивается на профили — по одному на каждый outbound.

Дополнительная помощь — на странице [Устранение неполадок](@/help/troubleshooting.ru.md#subscriptions).

## На Android {#android}

В Throne для Android те же группы, параметры и поведение при обновлении.

- Откройте `Группы` (Groups) в боковом меню. Вверху находятся `New group` и `Обновить все подписки` (Update all subscriptions). Для каждой группы показаны её тип, число профилей, время последнего обновления и, если провайдер передаёт эти сведения, квота («Used … · … left · expires …» — использовано, осталось, срок действия).
- В редакторе группы те же основные параметры, только их названия написаны с одной заглавной буквой: `Front proxy`, `Landing proxy`, `Auto clear unavailable profiles`, `Skip automatic update` и `Advanced`. После 2.0.2 в `Дополнительно` (Advanced) появляются также `Версия TLS` (TLS version), `Версия HTTP` (HTTP version), `Интервал обновления (минуты)` (Update interval (minutes)) и `Интервал от сервера` (Server interval), а в `Настройки` → `Подписки` — `Использовать интервал обновления от сервера` (Use the update interval sent by the server), `Версия TLS для подписок` (Subscription TLS version) и `Версия HTTP для подписок` (Subscription HTTP version). Тогда же приложение начинает сообщать, что сервер вернул веб-страницу, и показывать проблемы импорта или обновления в окне отчёта. Параметра `Server Address` в Throne для Android нет.
- Начиная с 2.0.2, над списком профилей показывается карточка со [сведениями от провайдера](#provider-info): трафик, оставшееся время, `Портал` (Portal) и `Поддержка` (Support) и объявление. Нажмите на объявление, чтобы прочитать его целиком. Чтобы скрыть карточку для одной группы, выключите в редакторе группы `Карточка сведений о подписке` (Subscription info card).
- Начиная с 2.0.2, у группы подписки есть раздел `Фильтр` (Filter) с двумя регулярными выражениями. `Только совпадающие имена` (Only names matching) оставляет только профили, имя которых совпадает с выражением, например `HK|SG|Japan`. `Удалять совпадающие имена` (Remove names matching) удаляет профили с совпадающим именем, например `expire|traffic|website`. Регистр не учитывается. Фильтры применяются при каждом обновлении, а в отчёте об изменениях указано, сколько профилей они отфильтровали. Если после фильтров не осталось бы ни одного профиля, обновление прерывается, и группа остаётся без изменений.
- Начиная с 2.0.2, записи, которые ядро Android не может запустить, пропускаются. См. [Отличия на Android](@/reference/protocols.ru.md#android-import).
- Поле `URL` принимает и адрес `content://`, поэтому подписка может поступать из файла, который предоставляет другое приложение. Для обычного адреса `http://` редактор предупреждает: «Передача HTTP-трафика в виде открытого текста небезопасна» (Cleartext HTTP traffic is insecure).
- Глобальные параметры находятся в `Настройки` (Settings) → `Подписки` (Subscriptions). Если поле `User agent` пустое, приложение отправляет `Throne/Android/` и номер своей версии.
- `Добавить профиль` (Add profile) → `Импорт из буфера обмена` (Import from clipboard) с адресом в буфере задаёт тот же вопрос «How to update?» (как обновить?).
- Окно изменений появляется только после ручного обновления одной группы. Автоматические обновления только пишут в лог.

Проблемы, характерные для Android, описаны на странице [Устранение неполадок на Android](@/android/troubleshooting.ru.md#subscriptions).
