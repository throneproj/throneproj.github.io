These guides explain the everyday features of Throne desktop in depth. Most of them also apply to Throne for Android, because both apps use the same settings. Where the apps differ, a guide says so in a platform note. Topics that exist only on Android are in [Throne for Android](@/android/_index.md).

Since 1.4.0, a new installation starts in Simple mode, which hides some of the options that these guides describe. See [Simple and Advanced mode](@/get_started/configuration.md#interface-mode).

If you are new to Throne, read these three first, in this order: [Subscriptions & Groups](@/guides/subscriptions.md), [System Proxy, TUN & LAN Sharing](@/guides/proxy_modes.md) and [Routing](@/guides/routing.md).

To control Throne from scripts, hotkey tools or other devices, see [Throne API & thronectl](@/advanced/api.md). To run Throne on a server or in a container without a window, see [Headless Throne](@/headless/_index.md).
