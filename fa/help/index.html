پشتیبانی

جای پیدا کردن پاسخ‌ها، راه رفع مشکلات رایج و روش گزارش باگ یا طرح پرسش.

برای پرسش‌های رایج، از پرسش‌های متداول شروع کنید و وقتی چیزی کار نمی‌کند، به عیب‌یابی مراجعه کنید. اگر از Throne برای Android استفاده می‌کنید، عیب‌یابی Android را ببینید.

برای گزارش یک باگ، ابتدا گزارش باگ را بخوانید، سپس یک issue برای Throne دسکتاپ یا Throne برای Android باز کنید. پرسش‌های مربوط به استفاده از Throne دسکتاپ را در دستهٔ Q&A در GitHub Discussions مطرح کنید.
